# 运行记录与管理

::: say
> 新闻助手最近一次运行做了什么？

> 先暂停新闻助手。

> 现在就让新闻助手跑一次。

Halo 会查看这位数字人的状态并告诉你结果，或者直接替你暂停、运行。要在这位数字人所在的工作区里说。
:::

## 所有数字人一览 {#directory}

点左侧栏的 **数字人**，在 **我的数字人** 里能看到所有数字人，按状态分组：**需要你处理**、**运行中**、**待命中**、**已暂停**。

- 用「搜索姓名、角色或团队」搜索，或按 **所有团队**、**所有工作区** 筛选。
- 有数字人在等你时，会出现 **全部处理（N 项）**，点它打开「需要我的关注」，一次看完所有待你决定的事。
- 卸载过的数字人在页面最下面的 **已移除** 里。

![数字人页面的「我的数字人」：几位数字人按需要你处理、待命中、已暂停分组显示，每张卡片写着所在工作区和状态](/images/digital-humans/manage/directory.zh.webp)

## 一位数字人的页面 {#person-page}

点开一位数字人，顶部是它的名字、状态、运行计划、上次和下次运行时间，右上角有：

- **聊天**：和它对话（全局安装的数字人没有这个按钮）。
- **立即运行**：马上开始一次运行。
- **暂停自动任务** / **启用自动任务**。
- **浏览器**：打开它要用的网站，提前登录。
- **⋮**：**重启智能体**、**分享**、**导出配置**、**移动到其他工作区**、**清除记忆**、**卸载**。

下面有四个标签：**工作动态**、**IM 会话**（绑定了机器人才有）、**参与的团队**、**能力与设置**。

## 看它做了什么 {#work-activity}

**工作动态** 是这位数字人的工作记录，最上面是等你处理的事，下面是 **最近活动**。可以用 **活动来源** 只看团队、独立执行、对话或版本更新。

![一位数字人的页面：头部是聊天、立即运行和暂停自动任务按钮；工作动态里依次是最近几次运行的成功情况、需要你处理、当前团队工作和最近一次运行的结果](/images/digital-humans/manage/work-activity.zh.webp)

每条运行记录会写明结果、用时和用掉的 token，产出的文件可以直接 **下载**：

- 点 **查看进程**，看这次运行的完整过程。正在运行时，可以在「添加一条消息以指导本次运行...」里补充要求。
- 运行失败时，记录上会有 **继续**，点它让数字人接着做。
- 显示 **未启动** 时，说明它要用的某个连接没准备好（没安装、被关闭、等待登录或连接失败），按提示去 **工具与资源** 处理。
- 正在运行时，顶部显示「独立执行进行中」，可以点 **停止此执行**。

## 回答它的提问 {#answer-questions}

数字人遇到需要你拍板的事，会停下这项工作，弹出一张问题卡片：

1. 点一个选项，或者在「输入你的回复…」里写你的决定。
2. 点 **提交并继续这项工作**。只有这项工作会继续，其他自动任务不受影响。

![「需要你处理」里的问题卡片：问题、两个选项和回复输入框，下面是忽略此请求、关闭此项工作…和提交并继续这项工作](/images/digital-humans/manage/escalation-card.zh.webp)

不想回答，可以点 **忽略此请求**（工作继续进行，不给答复）；不想让这项工作继续了，点 **关闭此项工作…**。

问题卡片会出现在这些地方，在哪里回答都一样：**工作动态** 顶部、「需要我的关注」、**任务** 面板，以及系统通知。如果数字人绑定了机器人，问题还会私聊发给你（机器人的主人），直接在私聊里用平常的话回复就行，不需要任何命令。

数字人有问题在等你时，它到点的定时运行会被跳过，直到你回答。

## 立即运行和暂停 {#run-pause}

- **立即运行**：数字人已暂停时也能用；正在运行或排队时不能再点。
- **暂停自动任务**：停掉定时运行和事件触发的运行，并丢掉排队中的自动工作。正在进行的运行、聊天和提醒不受影响。点 **启用自动任务** 恢复。

## 多次失败后自动停止 {#auto-paused}

数字人连续失败 5 次后，Halo 会停掉它的自动任务，它会出现在 **需要你处理** 里，卡片上写着「多次失败后已自动停止」。看一下最近的失败原因，解决后点 **恢复工作**。

## 和它聊天 {#chat}

点 **聊天** 会在它所在的工作区里开一个新的聊天，旧的聊天在 **会话** 列表的 **数字人** 分组里。绑定了机器人后，**IM 会话** 标签里能看到别人在企业微信、飞书或微信里和它的对话（只读）；点 **在客户端中继续**，可以把某段对话接到 Halo 里继续。

## 导出和导入 {#export-import}

- **导出给同事**：点 **⋮ › 分享**，选 **导出**，会保存一个可以手动发给别人的数字人包。对方在 **创建数字人 › 导入** 里导入即可。
- **只导出配置**：点 **⋮ › 导出配置**，下载这位数字人的 YAML 配置。
- **发布到商店**：在 **分享** 里选 **分享到商店**，见 [发布到商店](/developers/store-publishing)。

## 卸载和永久删除 {#uninstall}

点 **⋮ › 卸载**。卸载后它的工作历史会保留，它带来的技能会被移除；之后可以在 **已移除** 里打开它，点 **重新安装应用** 装回来。

在 **已移除** 里点 **永久删除** 会删掉它的记录、对话和整个数据文件夹（包括记忆），不能恢复。

::: danger 让 Halo 删除时不会再确认
对 Halo 说「删掉新闻助手」时，Halo 会直接永久删除，不会像界面那样先卸载、再确认。
:::

## 限制 {#limits}

| 项目 | 说明 |
|---|---|
| 同时运行 | 整个 Halo 最多同时 10 次独立运行，多出的排队；每位数字人同一时间只有一次运行 |
| 运行时长 | 没有时间上限；需要时点 **停止此执行** |
| 连续失败 | 连续失败 5 次后自动停止自动任务 |
| 运行过程 | 每位数字人最近 200 次运行保留完整过程，更早的只保留结果 |
| 工作动态 | 保留一年 |

::: done
你能在 **工作动态** 里看到每次运行的结果；回答完问题后，卡片上显示「已收到答复」，原来的工作接着进行。
:::

## 遇到问题 {#troubleshooting}

### 运行记录显示「未启动」

它声明要用的某个连接（比如某个 MCP 服务）不可用。按卡片上的提示打开 **工具与资源**，安装、打开或重新登录那个连接。

更多情况见 [数字人没有运行](/troubleshooting/digital-humans)。
