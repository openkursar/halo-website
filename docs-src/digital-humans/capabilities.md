# 能力与设置

打开数字人，切到 **能力与设置**。左边是分组目录，同时显示每组的状态：有没改完的、有没空着的必填项、运行计划是什么。右上角可以在 **设置** 和 **YAML** 之间切换。

改了影响聊天的设置后，页面上方会出现 **快速重启**：它不会删任何数据，但会停下正在进行的工作，让聊天用上新设置。

## 身份与指令 {#identity}

| 设置 | 作用 |
|---|---|
| **名称**、**描述** | 在目录和团队里显示；队友会读描述来分派工作 |
| **系统提示词** | 它的工作说明：每次做什么、怎么做、什么时候问你。长的可以点 **展开编辑器** |

改完点 **保存**，点 **重置** 放弃修改。

## 触发器 {#trigger}

| 设置 | 作用 |
|---|---|
| **定时执行** | 按间隔或按时间运行，见 [运行计划](/digital-humans/triggers#schedule) |
| 仅限中国大陆工作日 | 跳过法定节假日，见 [只在中国大陆工作日运行](/digital-humans/triggers#working-days) |
| **HTTP 触发器** | 复制一条命令，让别的程序启动它，见 [HTTP 触发器](/digital-humans/triggers#http-trigger) |
| **提醒** | 在它的聊天里约好的提醒，可以在这里取消，见 [提醒](/digital-humans/reminders) |

没有运行计划时，摘要显示「手动 / IM 触发」。

## 运行时参数 {#runtime-parameters}

只有数字人声明了配置项时才有这一组（比如从商店装的，要填关注的关键词）。每次运行都会读这些值。必填项空着不会让它停下，只是它会缺少信息干活。

## 模型与能力 {#model-and-capabilities}

### 模型 {#model}

默认 **跟随全局设置**，用输入框旁边选的模型。也可以给它单独指定一个模型；点 **重置为全局设置** 改回来。指定的账号被删掉后，它会自动改回跟随全局。

### 能力 {#capabilities}

| 开关 | 默认 | 作用 |
|---|---|---|
| **AI 浏览器** | 开 | 打开网页、点击、填表，见 [AI 浏览器](/features/ai-browser) |
| **AI 终端** | 开 | 在终端里运行命令；只在 macOS 和 Windows 上有效 |
| **操作 Halo** | 关 | 管理工作区、数字人、知识库和设置，见 [操作 Halo](/features/operate-halo) |
| **对话协作** | 关 | 读取同一工作区里的其他会话，也能给它们发消息；它在那些会话里以完全权限行事，只给信得过的数字人打开 |
| **电子邮件** | 开 | 收发和整理邮件、查看日历；要先在 **设置 › 消息通道** 配好邮箱，见 [邮件与日历](/features/email) |
| **IM推送** | 开 | 主动给机器人的联系人发消息；要先接好机器人，见 [通知与主动推送](/digital-humans/notifications) |

网页搜索和记忆始终可用，不需要开关。**操作 Halo** 不会给机器人里的访客使用。开关打开了、但还缺通道时（比如 **电子邮件** 没配邮箱），下面会有一行黄色提示，点它可以直接去设置。

## 工具与资源 {#tools-and-resources}

| 部分 | 作用 |
|---|---|
| **MCP 工具** | 它声明要用的连接和状态。可以 **对此数字人启用** 或 **对此数字人禁用**（只影响这一位），**添加依赖**、**浏览MCP商店**、**新建连接**、**测试连接** |
| **可用技能** | 工作区和全局的技能。可以 **选择现有的**、**新建技能**、**导入** 或 **浏览技能商店**；改动会影响同一范围里的其他数字人 |
| **知识** | 勾选它能读的知识库，或 **添加知识**、**管理** |
| **所需登录** | 它要用的网站，点一下在 Halo 的浏览器里打开并登录 |

规则：聊天会继承工作区的连接（明确禁用的除外）；独立运行只用它声明的连接。声明的连接不可用时，那次运行会显示 **未启动**，见 [运行记录显示「未启动」](/troubleshooting/digital-humans#not-started)。

## 消息与通知 {#messages-and-notifications}

| 部分 | 作用 |
|---|---|
| **系统通知** | **重要**（默认：里程碑、提问和产出）、**全部**（每次运行结果）或 **无** |
| **消息通道** | 已配置的通知通道；数字人自己决定什么时候发、发什么 |
| **可联系的联系人** | 给机器人发过消息的人和群；可以改名、移除，或打开 **自动同步运行结果** |
| **机器人访问权限** | **扫码添加机器人**、**绑定已有机器人** 或 **解绑**，见 [消息通道概览](/digital-humans/channels#binding) |

## 高级 {#advanced}

| 部分 | 作用 |
|---|---|
| **升级** | 每位数字人都有这一项，但只对从商店装的数字人起作用。**升级策略** 可选 **自动（静默安装补丁/次要更新）**（默认，大版本会先问你）、**仅通知** 或 **手动**，也可以点 **检查升级** |
| **应用规格** | 类型、版本、触发方式、工作区文件夹，以及记忆文件的位置 |
| **记忆** | 它自己的记忆；打开 **使用工作区记忆** 后，还能读工作区学到的内容（只读） |
| **运行时控制** | **重新启动Agent**：重新加载提示词和配置，聊天记录保留；和页面右上角 **⋮ › 重启智能体** 作用相同 |
| **危险区域** | **清除记忆**（删掉记忆和运行记录，工作动态里的条目保留）、**卸载**、**清空所有对话**（记忆和提醒保留） |

## YAML {#yaml}

**YAML** 标签可以直接编辑完整的数字人定义，改完点 **保存**；也可以 **重置** 或 **导出**。数字人的类型不能改。图形界面改不了的设置（比如复杂的时间规则、文件变化和 Webhook 触发），在这里改。字段说明见 [数字人 spec 参考](/developers/digital-humans/spec)。
