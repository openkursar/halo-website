# 数字人商店

数字人商店是 Halo 内置的应用市场。你可以像安装 App 一样，一键安装由社区开发者调教好的数字人，无需写代码，无需复杂配置，开箱即用。

## 打开商店

点击 Halo 主界面左侧的**商店**入口，或进入设置中的 **App Store** 选项。

<!-- 截图占位：screenshot-store.png（数字人商店主界面） -->

---

## 安装流程

1. 在商店中浏览或搜索场景关键词
2. 点击目标数字人，查看详情和说明
3. 点击「安装」
4. 填写少量必要参数（如目标关键词、通知邮箱等）
5. 启动运行

整个过程通常不超过 2 分钟。

---

## 典型场景示例

| 数字人 | 功能 |
|--------|------|
| **舆情监控** | 7×24 跟踪品牌/产品关键词，发现异常推送预警 |
| **Hacker News 日报** | 每天早上汇总 HN 热门内容，发送邮件摘要 |
| **代码评审助手** | 监听 GitHub PR，自动检查代码质量并评论 |
| **日报/周报生成器** | 定时汇总工作内容，自动发送报告 |
| **竞品动态追踪** | 定期抓取竞品官网/社媒，推送变化摘要 |
| **小红书评论监控** | 追踪指定账号或关键词的评论动态 |

更多数字人见 → [DHP Registry 生态](https://github.com/openkursar/digital-human-protocol)

## 为什么不自己写提示词？

理论上你可以自己配置一个 AI 执行这些任务，但实际难度远高于想象。

以「小红书舆情监控」为例：怎么搜帖子？怎么过滤无效内容？用哪个 MCP？数据怎么结构化？什么情况触发预警？输出发到哪里？每个细节都需要反复调试。

开发者把调教好的数字人打包上架，你一键安装，开箱即用。专业人做专业事。

## 贡献你的数字人

任何人都可以把自己写好的数字人发布到商店。流程见 → [DHP 协议](/digital-humans/dhp-protocol)

不想从零开始写 spec？在 Halo 对话中直接描述你想要的数字人功能，AI 会自动生成对应的配置。详见 [创建数字人](/digital-humans/create)。
:::
