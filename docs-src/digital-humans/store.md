# 商店

::: say
> 在商店里找一个每天汇总科技新闻的数字人，装到这个工作区。

Halo 会在商店里搜索，把合适的几个列给你挑，再装到当前工作区。**前提**：输入框 **＋ › 能力** 里的 **操作 Halo** 要打开。
:::

## 打开商店 {#open}

点左侧栏的 **商店**，打开「探索 · 商店」：

- 顶部的搜索框会同时搜所有来源，按名称、描述、作者和标签匹配。
- 下面是 **发现**、**数字人**、**技能**、**MCP** 四个标签。**发现** 是商店首页，官网版在这里列出全部条目（**全部应用**），公司自建的商店还可能有精选和专题；另外三个只看一种，可以按分类筛选，往下点 **加载更多**。
- 列表看起来没更新时，点搜索框右边的 **刷新**。

![「探索 · 商店」的数字人标签：顶部是搜索框、刷新和发布应用，下面是分类筛选和一张张数字人卡片](/images/digital-humans/store/browse.zh.webp)

商店里的东西来自几个来源：数字人协议（DHP）官方仓库、MCP 官方注册表、Smithery、Claude Skills 和 SkillHub。在 **设置 › 应用商店** 里可以关掉不需要的来源，或者 **添加注册表**；公司想搭自己的商店，见 [私有商店](/advanced/private-store)。

## 安装数字人 {#install-digital-human}

1. 在 **数字人** 标签里点一张卡片。详情页上有它的描述、要填的 **配置**、依赖的技能和 MCP（**依赖项**），以及系统提示词（点 **查看系统提示词** 展开）。
2. 点 **安装**。
3. 在 **安装到** 里选一个工作区。数字人只能装到一个工作区；只有一个工作区时不用选。
4. 有要填的配置时点 **下一步**，填好必填项，再点 **安装**；没有配置的，直接点 **安装**。
5. 装好后按钮变成 **已安装**，点 **去使用** 打开它。

![商店里一位数字人的详情页：右上角是安装按钮，左边列出描述、配置项、依赖项和系统提示词](/images/digital-humans/store/detail.zh.webp)

它依赖的技能会一起装好；有一个装不上，这次安装会整个撤回，不会留下装了一半的数字人。

![安装第 1 步「选择安装位置」：安装到哪个工作区，以及下一步按钮](/images/digital-humans/store/install-step1.zh.webp)

![安装第 2 步「配置」：几项必填配置已经填好，下面是返回和安装按钮](/images/digital-humans/store/install-step2.zh.webp)

::: tip 有要登录的网站时
详情里列着 **所需登录** 的网站时，装好后先在 Halo 的浏览器里登录这些网站，它运行时才能用，见 [AI 浏览器](/features/ai-browser#digital-human-sign-in)。
:::

::: done
它出现在 **数字人 › 我的数字人** 里；有运行计划的，到点就会开工。想马上看效果，打开它点 **立即运行**。
:::

## 安装技能 {#install-skill}

1. 在 **技能** 标签里点一张卡片，详情里能看到技能的说明 **文档**。
2. 点 **添加**，选 **全局（所有工作区）** 或者某个工作区。全局的技能在每个工作区都能用；工作区里有同名技能时，以工作区的为准。
3. 装好后按钮变成 **已添加**，点 **去使用**，会开一个带着这个技能的对话。

## MCP 服务 {#mcp}

在商店页面上，MCP 条目只能浏览，按钮显示 **即将推出**。要装 MCP 服务，打开数字人的 **能力与设置 › 工具与资源 › MCP 工具**，点 **浏览MCP商店**，从那里装到这位数字人的工作区，见 [MCP 服务器](/features/mcp#from-the-store)。

## 更新 {#updates}

Halo 启动后约 1 分钟检查一次，之后每 6 小时检查一次，看从商店装的东西有没有新版本。它比对的是本地缓存的商店目录，这份目录在启动时、打开商店或点 **刷新** 时才会同步，所以新版本要等同步之后才看得到。

有新版本时，详情页的按钮会变成 **更新至 vX**。点它，在「有可用更新」里三选一：

| 选项 | 作用 |
|---|---|
| **原地更新**（数字人）或 **覆盖升级**（技能、MCP） | 原地更新：换成新版本，你改过的地方保留你的版本，之后可以在 **工作动态** 里逐项改用作者的版本。覆盖升级：内容换成新版本，你对内容的改动会被替换，设置和数据保留 |
| **保留当前,装为新副本** | 把新版本装到另一个工作区，原来的不动 |
| **跳过此版本** | 这个版本不再提醒 |

每位数字人自己怎么更新，看它的 **能力与设置 › 高级 › 升级 › 升级策略**：默认自动安装补丁和次要更新（大版本会先问你），也可以选 **仅通知** 或 **手动**。

离线时不能安装或更新。

## 分享你做的数字人 {#share}

- **导出成文件**：打开数字人，点右上角的 **⋮ › 分享**，再点 **导出**，得到一个 `.dhpkg` 文件，发给同事。同事在 **创建数字人 › 导入** 里装上，见 [导入文件](/digital-humans/create#import)。只有桌面版能导出。
- **发布到商店**：在商店点 **发布应用**，或者在 **分享** 里点 **分享到商店**，按提示选择要发布的数字人或技能。从官网下载的 Halo 不会直接上架：它会打包好文件，在浏览器里打开一个填好内容的 GitHub 议题（Issue）页面。把打包好的文件手动附上去；正文里带着这个文件在你电脑上的临时路径，Windows 上会包含你的用户名，提交前删掉这段路径。提交后等人工审核。步骤见 [发布到商店](/developers/store-publishing)。

![「发布应用到商店」窗口：先选要发布的是数字人还是技能](/images/digital-humans/store/publish-dialog.zh.webp)

`.dhpkg` 文件的格式见 [DHP 协议](/developers/dhp#package)。

## 遇到问题 {#troubleshooting}

### 安装按钮显示「离线」

提示「您处于离线状态。请连接网络以安装。」联网后再装。

### 提示「此应用已安装在所选范围中。」

这个工作区里已经装过它。换一个工作区，或者先把原来的卸载。

### 提示 Installation of "…" failed

这条提示只有英文，意思是安装过程中出了错（常见的是它依赖的某个技能装不上），整个安装已经撤回。看冒号后面的原因，稍后重试；一直失败的话，联系作者。

### 详情页显示「不支持的包格式」

这个条目的打包格式 Halo 还不支持，暂时装不了。
