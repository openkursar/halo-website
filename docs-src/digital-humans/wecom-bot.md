# 企业微信智能机器人

接入要你自己在 Halo 和手机企业微信里操作，Halo 不能替你扫码或填写密钥。

## 开始之前 {#before-you-start}

- 一个企业微信账号，手机上装着企业微信。
- Halo 开着。机器人靠 Halo 保持连接，Halo 退出或电脑睡眠时它不会回复，见 [让数字人一直在线](/digital-humans/keep-running)。

先分清两样东西：企业微信里的 **机器人** 只负责收发消息，理解消息、动手干活的是 Halo 里的 **数字人**。机器人是门，数字人是门后面的人。扫码添加会把两样一次配好。

## 扫码添加 {#scan}

1. 打开 **设置 › 消息通道**，找到 **企业微信智能机器人**，点 **扫描添加**。
2. 在「扫描添加企业微信机器人」窗口里，用手机企业微信扫二维码，再在手机上点「同意」。二维码 5 分钟内有效；等待时可以点 **重新生成** 换一个。
3. Halo 会自动新建一位数字人「WeCom Assistant …」并绑定好，窗口显示「机器人添加成功」。
4. 按窗口里的提示做：「下一步：打开企业微信，向这个机器人发送任意一条消息。你的用户 ID 会被自动绑定为主人，无需手动配置。」点 **明白了**。
5. 在企业微信里找到这个机器人，私聊给它发一句话。它会先回「✅ 已自动绑定你为本机器人的主人，拥有完整权限。」，再回答你。

![「扫描添加企业微信机器人」窗口：中间是二维码（已打码），下方是过期倒计时和重新生成按钮](/images/digital-humans/wecom-bot/scan-dialog.zh.webp)

::: warning 第一个私聊机器人的人会成为主人
扫码添加的机器人会打开权限控制。谁先私聊它，谁就成为主人，所以添加好后请马上自己发第一条消息。主人和访客的区别见 [主人与访客权限](/digital-humans/permissions)。
:::

机器人的名字由企业微信自动起（比如「某某的机器人」），可以在企业微信的「工作台 › 智能机器人」里改。

![「机器人添加成功」：显示已绑定的数字人名称，以及「下一步」提示和明白了按钮](/images/digital-humans/wecom-bot/scan-success.zh.webp)

::: done
机器人回复说已把你绑定为主人，之后你发的消息数字人都会回复。在 **设置 › 消息通道** 里，这个机器人前面的圆点变绿，企业微信智能机器人卡片的标题显示「1 已连接」。
:::

## 交给已有的数字人 {#use-existing}

在设置里扫码，每次都会新建一位数字人。想让已有的数字人接机器人，二选一：

- 打开这位数字人，切到 **能力与设置**，在 **消息与通知 › 机器人访问权限** 里点 **扫码添加机器人 › 企业微信机器人**，扫码步骤同上。
- 在机器人卡片的 **回复 › 后端** 里改选别的数字人。会问「重新绑定此机器人？」，确认后原来的数字人不再收到这个机器人的消息。

一个机器人只能绑定一位数字人。

## 在群里使用 {#groups}

1. 把这个机器人加进企业微信群。
2. 在群里 @ 机器人再说话。企业微信只把 @ 机器人的消息转给它。
3. 它的回复默认会引用你那条消息（**引用回复（群聊）**），一看就知道在回答谁。

群里的人按主人和访客区分权限：主人能让它做任何事，访客默认只能聊天和使用记忆。机器人还没有主人时，在群里什么也不做，只提示先私聊它绑定主人。

## 回复设置 {#reply-settings}

在 **设置 › 消息通道** 里点开这个机器人，**回复** 里有：

| 设置 | 默认 | 作用 |
|---|---|---|
| **后端** | 扫码时新建的数字人 | 谁来回复：一位数字人，或团队里的一位成员 |
| **回复范围** | **所有消息** | **所有消息**：群里被 @ 和私聊都回复；**仅群聊**：私聊会被拒绝；**仅私信**：群消息不回复 |
| **流式传输** | 关 | 打开后，回复会边写边显示在一条消息里；关着时写完一次发出。群聊里要同时开着 **引用回复（群聊）** |
| **引用回复（群聊）** | 开 | 群里的回复引用它回答的那条消息。关掉后 **流式传输** 也会关掉 |
| **处理中提示** | 开 | 5 秒内还没回复时，先发「已收到，正在处理…」。**流式传输** 开着时，这句话直接出现在正在写的回复里 |

改动自动保存。

## 手动设置 {#manual-setup}

已经在企业微信里用 API 模式建好智能机器人、连接方式选的是长连接，并拿到了 **Bot ID** 和 **Secret** 时，可以手动接入：

1. 在 **设置 › 消息通道 › 企业微信智能机器人** 里点 **手动设置**，会加一个空的、未启用的机器人。
2. 在 **连接** 里填 **Bot ID**（以 `aib` 开头）和 **Secret**。**WebSocket URL** 保持默认。
3. 在 **回复 › 后端** 里选一位数字人。
4. 打开机器人右上角的开关，状态变成 **已连接** 就接好了。
5. 看一下 **权限** 里的 **权限控制**。它关着时显示「所有人都有完全访问权限」，任何给机器人发消息的人都能让数字人做任何事。建议打开，见 [主人与访客权限](/digital-humans/permissions)。

企业微信那边的创建步骤和菜单名称以企业微信为准，Halo 里没有对应的引导。

## 显示发消息人的真实姓名 {#sender-names}

企业微信新建的机器人会隐藏发消息人的身份，联系人只显示一串 ID。在 **连接** 的 **姓名解析 URL** 里粘贴企业微信给的授权链接后，Halo 就能查到真实姓名；授权 7 天有效，过期后要重新粘贴。步骤见 [企业微信显示真实姓名](/digital-humans/wecom-name-resolution)。

## 同一个机器人接在两台电脑上 {#standby}

企业微信同一时间只让一台电脑连着同一个机器人。另一台电脑上的 Halo 也接了它时，这台会让出连接，显示 **待机中** 和「在另一台设备上使用中」。想在这台电脑上用，点 **在此设备上使用**，另一台就转为待机。

## 限制 {#limits}

- 对方最后一条消息后 24 小时内，回复会引用原消息；超过 24 小时，回复和文件改为直接发出，不再带引用。
- 一条消息最多约 2 万字节，更长的回复会拆成几条。
- 发图片最大 10 MB，发文件最大 20 MB；超过 10 MB 的图片会当成文件发。
- 能收文字、图片、图文混排、语音（企业微信转好的文字）、文件和视频。

## 遇到问题 {#troubleshooting}

### 扫码后提示「设置失败」或「扫描失败」

点 **重试** 重新扫。还不行，可能是公司的企业微信不允许你创建智能机器人，或者网络连不上企业微信，问一下公司的企业微信管理员或网络管理员。

### 二维码提示「二维码已过期，请重新生成。」

二维码过期后，窗口会显示「设置失败」和这句提示。点 **重试**，会生成新的二维码。

### 私聊机器人没有回复

1. Halo 开着，卡片显示 **已连接**。显示 **已断开连接** 时，点机器人右上角的 **⋮ › 重新连接**。
2. **回复范围** 不是 **仅群聊**。
3. **后端** 选了数字人，没有显示「绑定已失效」。

更多情况见 [机器人不回复](/troubleshooting/channels)。

### 群里 @ 了机器人，它只回「该机器人尚未绑定主人，暂时无法执行任务。」

机器人还没有主人。先私聊它发一条消息，你就会成为主人。

### 提示「该机器人已被其他实例使用。每个机器人只能绑定一个数字人。」

这个 Bot ID 已经接在另一个机器人实例上了。改用那个实例，或者先把它删掉（**⋮ › 删除**）。
