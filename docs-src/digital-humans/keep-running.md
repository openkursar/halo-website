# 让数字人一直在线

数字人在你自己的电脑上干活，Halo 没有云端替它值班。所以「一直在线」靠的是两件事：电脑醒着，Halo 开着。这些是系统和 Halo 的设置，需要你自己调整，Halo 不能替你改。

## 需要满足的条件 {#requirements}

| 条件 | 说明 |
|---|---|
| 电脑开着、没有睡眠 | Halo 不会阻止电脑进入睡眠。要让数字人整夜工作，需要在系统设置里关掉自动睡眠 |
| Halo 在运行 | 在 macOS 和 Windows 上，关闭窗口不影响；在 Linux 上，关闭窗口就会退出 Halo |
| 能上网 | AI 模型、企业微信和飞书机器人都需要联网 |

电脑睡眠期间到点的定时运行，会在电脑醒来后补跑一次（错过好几次也只补一次）。Halo 退出期间到点的定时运行不会补跑，需要的话打开后点 **立即运行**。提醒不一样：Halo 退出期间到点的提醒，下次打开 Halo 时会补上一次。

## 关闭窗口和退出 Halo {#close-vs-quit}

- **macOS、Windows**：点窗口的关闭按钮，Halo 会留在后台，数字人、定时任务和远程访问照常工作。再打开一次 Halo 就能回到窗口。
- **Linux**：关闭窗口会退出 Halo，所有后台工作都会停下。需要后台运行时，不要关窗口，最小化即可。
- **彻底退出**：在托盘图标的菜单里选 **Quit Halo**（这个菜单只有英文）。有数字人在值班（设了运行计划或事件触发）或有任务在运行时，Halo 会先提醒你，退出会让它们停下。

## 开机自动启动 {#auto-launch}

打开 **设置 › 系统**，开启 **开机自动启动**（「系统启动时自动运行 Halo」）。电脑重启后，数字人会自己回到岗位上。

这个设置在 macOS 和 Windows 上有效，在 Linux 上不起作用。

## 后台完成时通知你 {#notifications}

- **设置 › 系统 › 任务通知**：开启后，后台任务完成时会通知你（默认关闭）。
- 每位数字人自己的 **系统通知**（在 **能力与设置 › 消息与通知** 里）：**重要**（默认，有里程碑、提问和产出时通知）、**全部**（每次运行结果都通知）、**无**。

Halo 窗口在前台时，通知显示在 Halo 里面；不在前台时，用系统通知提醒你。

## 不在电脑旁时查看进度 {#away}

- 用手机或别的电脑打开 Halo：见 [远程访问](/features/remote-access) 和 [在手机上用 Halo](/features/mobile)。
- 让数字人把结果发到企业微信、飞书或微信，问题也会私聊发给你：见 [消息通道概览](/digital-humans/channels)。

## 一个机器人只在一台电脑上用 {#one-computer}

- **企业微信**：同一个机器人在两台电脑上的 Halo 里都开着时，后连上的会占用连接，另一台会显示「在另一台设备上使用中」并进入待机。想换回来，点 **在此设备上使用**。
- **飞书**：同一个飞书应用不要在两台电脑上同时连接，否则消息会被随机分到其中一台。

## 需要真正 24 小时在线？ {#always-on}

如果团队有一台常开的服务器，可以在上面部署 Halo Server，让数字人不依赖个人电脑。部署方法见 [Halo Server 快速开始](/server/)，适合有一定技术基础的同事或 IT 来做。

## 遇到问题 {#troubleshooting}

### 第二天早上发现夜里的运行都没跑

多半是电脑睡眠了。在系统设置里关掉自动睡眠，或者让电脑在需要的时间保持唤醒。醒来后，错过的任务会补跑一次。

### 重启电脑后数字人没有工作

检查 **设置 › 系统 › 开机自动启动** 是否开着。在 Linux 上这个设置不起作用，需要手动打开 Halo。

更多情况见 [数字人没有运行](/troubleshooting/digital-humans)。
