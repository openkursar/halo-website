# 运行计划与触发方式

::: say
> 把「新闻助手」改成每个工作日早上 8 点运行。

Halo 会改好这位数字人的运行计划，并告诉你改成了什么。要在这位数字人所在的工作区里说。
:::

## 开始之前 {#before-you-start}

- 已经有一位数字人。还没有的话，先看 [创建数字人](/digital-humans/create)。

## 有哪些触发方式 {#trigger-types}

一位数字人可以同时用好几种方式开工：

| 方式 | 什么时候开始 | 在哪里设置 |
|---|---|---|
| [定时执行](#schedule) | 每隔一段时间，或在固定的时间点 | **能力与设置 › 触发器** |
| [机器人消息](#im-messages) | 有人给绑定的机器人发消息 | 绑定企业微信、飞书或微信机器人 |
| [立即运行](#run-now) | 你点按钮的时候 | 数字人页面右上角 |
| [提醒](/digital-humans/reminders) | 你在它的聊天里约好的时间 | 在聊天里说 |
| [HTTP 触发器](#http-trigger) | 别的程序发来请求 | **能力与设置 › 触发器** |
| [文件变化、Webhook](#events) | 工作区文件变化，或外部系统推送 | YAML（进阶） |

## 设置运行计划 {#schedule}

1. 点左侧栏的 **数字人**，打开这位数字人，切到 **能力与设置**。
2. 在 **触发器** 里打开 **定时执行**。
3. 选一种方式：
   - **按间隔**：从 1 分钟到 1 天的几个常用间隔里选一个，比如每 30 分钟、每 2 小时。
   - **按时间**：在 **重复** 里选 **每天**、**按周** 或 **按月**，再选 **时间**（小时和分钟）。按周时点 **工作日**，会一次选中周一到周五。
4. 改动马上生效，不用保存，也不用重启。

![触发器里的定时执行：选了按时间、每天，时间是 09:00，下方的「仅限中国大陆工作日」已经打开](/images/digital-humans/triggers/schedule-picker.zh.webp)

### 只在中国大陆工作日运行 {#working-days}

打开 **仅限中国大陆工作日**：遇到法定节假日不运行，调休上班的周末照常运行。用这个开关时，把重复设成 **每天**，节假日由日历来跳过。

- 这个开关只在界面语言是简体中文，或电脑时区在中国时显示。
- 节假日日历需要联网下载。日历没有覆盖到当天时，这次运行会被跳过，工作动态里会写明原因。

::: tip 「工作日」和「仅限中国大陆工作日」不一样
**按周** 里的 **工作日** 只是选中周一到周五，不管节假日。**仅限中国大陆工作日** 会按国家的放假和调休安排来跑。
:::

更复杂的时间规则（比如每月最后一个周五）在图形界面里只能看、不能改，要到 **能力与设置** 的 **YAML** 标签里编辑，见 [数字人 spec 参考](/developers/digital-humans/spec)。

### 运行时的几条规则 {#schedule-rules}

- 一次运行还没结束时又到了时间，这一次会被跳过，工作动态里会记下跳过了几次。
- 点了 **暂停自动任务** 后，定时运行全部停下；聊天、提醒和手动运行不受影响。
- 数字人有问题在等你回答时，到点的定时运行会被跳过；你回答后，那项工作接着做完，之后按计划照常运行。

## 让机器人消息叫醒它 {#im-messages}

数字人绑定了企业微信、飞书或微信机器人后，有人给机器人发消息，它就会接着处理，不需要设置运行计划。没有运行计划的数字人，在 **触发器** 的摘要里显示「手动 / IM 触发」。

绑定机器人的步骤见 [消息通道概览](/digital-humans/channels)。

## 立即运行 {#run-now}

在数字人页面右上角点 **立即运行**，它马上开始一次独立运行。正在运行或排队时按钮不可用；数字人暂停了自动任务时也可以手动运行。

## HTTP 触发器 {#http-trigger}

想让别的程序叫数字人干活：

1. 打开 **设置 › 远程访问**，开启 **启用远程访问**。没开时，HTTP 触发器会提示「远程访问已关闭」。
2. 在数字人的 **能力与设置 › 触发器** 里展开 **HTTP 触发器**。
3. 选地址类型：**本地**、**局域网** 或 **互联网**，点 **复制 curl 命令**。有局域网地址时才有 **局域网**；**互联网** 只在 **远程访问** 的互联网访问开着时出现。
4. 在别的程序里发送这个请求。请求要带远程访问的访问令牌，并且会等到这次运行结束才返回。

这个卡片只在桌面应用里显示命令。更多接口用法见 [HTTP API 概览](/developers/api/)。

## 文件变化和 Webhook {#events}

数字人也可以在文件新建、修改或删除时运行，或者在外部系统向 Halo 推送数据时运行。这两种只能在 YAML 里配置，适合有一定技术基础的用户，字段见 [数字人 spec 参考](/developers/digital-humans/spec)。

- 文件触发要把 `path` 设成它工作区里的某个文件夹：不设的话，Halo 正在监视的其他工作区里的文件变化也会触发它。
- Webhook 需要开启远程访问。

::: done
**触发器** 的摘要里显示了你设的运行计划，数字人页面头部能看到「下次运行」的时间。
:::

## 遇到问题 {#troubleshooting}

### 到点了没有运行

依次检查：

1. Halo 是否开着，电脑是否在睡眠。电脑睡眠期间到点的运行，会在电脑醒来后补跑一次（错过好几次也只补一次）；Halo 退出期间到点的运行不会补跑，需要的话打开后点 **立即运行**。
2. 数字人是不是 **已暂停**。点 **启用自动任务** 恢复。
3. 它是不是有问题在等你回答。到 **工作动态** 顶部或 **任务** 面板回答。
4. 开了「仅限中国大陆工作日」时，当天是不是节假日，或者日历没有下载成功。
5. 上一次运行是不是还没结束。

更多情况见 [数字人没有运行](/troubleshooting/digital-humans)。
