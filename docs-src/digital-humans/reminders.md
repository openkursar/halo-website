# 提醒

::: say
> 明天早上 9 点提醒我交周报。

> 每个工作日下午 5 点半提醒我写日报。

这两句要在数字人自己的聊天里说。数字人会告诉你提醒定在什么时候；到点后，它会在同一个聊天里接着说，比如告诉你该交周报了。
:::

## 开始之前 {#before-you-start}

- 提醒只能在数字人的聊天里设置，在普通的 Halo 会话里说，它会请你去找一位数字人。
- 新装的 Halo 在 **Halo 工作区** 里已经有一位「Halo AI 数字人模板」，可以直接用它来设提醒。

## 操作步骤 {#steps}

1. 打开一位数字人的聊天，任选一种：
   - 在 **会话** 列表的 **数字人** 分组里点它；
   - 在输入框点 **＋**，选 **与数字人聊天**，再选它；
   - 在左侧栏 **数字人** 里，把鼠标移到它的卡片上，点聊天图标。
2. 用平常的话说出时间和内容：一次性的（「一小时后」「明天 9 点」），或者重复的（「每天 9 点」「每个工作日 17:30」）。
3. 数字人回复提醒的时间，就设好了。

在企业微信、飞书或微信里和数字人聊天时也可以这样设，到点后提醒会发回那个聊天。

::: done
数字人回复了提醒的时间，并且在这位数字人的 **能力与设置 › 触发器 › 提醒** 里能看到这一条。
:::

## 查看和取消提醒 {#manage}

- 打开这位数字人，切到 **能力与设置**，在 **触发器** 里找到 **提醒**。每一条写着内容、时间、在哪个聊天里设的，以及是谁设的。点 **取消此提醒** 就能删掉。
- 也可以在设提醒的那个聊天里直接说：「我设了哪些提醒？」「取消明天的那个提醒。」

![数字人的触发器里的提醒列表：一条每周一 08:30 的提醒，写着下次时间和所在的主聊天，右边是取消按钮](/images/digital-humans/reminders/reminders-list.zh.webp)

## 规则和限制 {#limits}

| 项目 | 说明 |
|---|---|
| 时间 | 按这台电脑的本地时间；最远可以设到一年后 |
| 重复间隔 | 至少相隔 5 分钟 |
| 数量 | 每个聊天最多 20 条，每位数字人最多 100 条 |
| 暂停自动任务 | 不影响提醒，提醒照常到点 |
| 清空聊天记录 | 提醒保留；删除这个聊天或卸载数字人时，提醒一起删除 |
| Halo 没开着 | 到点时 Halo 没开或电脑在睡眠，下次打开后会补上一次 |
| 访客 | 机器人的访客不能设提醒 |

## 遇到问题 {#troubleshooting}

### 说了「提醒我」，它却说要去找数字人

你是在普通的 Halo 会话里说的。按上面的步骤打开一位数字人的聊天再说一次。

### 到点没有收到提醒

先确认 Halo 开着、电脑没有睡眠。在企业微信或飞书里设的提醒，如果机器人那时没连上，或者那个聊天已经不在回复范围内，这一次就不会送达。
