# 数字人团队

::: say
> 组个小团队：一个查资料、一个写稿、一个审稿，帮我出一份三款笔记软件的对比报告。

Halo 会在当前工作区组建一个临时团队，给每位成员分好工。会话下方会出现团队面板，显示每位成员在做什么；成员的汇报会出现在会话里，最后 Halo 把结果交给你。

**前提**：输入框 **＋ › 能力** 里的 **团队协作** 要开着。新会话默认是开着的。
:::

一个人包揽所有事，注意力有限；分工可以让每位成员只管一道工序，彼此交接、互相把关。Halo 的团队就是这样：几位数字人一起干活，你只负责定方向、做决定。

## 什么时候适合用团队 {#when}

- 任务能拆成几块并行做，比如分头调研几个对象。
- 需要不同角色，比如一人写、一人审。
- 需要互相检查的工作，比如核对数据和结论。

简单的任务直接在会话里做更快：团队里每多一位成员，就多一份模型用量。Halo 也只会在值得的时候组队。

## 两种团队 {#two-kinds}

| | 临时协作 | 长期团队 |
|---|---|---|
| 怎么来的 | 在会话里让 Halo 组队 | 在 **数字人 › 团队** 里新建，或者把一次临时协作保留下来 |
| 谁来协调 | 这个会话本身 | 团队自己的负责人 |
| 成员 | Halo 为这次任务新建的成员，最多 5 位 | 你的数字人，也可以加入同事电脑上的数字人 |
| 在哪里看 | 会话下方的团队面板，或右侧画布里的团队视图 | **数字人 › 团队** 里的团队工作台 |
| 定时运行 | 不能 | 可以 |

## 一句话组建临时协作 {#start}

1. 在会话里点输入框的 **＋**，确认 **能力** 里的 **团队协作** 是打开的。
2. 说出你要的结果，可以说明怎么分工，也可以交给 Halo 决定。
3. Halo 组好团队后，会话下方出现「团队：名称 · N/M 个工作中」面板，每位成员一行，显示状态和正在做的事。
4. 成员的汇报会以折叠的消息出现在会话里，标着成员和团队的名字，展开后能看到「由团队成员发送，而非您本人」。
5. 想看团队内部的完整对话，点面板上的 **打开团队视图**，它会在右侧画布里打开。

团队工作期间，你可以继续和 Halo 聊别的事。全部做完后，面板显示「已完成」。

### 成员需要你拍板时 {#decisions}

成员遇到团队定不了的事，会来问你。这时面板里它的状态会变成「等待你的决定」，打开团队视图就能看到问题并回答。

## 保留这个团队 {#keep}

用得满意，可以把临时协作保留成长期团队，以后接着用：

- 在团队视图顶部点 **保留此团队**；或者
- 直接对 Halo 说：「把这个团队保存下来，以后还用。」

![临时协作的团队视图：顶部右侧是「临时协作」标记和「保留此团队」按钮，中间是协作消息，右边是三位成员](/images/digital-humans/collaboration/team-view.zh.webp)

保留后，团队会出现在 **数字人 › 团队** 里。这次协作结束后，它就可以单独接任务、定时运行了。详见 [保存团队与定时运行](/digital-humans/saved-teams)。

::: warning 一个会话同时只有一个临时协作
在同一个会话里再组一个新团队时，上一个已经结束、但没有保留的临时协作会被解散，Halo 为它新建的成员也会一起删除。想留着，就先保留下来。
:::

## 把工作交给已保存的团队 {#delegate}

在会话里直接说：

> 让「竞品调研」团队再做一次，这次加上价格对比。

> 竞品调研团队现在进展如何？

Halo 会把任务交给那个团队的负责人，自己继续陪你聊；问进展时，它会汇总团队的任务、成果和在等你决定的事。这里只能用当前工作区里的团队。

## 同事的数字人也能加入 {#across-computers}

长期团队可以邀请同事带着他们自己的数字人加入，各自在自己的电脑上运行，数据留在各自电脑上。详见 [跨电脑团队](/digital-humans/cross-computer-teams)。

::: info 想让程序通过 HTTP 调用数字人？
用 Halo 的 HTTP API 让程序或别的系统调用数字人，见 [API 实用示例](/developers/api/recipes)。
:::
