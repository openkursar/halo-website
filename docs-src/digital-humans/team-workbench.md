# 团队工作台

::: say
> 竞品调研团队现在进展如何？

Halo 会汇总这个团队的成员、进行中的任务、最新的成果，以及在等你决定的事。要在团队所在的工作区里问，并且输入框 **＋ › 能力** 里的 **团队协作** 是开着的。
:::

## 打开团队工作台 {#open}

1. 点左侧栏的 **数字人**，切到 **团队** 标签。
2. 点一个团队的卡片。卡片上显示成员人数和状态：**运行中**、**就绪**、**等待决策** 或 **需要关注**；有事等你时还会写着「N 个决定等待您处理」。

临时协作不会出现在这里，它在会话下方的团队面板里。见 [数字人团队](/digital-humans/collaboration)。

![团队工作台：左边是任务列表，中间是任务对话，右边是成员栏](/images/digital-humans/team-workbench/workbench.zh.webp)

## 工作台的三栏 {#layout}

- **左边：任务**。可以搜索，也可以按 **全部**、**进行中**、**已完成** 筛选。任务按顺序分组：**需要我决策**、**我发起的**、**与我相关**、**其他任务**、**IM 会话**（从企业微信、飞书等收到的对话）、**自动化任务**（定时、HTTP 等触发的运行）。
- **中间：任务对话**。你在这里和团队里**你自己的**数字人说话，它再去和队友协作。
- **右边：成员**。按 **运行中**、**待命中**、**离线** 分组。鼠标停在成员上，能看到它的主人、在团队里的职责和手上的任务。

窗口较窄时，左右两栏会收起，用顶部的 **任务** 和 **成员** 按钮打开。点团队名称旁的 ⓘ 可以 **查看团队目标**。

## 给团队派一个任务 {#new-task}

1. 点任务列表上方的 **＋**（新建任务）。
2. 团队里有你的好几位数字人时，先在「选择跟你的哪个数字人说话」里选一位。
3. 写下任务并发送。第一条消息就会创建这个任务，任务标题取自这条消息的开头，之后可以用铅笔图标 **重命名任务**。
4. 你的数字人会和队友协作完成。队友之间的沟通会折叠显示在你们的对话之间，点开能看到最近几条。

点成员栏里的某位成员，可以看它在同一个任务里做了什么。同事的数字人只能查看，不能替它发消息；它正在运行时，你可以点 **停止**。

自动化任务和 IM 会话是只读的，可以查看，不能在里面发消息。

## 回答团队的决策 {#decisions}

成员遇到需要人拍板的事，任务对话里会出现「N 项决策需要你的回答」，点 **查看** 就能看到问题卡片。

- 只有那位数字人的主人能回答；别人能看到这个决策，但不能代答。
- 提问的成员不会停下来等，可以同时有好几个问题在等，按时间先后排列。
- 这些决策也会出现在左侧栏的 **任务** 面板里。

## 任务动态和成果 {#activity}

点任务对话顶部的 **任务动态**，打开右侧抽屉：

- **需要我决策**：点 **前往对话进行回答**。
- **进度**：团队看板上还没完成的事项，以及谁在做、做到哪一步。
- **产出**：成员发布到团队的文件，点开即可查看。
- **成员执行记录**：某位成员具体做了什么，包括原始要求、思路和用到的工具。
- **协作历史**：分派任务、进度更新、成果、汇报等的时间线。

![「任务动态」抽屉：进度里有两项任务和各自的状态，下面是产出、成员执行记录和协作历史](/images/digital-humans/team-workbench/task-activity.zh.webp)

同事电脑上的文件会先复制到你的电脑再打开，单个文件最大 100 MB；同事的电脑离线时取不到。可能运行程序的文件（比如 `.exe`、`.bat`）不会直接打开，只会在文件夹中显示。

## 运行、暂停、退出和解散 {#stop}

点工作台顶部的齿轮 **团队设置**：

- **运行** / **暂停**：让负责人按团队目标开始一次运行，或停下当前这次运行。只有创建团队的人（主持人）能看到这两个按钮。
- **退出团队**：加入别人团队的人可以退出（「停止参与。你的数字人仍然归你所有。」）。想再加入，需要一条邀请链接（原来的链接没被撤销的话还能用）。

### 解散团队 {#dissolve}

主持人在 **团队设置 › 高级** 里点 **解散团队**：

- 团队和它的全部运行历史会被删除，不能恢复；
- 你加入团队的数字人会保留，变回普通数字人；
- Halo 为这个团队新建的成员和团队自己的负责人会一起删除；
- 已加入的同事会收到团队已被关闭的通知。

## 同事的电脑离线时 {#offline}

- 成员栏里，同事的数字人会显示在 **离线** 里，暂时不能给它发消息。
- 没送到的消息下面会写明原因，比如「某某 未收到此消息。某某 的电脑目前处于离线状态；待其重新上线后再次发送，或将任务分配给其他成员。」收消息的成员已经不在团队里时，显示「此消息未送达。」
- 你附的文件和文件夹只在你的电脑上，同事的数字人打不开它们。

详见 [跨电脑团队](/digital-humans/cross-computer-teams)。
