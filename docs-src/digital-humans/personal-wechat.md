# 微信机器人

连接要你自己在 Halo 里点、用手机微信扫码，Halo 不能替你连接。

## 开始之前 {#before-you-start}

- 一个个人微信账号，手机上装着微信。
- 已经有一位放在工作区里的数字人，见 [创建数字人](/digital-humans/create)。
- Halo 开着。Halo 退出或电脑睡眠时，机器人不会回复，见 [让数字人一直在线](/digital-humans/keep-running)。

## 和企业微信、飞书机器人的区别 {#compare}

- **只能私聊**，不能拉进群。
- **没有权限控制**：能给它发消息的人都按主人对待，可以让数字人做任何事。只在自己用、或只给信得过的人用时连接。
- **不能边写边显示回复**，写完一次发出。

需要群聊或主人、访客的权限区分时，用 [企业微信智能机器人](/digital-humans/wecom-bot) 或 [飞书机器人](/digital-humans/feishu-bot)。

## 从数字人这边连接 {#connect}

1. 点左侧栏的 **数字人**，打开要接微信的数字人，切到 **能力与设置**。
2. 在 **消息与通知 › 机器人访问权限** 里点 **扫码添加机器人 › 微信机器人**，打开「添加微信机器人」。
3. 用手机微信扫二维码（「使用微信扫码连接」），在手机上确认。窗口先显示「等待确认中...」，再显示「连接中...」，连好后自动关闭，机器人出现在 **机器人访问权限** 的列表里。
4. 在微信里给机器人发一句话，数字人会回复。

二维码过期时显示「二维码已过期」，点 **重试** 换一个（在设置里连接时是 **刷新**）。

::: done
在微信里发出的消息，数字人回复了。在 **设置 › 消息通道** 里，这个机器人显示 **已连接**，微信机器人卡片的标题显示「1 已连接」。
:::

## 在设置里连接 {#from-settings}

1. 打开 **设置 › 消息通道**，找到 **微信机器人**，点 **添加机器人**。
2. 在新加的机器人里点 **连接微信**，用手机微信扫码并确认。
3. 在 **后端** 里选一位数字人。

![设置里的微信机器人：新加的机器人显示二维码（已打码）和「使用微信扫码连接」，下面是后端和处理中提示](/images/digital-humans/personal-wechat/connect.zh.webp)

## 断开连接 {#disconnect}

在机器人卡片里点 **断开连接**，机器人显示 **已禁用**。数字人不再收微信消息，连接凭证也会清除，下次要重新扫码。

## 限制 {#limits}

- 只能私聊。
- 一条消息最多 4,000 个字，更长的回复会拆成几条。
- 能收图片、语音（微信转好的文字）、文件和视频，单个文件最大 25 MB。
- 只能回复或主动发消息给最近给它发过消息的人。Halo 重启后，要对方先发一条消息，数字人才能再主动发给他。
- 微信那边的登录会过期。过期后机器人会停下，要重新扫码连接。

**处理中提示** 默认开着：5 秒内还没回复时，先发「已收到，正在处理…」。

## 遇到问题 {#troubleshooting}

### 机器人显示「未连接」或「已禁用」

- 「未连接」：微信那边的登录过期了。点 **连接微信** 重新扫码。
- 「已禁用」：有人点过 **断开连接**。同样点 **连接微信** 重新扫码。

### 数字人主动发的消息对方收不到

Halo 重启过，或者对方从没给机器人发过消息。请对方先给机器人发一条消息，之后就能正常发了。

更多情况见 [机器人不回复](/troubleshooting/channels)。
