# 数字人概述

Halo 的数字人是一位长期在岗的 AI 成员。你给它一份工作说明，它就按计划或按事件自己开工，有自己的记忆，做完会汇报，遇到需要你拍板的事会来问你。这里的数字人是会干活的 AI，不是做视频用的[虚拟形象](/seo/ai-digital-human)。

## 数字人和普通会话有什么区别 {#vs-conversation}

| | 普通会话 | 数字人 |
|---|---|---|
| 谁来开头 | 你发消息，它才回答 | 到点、来消息或有事件时，它自己开始 |
| 在哪里找它 | 左侧栏 **会话** | 左侧栏 **数字人** |
| 记忆 | 同一工作区的会话共享一份记忆 | 每位数字人有自己的记忆，跨次运行记住做过什么 |
| 和外部的联系 | 只在 Halo 里 | 可以接企业微信、飞书、微信，也能主动把结果发到群里 |
| 适合 | 一次性的任务：写文档、改代码、查资料 | 反复做的事：每日简报、定时巡检、答复同事、提醒 |

两者用的是同一个 AI，能力相同。区别在于数字人不用你守着：它有固定的工作说明，按自己的节奏干活。

## 它能帮你做什么 {#examples}

- 每个工作日早上 9 点，把行业新闻整理成 5 条要点，发到企业微信群。
- 每小时看一次竞品官网，价格有变化就告诉你。
- 在飞书里回答同事关于报销流程的问题。
- 每周一汇总上周的工单，生成一份 Excel。
- 在它的聊天里说一句「下午 3 点提醒我开会」，到点就提醒你。

更多按职业整理的例子见 [场景示例](/use-cases/)，也可以看看 [AI 数字员工](/seo/ai-digital-worker) 能做哪些重复的办公工作。

## 它怎么开始干活 {#how-it-runs}

一位数字人可以同时有几种开工方式：

- **按计划**：比如每天 9 点、每小时一次，或者只在中国大陆的工作日。见 [运行计划与触发方式](/digital-humans/triggers)。
- **来消息时**：绑定企业微信、飞书或微信机器人后，有人给机器人发消息，它就接着处理。见 [消息通道概览](/digital-humans/channels)。
- **你叫它时**：在它的页面点 **立即运行**，或者直接和它聊天。
- **提醒**：在它的聊天里让它提醒你，到点它会在同一个聊天里接着说。见 [提醒](/digital-humans/reminders)。

做完的结果会出现在它的 **工作动态** 里；需要你决定的问题会出现在 **任务** 面板和 **工作动态** 顶部，也可以推送到你的企业微信、飞书或微信。见 [运行记录与管理](/digital-humans/manage)。

数字人运行在你自己的电脑上，Halo 要开着它才能干活。在 macOS 和 Windows 上关掉窗口不影响；电脑关机或睡眠时就会停下。见 [让数字人一直在线](/digital-humans/keep-running)。

## 在哪里管理数字人 {#where}

点左侧栏的 **数字人**（悬停显示「数字人 · 扩展」）。页面上有三个标签：

- **我的数字人**：所有数字人按 **需要你处理**、**运行中**、**待命中**、**已暂停** 分组显示。
- **团队**：几位数字人组成的团队。见 [数字人团队](/digital-humans/collaboration)。
- **能力库**：数字人可以用的技能和 MCP 连接。

第一次打开 Halo 时，**Halo 工作区** 里已经有一位「Halo AI 数字人模板」。它没有运行计划，可以直接和它聊天、让它提醒你，也可以绑定机器人，或者改成你想要的样子。
