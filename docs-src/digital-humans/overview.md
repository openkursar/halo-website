# AI 数字人：7×24 小时自动运行的智能体

从 Halo v2.0 起，Halo 不再只是"一次性的 AI 对话工具"，而是一个可以长期运行 AI 个体的平台。

这些长期运行的 AI 个体，就是**数字人**。

---

## 数字人 vs 普通对话

| | 普通对话 | AI 数字人 |
|---|---|---|
| 运行方式 | 你发消息，AI 回复 | 在后台自主运行，7×24 |
| 上下文 | 单次对话结束即清除 | 长期记忆，跨天跨周持续 |
| 触发机制 | 人工输入 | 定时计划、事件触发、Webhook |
| 执行能力 | 完整 Agent 能力 | 完整 Agent 能力（相同） |
| 适合任务 | 即时问答、一次性任务 | 持续监控、周期性自动化 |

一句话：**普通对话是你雇佣的临时工，数字人是你雇佣的全职员工。**

---

## 数字人的能力构成

```
AI 数字人
├── 身份与记忆       → 持久化，跨次运行保持上下文
├── 触发机制         → 定时计划 / 文件变化 / Webhook / 网页监控
├── 执行工具         → MCP 服务器 / AI 浏览器 / Shell 命令
├── 输出渠道         → 系统通知 / 邮件 / 企业微信 / 飞书 / 钉钉
└── 用户配置项       → 关键词、URL、API Key 等参数
```

## 与 MCP、Skill、A2A 的区别

这几个概念容易混淆，一次说清楚：

| 概念 | 是什么 | 类比 |
|------|--------|------|
| **MCP** | AI 能调用的工具接口（查数据库、操作文件、调 API…） | 员工手里的工具箱 |
| **Skill** | 封装好的单一能力（发邮件、搜索、写报告…） | 员工会的一项技能 |
| **A2A**（Google） | Agent 之间通信的网络协议，解决"怎么传消息" | 员工之间的对讲机 |
| **AI 数字人（DHP）** | 完整的、独立运行的 AI 个体，拥有身份、记忆、目标、触发机制 | 员工本身 |

更直白地说：
- MCP 和 Skill 是"工具"，数字人是"使用工具的人"
- A2A 解决通信格式，DHP 解决"这个 Agent 是谁、它能做什么、怎么分发给所有人用"
- 数字人不是一次性的 prompt，它有持久身份、长期记忆、外部触发能力

## 典型场景

- **舆情监控**：每小时搜索品牌关键词，发现异常立即推送预警
- **代码评审**：监听 GitHub PR，自动完成代码质量检查并评论
- **日报/周报助手**：每天定时汇总工作进展并发送邮件
- **信息订阅**：追踪竞品动态、行业新闻，定期推送摘要
- **任务委托**：交给数字人一个长期目标，让它持续推进，你去做别的事
