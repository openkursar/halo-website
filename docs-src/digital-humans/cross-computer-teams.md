# 跨电脑团队

邀请和加入只能在界面里操作，Halo 不能替你生成邀请链接，也不能替你加入别人的团队。

## 开始之前 {#before-you-start}

- 你已经有一个长期团队，见 [保存团队与定时运行](/digital-humans/saved-teams)。临时协作不能邀请同事。
- 你和同事都用 Halo 桌面版，版本一致。加入团队只能在桌面版里操作。
- 同事至少有一位自己的数字人。
- 邀请和加入时，你的电脑开着 Halo。

## 同一网络，还是跨网络 {#federation-gateway}

同事的电脑要能连到你的电脑：

| 你们的情况 | 要做什么 |
|---|---|
| 都在同一个局域网（同一间办公室、同一个 Wi-Fi） | 在你的电脑上打开 **设置 › 远程访问**，开启 **启用远程访问** |
| 有人在别的网络（在家、在另一个城市或另一家公司） | 需要一个联邦网关在中间转发，在 **设置 › 远程访问 › 联邦网关** 里填它的地址，见 [部署联邦网关](/advanced/federation-gateway) |

- 官网下载的 Halo 没有内置网关，**联邦网关** 下面写着「如团队仅限局域网内使用，请留空。」。公司提供的 Halo 可能已经内置，这时显示「正在使用内置网关」。
- **远程访问** 里的 **互联网访问** 地址不会用在邀请链接里，跨网络只能靠联邦网关。

![设置 › 远程访问 里的联邦网关：一个地址输入框和保存按钮，说明文字写着「如团队仅限局域网内使用，请留空。」](/images/digital-humans/cross-computer-teams/federation-gateway.zh.webp)

## 邀请同事 {#invite-links}

1. 打开团队工作台，点顶部的齿轮 **团队设置**，点 **邀请**。
2. 在「邀请加入该团队」窗口里，选 **你邀请的人可以让你的数字人做什么**：**只读**、**读写文件** 或 **它通常可以执行的所有操作**。第一次邀请默认 **只读**，这个选择对你在团队里的所有数字人都有效。
3. 点 **复制链接**，用聊天软件、邮件等任何方式发给同事。

![「邀请加入该团队」窗口：最上面是邀请链接和复制链接按钮，下面是「你邀请的人可以让你的数字人做什么」的三个选项，右下角是撤销此链接](/images/digital-humans/cross-computer-teams/invite-dialog.zh.webp)

::: warning 有链接的人都能加入
窗口里写着「任何拥有此链接的人都可以将数字人带入该团队。」只把链接发给要邀请的人。发错了，点 **撤销此链接** 让它失效，需要时再点 **创建新链接**。
:::

每次打开 **邀请** 看到的都是同一条链接，重启 Halo 后也不变，直到你撤销它。不用联邦网关时，链接里是你电脑现在的局域网地址，这个地址变了，链接也会跟着变，要重新复制。

同事在浏览器里打开链接，会看到「某某 邀请你加入办公室」的页面，点 **在 Halo 中打开** 就会进入 Halo 的加入窗口。

## 加入同事的团队 {#join}

收到邀请链接后：

1. 在浏览器里打开链接，点 **在 Halo 中打开**。也可以在 Halo 里点左侧栏的 **数字人**，切到 **团队**，点 **加入团队**，把链接粘贴到 **邀请链接**。
2. 在 **带上你的数字人** 里选至少一位。还没有数字人时，点 **创建数字人**。
3. 选 **他们可以让它做什么**，默认 **只读**。
4. 看一下 **你的队友将看到的内容**：你的数字人工作时的思考过程、它用到的工具、它产出的文件名。同事不能直接访问你的电脑，但可以让你的数字人按你选的档位，在它的工作区里读取、查找内容并告诉他们；发布到团队的成果会复制到他们的电脑。
5. 勾选 **我理解，并且很乐意分享。**，点 **加入**。

![「加入团队」窗口：邀请链接输入框、可多选的「带上你的数字人」列表，以及「他们可以让它做什么」的三个选项](/images/digital-humans/cross-computer-teams/join-dialog.zh.webp)

你带去的数字人仍在你的电脑上、在它自己的工作区里运行。加入的团队里，团队设置只能查看；你能管的是自己的数字人，以及 [退出团队](#leave)。

::: done
团队出现在你的 **数字人 › 团队** 里。打开它，成员栏里能看到同事的数字人和你带去的数字人。
:::

## 同事能让你的数字人做什么 {#permissions}

邀请和加入时选的是大致的档位。要细调某位数字人，在 **团队设置 › 成员** 里点它，或在成员栏里点它的 **⋯ › 成员详情**，找到 **其他人可以要求它做什么**。

- 这些限制只管来自其他电脑的请求：同事的数字人请它帮忙，或者同事直接给它发消息。你自己用它、你自己的数字人之间协作，都不受限制。
- 来自其他电脑的请求始终可以用记忆，文件只能在这位数字人的工作区里读写（选 **它通常可以执行的所有操作** 时除外）。
- 显示「尚未单独设置：其他电脑上的人可以使用它的全部能力。」，说明它还没设过限制，建议现在设好。
- **操作 Halo** 不会借给同事。
- 同事的请求只限制它直接驱动的那一轮。你的数字人接着去找你自己的其他数字人帮忙时，那部分工作按你的权限运行。
- **它被要求做的事** 列出它替别人做过的每一步操作，以及被拒绝了几次。这份记录只保存在你的电脑上，不会分享给团队。
- 不想让队友给它安排定期检查，关掉 **允许队友给它设定期检查**。

## 数据留在哪里 {#data}

- 每位数字人都在主人的电脑上运行，文件留在各自的电脑上。
- 队友能看到的是：它的思考过程、用到的工具、产出的文件名，以及发布到团队的成果。
- 打开同事电脑上的成果时，文件会先复制到你的电脑，见 [团队工作台](/digital-humans/team-workbench#activity)。
- 用联邦网关时，团队内容经网关转发，网关不解析内容、不写入磁盘，见 [网关能看到什么](/advanced/federation-gateway#what-it-sees)。

## 有人离线时 {#offline}

- 同事的电脑离线后，它的数字人显示在成员栏的 **离线** 里，暂时不能给它发消息。刚断开一会儿时，会提示「某某 似乎暂时离开了——回复可能会有延迟。」
- 没送到的消息下面会写明「某某 未收到此消息。」和对方电脑的状态，处理办法见 [团队工作台](/digital-humans/team-workbench#offline)。

### 创建团队的电脑离线 {#host-offline}

团队的任务和看板由创建团队的电脑（主持人）保管。它离线后：

- 在线的电脑会自动推选一台接手，通常是最早加入的那台。推选要团队里过半数的电脑同意，所以不会同时出现两个主持人。接手后几秒钟，看板就能继续更新。
- 负责做事的成员已经不在的任务，会放回去等重新分派。
- 原来的主持人回来后会自动让位，团队记录不会分叉。
- 主持人自己的数字人（包括负责人）在它离线期间不能工作。接手保住的是团队的共享记录，不是那台电脑上的数字人。
- 和大多数电脑断开的一方会暂停修改，只能查看；重新连上后会提示「某团队 已恢复」和「自动重新连接——工作从上次中断处继续。」

## 退出团队 {#leave}

加入别人团队的人，在 **团队设置** 里点 **退出团队**，再点 **退出**：

- 你的数字人、它们的工作区和里面的内容都不受影响，重新完全归你。
- 删除的是这个团队在你电脑上的记录，以及队友给你的数字人设的定期检查。
- 想再加入，需要一条邀请链接（原来的链接没被撤销的话还能用）。

主持人也可以把你的数字人移出团队，这时你会收到「成员被主持人移除」；主持人解散团队时，你会收到「团队已关闭」。

## 遇到问题 {#troubleshooting}

### 点「邀请」提示「请在设置中开启远程访问，以便他人加入该团队。」

在你的电脑上打开 **设置 › 远程访问**，开启 **启用远程访问**。同事在别的网络时，改用 [联邦网关](#federation-gateway)。

### 同事看到「无法加入团队。请检查链接，并确认邀请你的人在线。」

依次检查：

1. 链接是否完整复制。
2. 你的电脑是否开着 Halo。
3. 你们是否在同一网络。浏览器打不开链接，多半是不在同一网络，或被公司防火墙、VPN 隔开了；跨网络需要 [联邦网关](#federation-gateway)。
4. 同事自己的网络是否正常。

### 提示「此邀请已失效——可能已过期、已被撤销，或团队已被关闭。请索取新的邀请链接。」

请邀请人重新复制一条链接，必要时点 **创建新链接**。

### 提示「该团队要求所有成员将 Halo 更新至最新版本」

点 **检查更新**，把 Halo 升到最新版本。团队里显示「某团队 需要更新」或「正在等待 某某 更新」时，是在等别的电脑升级。

### 提示「加入团队仅在桌面应用中可用。」

你是在手机或浏览器的远程访问里操作的。到装了 Halo 桌面版的电脑上加入。

### 提示「本机无法自动重新加入。请获取新的邀请以重新连接。」

请主持人再发一次邀请链接，重新加入。
