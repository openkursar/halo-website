# 主人与访客权限

这些设置要你自己在 **设置 › 消息通道** 里改，Halo 不能替你改。

## 主人和访客 {#owner-and-guest}

给机器人发消息的人分两种：

| | 主人 | 访客 |
|---|---|---|
| 是谁 | **主人用户 ID** 里填的人 | 其他所有人 |
| 能让数字人做什么 | 和你在 Halo 里用它一样，什么都能做 | 默认只能聊天和使用记忆；你可以再放开一些工具 |
| 能不能让它主动给别人发消息 | 能 | 默认不能（可以放开） |
| 能不能让它设提醒 | 能 | 不能 |
| 能不能回答它的提问 | 能，在私聊里直接回复 | 不能 |

权限控制只有 **企业微信智能机器人** 和 **飞书机器人** 有。微信机器人没有，每个发消息的人都按主人对待。

## 打开权限控制 {#turn-on}

1. 打开 **设置 › 消息通道**，点开要设置的机器人。
2. 打开 **权限控制**（企业微信机器人在 **权限** 里）。关着时显示「所有人都有完全访问权限」：任何给机器人发消息的人都能让数字人做任何事。
3. 在 **主人用户 ID** 里填主人的 ID，多个用逗号或换行隔开。不知道自己的 ID，就私聊机器人问「我的用户 ID 是什么」。

扫码添加的机器人会自动打开权限控制。

![机器人的权限设置：权限控制已打开，主人用户 ID 还空着，下方黄色提示「未设置所有者」](/images/digital-humans/permissions/permission-panel.zh.webp)

## 第一个私聊的人自动成为主人 {#auto-claim}

权限控制打开、**主人用户 ID** 还空着时：

- 第一个**私聊**机器人的人自动成为主人，机器人会回「✅ 已自动绑定你为本机器人的主人，拥有完整权限。」
- 在这之前，所有人都是访客，只能聊天和使用记忆。设置里会提示「未设置所有者。第一个向此机器人发送私信的用户将被绑定为所有者……」
- 群聊不会认领主人。没有主人的机器人在群里什么也不做，最多每 10 分钟提示一次「该机器人尚未绑定主人，暂时无法执行任务。」

::: warning 别让别人抢先
添加好机器人后，马上自己私聊它；或者先把自己的 ID 填进 **主人用户 ID**。
:::

## 给访客放开工具 {#guest-tools}

有了主人之后，下面会出现 **访客权限**：

1. 打开 **访客访问权限**。关着时显示「访客只能聊天和使用记忆」。
2. 在 **访客允许使用的工具** 里勾选要放开的工具。第一次打开时，默认只放开 **读取文件**、**查找文件** 和 **搜索内容**。

| 分组 | 工具 |
|---|---|
| **查看文件** | **读取文件**、**查找文件**、**搜索内容**，只限这位数字人的工作区 |
| **互联网** | **打开网页**、**网络搜索** |
| **其他** | **子任务** |
| **更改文件并运行命令**（**高风险**） | **写入文件**、**编辑文件**、**运行命令**（**无命令**、**仅限这些** 或 **任意命令**） |
| **AI 浏览器**、**电子邮件**、**Notifications**、**数字人**、**File Send**、**Text Extraction (OCR)**、**Terminal** | Halo 自带的能力，后面几个在中文界面里显示英文名。**Notifications** 让访客能让它主动给联系人发消息；**电子邮件**、**File Send** 和 **Terminal** 风险较高，谨慎放开。**Terminal** 只有在 **运行命令** 选了 **任意命令** 时才能打开 |
| **技能**、**你自己装的 MCP** | 这位数字人能用的技能，以及你装的 MCP 服务 |

记忆始终可用，不受这些设置影响。关掉再打开 **访客访问权限**，之前的勾选会恢复。

::: danger 「任意命令」等于把电脑交出去
选 **任意命令** 时会先问「允许任何命令？」：「访客将能够在你的计算机上运行任何命令，包括读取、更改或删除任何文件，不受空间限制。」选好后，设置里还会一直显示这条警告。除非群里都是你信得过的人，否则不要选。
:::

## 访客的其他限制 {#guest-limits}

- 访客默认不能让数字人主动给别的联系人发消息（放开 **Notifications** 后可以），始终不能设提醒，也拿不到 **操作 Halo** 的能力。
- 数字人发出的文件只能来自它的工作区或临时文件夹，对谁都一样。
- 群里主人和访客的消息被合在一起处理时，按访客的权限执行。
- 机器人背后是团队成员时，访客的请求在整个团队里都只有访客权限，队友替它做的事也一样。

## 谁能回答数字人的提问 {#questions}

数字人遇到要人决定的事，会私聊发给主人。主人直接在私聊里回复，或者在 Halo 里回答都行。团队在群聊里接手的工作卡住时，那个群会收到提示：「……的这项工作在等主人决定。主人可以直接回复机器人的私聊，或在 Halo 里回答。」访客不能代答。

没开权限控制时，问题会发给打开了 **自动同步运行结果** 的私聊联系人。

## 同事电脑上的请求 {#teammates}

跨电脑团队里，同事的数字人或同事本人发来的请求，用的是另一套设置：成员设置里的 **其他人可以要求它做什么**。见 [跨电脑团队](/digital-humans/cross-computer-teams#permissions)。

::: done
权限控制打开，**主人用户 ID** 里有你的 ID。别人私聊或在群里 @ 机器人时，数字人只用你给访客放开的工具。
:::

## 遇到问题 {#troubleshooting}

### 别人先私聊，成了主人

在 **主人用户 ID** 里删掉他的 ID，填上你自己的。

### 访客让数字人查文件，它说做不到

**访客访问权限** 没开，或者没勾选对应的工具。按 [给访客放开工具](#guest-tools) 设置。
