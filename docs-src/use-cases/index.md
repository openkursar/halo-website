# 场景示例

## 开始之前 {#before-you-start}

- 已经 [连接 AI 模型](/getting-started/setup-ai)。
- 下面的说法可以直接复制，把内容换成你自己的。需要附文件的，先点输入框左边的 **＋**，选 **文件和文件夹**。
- 标着「数字人」的，是让 AI 按计划自己干活，或者要在数字人自己的聊天里说，详见 [数字人概述](/digital-humans/overview)。

## 行政与办公 {#office}

| 想做的事 | 可以这样说 | 详见 |
|---|---|---|
| 整理会议纪要 | 把附件里的会议记录整理成会议纪要，列出决定事项和待办，每条待办写上负责人，做成 Word 文档 | [Office 文档](/features/office-documents#make-a-document) |
| 写通知 | 写一份下周三下午消防演练的通知，语气正式，控制在 300 字以内 | [完成第一个任务](/getting-started/first-chat) |
| 每周提醒（数字人） | 在数字人的聊天里说：每周五下午 4 点提醒我交周报 | [提醒](/digital-humans/reminders) |

## 运营与市场 {#marketing}

| 想做的事 | 可以这样说 | 详见 |
|---|---|---|
| 竞品对比 | 打开这三家竞品的官网，整理它们的价格和套餐，做成一张 Excel 对比表 | [AI 浏览器](/features/ai-browser) |
| 每天的行业简报（数字人） | 帮我建一个数字人：每个工作日早上 9 点，把前一天的行业新闻整理成 5 条要点 | [创建数字人](/digital-humans/create) |
| 写文章，有人审 | 组个小团队：一个人搜集资料，一个人写，一个人审核，帮我写一篇新品发布的推文 | [数字人团队](/digital-humans/collaboration) |
| 发到工作群（数字人） | 在数字人的聊天里说：以后每天的简报也发到「市场部群」（数字人要接好机器人、打开 **IM推送**，群里有人 @ 过这个机器人） | [消息通道概览](/digital-humans/channels#push) |

## 销售与客户 {#sales}

| 想做的事 | 可以这样说 | 详见 |
|---|---|---|
| 写跟进邮件 | 根据附件里的拜访记录，给每位客户各写一封跟进邮件的草稿 | [完成第一个任务](/getting-started/first-chat) |
| 查产品资料 | 先用输入框的 **知识** 按钮加载产品资料库，再问：根据产品手册，旗舰型号支持哪些接口？ | [知识库](/features/knowledge-base#use-in-conversation) |

## 财务与数据 {#finance}

## 一句话怎么说更好 {#tips}

- 说清要什么结果：做成什么格式、多少页、给谁看。
- 给齐材料：附上文件，或者说清在哪个文件夹。
- 说清什么时候问你：比如「不确定的地方先问我」。
- 一次说一件事：大任务可以说「组个团队」，让几位数字人分工。
