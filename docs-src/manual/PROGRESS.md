## 写作原则（每次运行必须遵守）
- 读者：完全不懂软件的普通人（律师、会计师等）
- 每步三要素：看哪里 → 做什么 → 做完后看到什么
- 用 ASCII 图示界面布局
- 绝不跳步，绝不假设读者有任何前置知识
- 每次聚焦 1-2 个小节写透，不铺开
