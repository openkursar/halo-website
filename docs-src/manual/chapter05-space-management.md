# 第五章：空间管理——给 AI 一个专属工作间

> 在前面的章节里，你已经学会了和 AI 对话。但你有没有发现，每次对话，AI 生成的文件都存在一个叫「Halo」的默认地方？如果你同时在做多件事——写一份报告、整理一个项目、帮同事整理资料——所有文件混在一起就会很乱。
>
> 这一章教你用「空间」把不同的任务隔离开来，就像给每件事分配一个独立的文件夹和一个独立的 AI 助手。

---

## 5.1 什么是「空间」

想象你有一张很大的办公桌。如果把所有项目的文件都堆在一起，找东西就很痛苦。所以你会给每个项目准备一个独立的文件盒——有自己的名字、有自己的文件、互不干扰。

Halo 里的**「空间」（Space）**就是这样的文件盒：

| 你在现实中会做的事 | 空间帮你做的事 |
|---|---|
| 给每个项目准备一个文件夹 | 每个空间有自己独立的文件存储位置 |
| 每个项目的笔记分开记 | 每个空间有自己独立的对话历史 |
| 不同项目的文件不混在一起 | AI 在空间 A 里生成的文件，不会出现在空间 B 里 |
| 可以同时推进多个项目 | 可以在多个空间之间来回切换，AI 在后台各自工作 |

本手册后面说「空间」，就是指这个概念。

---

## 5.2 两种空间：Halo 空间和专属空间

Halo 里有两种空间，它们的区别就像**公共会议室**和**私人办公室**：

### Halo 空间（公共会议室）

打开软件就有的默认空间，不需要你创建。适合：

- 随手问 AI 一个问题（「帮我算一下这个利率」）
- 做一些临时的小任务（「帮我翻译这段话」）
- 不需要保存文件的场景

就像走进公司的公共会议室，拿起白板就能用，用完走人。

### 专属空间（私人办公室）

你自己创建的空间，关联到电脑上的一个文件夹。适合：

- 需要 AI 帮你读写文件的项目（「帮我整理这个文件夹里的报表」）
- 长期维护的工作（「每周帮我更新这份分析报告」）
- 需要 AI 记住上下文的持续任务

就像你有一间自己的办公室，文件都放在固定的柜子里，AI 随时能找到。

> **什么时候该用哪种？**
>
> 问自己一个问题：**这件事需要 AI 操作文件吗？**
> - 不需要 → 用 Halo 空间
> - 需要 → 创建一个专属空间

让我们先看看空间在主页上长什么样。

打开 Halo 后，你会看到主页。主页分为两个大区域：

│  │ ┌───────────────┐ │ │  · 数字人A        │ │
│  │ │Ask me anything│ │ │  · 数字人B        │ │
│  │ │           ➤  │ │ │         Open →    │ │
│  │ └───────────────┘ │ └───────────────────┘ │
│  └───────────────────┘                       │
│                                              │

│                                              │

**上半部分**——两张并排的大卡片：

**下半部分**——标题写着「Dedicated Spaces」（专属空间）：
- 一个可以展开收起的指南条「Learn what spaces are」
- 你创建的所有专属空间卡片，两两排列
- 右上角有一个蓝色的「+ New」按钮

如果你还没创建过任何专属空间，下半部分只会显示一行小字：「No dedicated spaces yet」（还没有专属空间）。

## 5.4 认识空间指南条

在「Dedicated Spaces」标题下方，有一个带问号图标的横条：

```
┌─────────────────────────────────────────────┐
│ ❓ Learn what spaces are                 ▼  │
└─────────────────────────────────────────────┘
```

**操作方法**：把鼠标移到这个横条上，按下鼠标左键单击一次。

**做完后看到什么**：横条下方会展开一个信息面板，里面用三个小节解释了空间的概念：

```
┌─────────────────────────────────────────────┐
│ ❓ Learn what spaces are                 ▲  │
├─────────────────────────────────────────────┤
│ ⚡ What can AI do?                         │
│    Halo 不只是聊天，还能帮你做事...          │
│                                             │
│ 📁 What is a space?                        │
│    AI 生成的文件需要一个地方存放...           │
│                                             │
│ ❓ When do you need to create one?          │
│    随便聊聊 → 用 Halo 空间                  │
│    项目、长期任务 → 建议创建专属空间          │
│                                             │
│ ⚠️ AI has delete permissions                │
│    注意备份重要文件                           │
└─────────────────────────────────────────────┘
```

底部有一条黄色警告：**AI 有删除文件的权限**，提醒你备份重要文件。

> ⚠️ 注意：这条警告很重要。当你把一个文件夹关联为专属空间后，AI 不仅能读取和创建文件，**还能删除文件**。所以在把现有的重要文件夹关联为空间之前，建议先备份。

再次点击横条可以收起这个面板。Halo 会记住你的选择——如果你收起了，下次打开软件它还是收起的。

## 5.5 创建专属空间

### 第一步：点击「+ New」按钮

在主页的「Dedicated Spaces」区域，找到右上角蓝色的文字「+ New」。把鼠标移上去，单击一次。

**做完后看到什么**：屏幕中央会弹出一个对话框，顶部写着「Create Dedicated Space」（创建专属空间）。

```
┌───────────────────────────────────────┐
│ Create Dedicated Space                │
│                                       │
│ Icon (optional)                       │
│ [📁][💻][🌐][📊][📄][🎨]             │
│ [🎮][🔧][📱][💡][🚀][⭐]             │
│                                       │
│ Storage Location                      │
│ ○ Default Location                    │
│   ~/.halo/spaces/…                    │
│                                       │
│ ○ Custom Folder                       │
│   Select an existing project  [Browse]│
│                                       │
│ Name this space                       │
│ ┌───────────────────────────────────┐ │
│ │ My Project                        │ │
│ └───────────────────────────────────┘ │
│                                       │
│                    [Cancel]  [Create] │
└───────────────────────────────────────┘
```

这个对话框里有三个区域要填写，我们逐个讲解。

### 第二步：选择图标（可选）

对话框顶部有一排小方块，每个方块里是一个小图标（文件夹、电脑、地球、图表、文档、调色板、游戏手柄、扳手、手机、灯泡、火箭、星星）。

**操作方法**：如果你想给这个空间选一个容易辨认的图标，就用鼠标点一下你喜欢的那个小方块。被选中的方块会出现蓝色的边框。

**做完后看到什么**：被点击的方块会高亮显示（蓝色边框 + 浅蓝背景），之前选中的方块恢复原样。

> 这一步纯粹是装饰性的，帮你在多个空间之间一眼区分。跳过不选也完全没问题，默认是文件夹图标。

### 第三步：选择存储位置

这是最关键的一步。你需要选择「这个空间的文件放在哪里」。有两个选项：

**选项 A：Default Location（默认位置）**

选这个选项，Halo 会自动在自己的内部目录（`~/.halo/spaces/`）里创建一个新文件夹。

适合：你只是想要一个干净的独立空间，让 AI 在里面工作，**不需要关联已有的文件夹**。

**操作方法**：这个选项默认已经选中（左边的圆圈是蓝色的）。如果它已经选中，你不需要做任何操作。

**选项 B：Custom Folder（自定义文件夹）**

选这个选项，你可以把空间关联到你电脑上**已有的一个文件夹**。

适合：你已经有一个项目文件夹（比如 `D:\工作\Q2报表`），想让 AI 直接在这个文件夹里读写文件。

**操作方法**：

1. 点击「Custom Folder」那一行左边的圆圈，让它变成蓝色
2. 然后点击右侧的「Browse」按钮
3. 电脑会弹出一个标准的文件夹选择窗口（Windows 叫「浏览文件夹」，Mac 叫「打开」）
4. 在窗口中找到你想关联的文件夹，选中它，然后点「选择文件夹」（Windows）或「打开」（Mac）

**做完后看到什么**：「Custom Folder」选项下方会显示你选择的文件夹路径，比如 `~/工作/Q2报表`。同时，如果你还没有填写空间名称，Halo 会自动把文件夹的名字填到名称输入框里。

### 第四步：输入空间名称

在「Name this space」（为这个空间命名）下面，有一个输入框，里面有灰色的占位文字「My Project」。

**操作方法**：把鼠标移到输入框里，单击一次（光标会闪烁），然后用键盘输入你想要的名字。比如输入「Q2 财务报表」。

> 如果你在上一步选了「Custom Folder」并且选了一个文件夹，这个输入框里可能已经自动填入了文件夹的名字。你可以修改它，也可以保持不变。

### 第五步：点击「Create」

确认以上三个区域都填好后，看对话框右下角，有两个按钮：

- 左边灰色的「Cancel」——放弃创建，关闭对话框
- 右边蓝色的「Create」——确认创建

**操作方法**：把鼠标移到蓝色的「Create」按钮上，单击一次。

**做完后看到什么**：

1. 对话框消失
2. 主页的「Dedicated Spaces」区域出现了一张新的空间卡片
3. 卡片上显示你刚才输入的名字和选择的图标

> ⚠️ 注意：如果你没有填写空间名称（输入框是空的），「Create」按钮会变成灰色，点不了。必须先输入名字才能创建。

---

## 5.6 进入空间

创建好空间后，你需要点进去才能开始使用。

### 进入 Halo 空间

在主页上半部分，找到左边那张写着「Halo」的大卡片（带有 ✨ 图标）。把鼠标移上去，单击一次。

**做完后看到什么**：屏幕切换到聊天界面（和第四章介绍的一样），左上角显示 ✨ Halo 字样。

### 进入专属空间

在主页下半部分的「Dedicated Spaces」区域，找到你要进入的那张空间卡片。卡片上显示了空间的图标、名字、以及最后活跃时间（如「Today active」「3 days ago active」）。

**操作方法**：把鼠标移到那张卡片上（卡片会轻微变色表示可以点击），然后单击一次。

**做完后看到什么**：屏幕切换到聊天界面，左上角显示这个空间的图标和名字。你现在可以开始和 AI 对话了，AI 会在这个空间关联的文件夹里工作。

---

## 5.7 在空间之间切换

当你进入一个空间后，不需要每次都回到主页才能切换到另一个空间。Halo 在聊天界面的左上角提供了一个快速切换的入口。

### 第一步：找到空间选择器

在聊天界面的左上角，有一个显示当前空间名字的小按钮，右边带一个小三角箭头 ▼：

```
┌──────────────────────────────────────────────┐
│ [📁 Q2报表 ▼]  ···                    ⚙️     │
├──────────────────────────────────────────────┤
│                                              │
│              （对话区域）                      │
│                                              │
└──────────────────────────────────────────────┘
  ↑ 这里就是「空间选择器」
```

### 第二步：打开下拉列表

**操作方法**：把鼠标移到左上角那个空间名字上，单击一次。

**做完后看到什么**：名字下方弹出一个下拉列表，里面列出了你所有的空间：

```
┌──────────────────────────┐
│ ✨ Halo Space             │  ← Halo 空间永远排第一
│ 📁 Q2 财务报表        ●  │  ← 当前所在的空间有蓝点
│ 💡 年度分析              │
│ 🚀 竞品调研              │
├──────────────────────────┤
│ ⚙ Manage Spaces          │  ← 回到主页管理空间
└──────────────────────────┘
```

每一行前面都有空间的图标和名字。当前正在使用的空间后面会有一个小蓝色圆点标记。

### 第三步：选择要切换到的空间

**操作方法**：在下拉列表中，找到你想切换到的空间，把鼠标移上去（那一行会轻微变色），然后单击一次。

**做完后看到什么**：

1. 下拉列表消失
2. 左上角的名字变成了你刚选择的空间的名字
3. 对话区域切换到新空间的聊天记录

> ⚠️ 切换空间时，你在前一个空间里正在进行的 AI 任务**不会中断**。如果 AI 正在帮你写文件，你可以放心切走——它会在后台继续工作。这就是 Halo 的**并行工作**能力，详见 5.10 节。

### 快速回到主页

下拉列表最底部有一行小字「Manage Spaces」，前面有一个齿轮图标。点击它可以直接回到主页，管理所有空间（创建新空间、编辑、删除）。

## 5.8 编辑空间（改名和换图标）

创建空间之后，你可能想改一下名字或者换一个图标。

### 第一步：找到编辑按钮

回到主页（通过空间选择器下拉列表底部的「Manage Spaces」，或者直接点击顶部 Halo 图标回到主页）。

在「Dedicated Spaces」区域找到你想编辑的空间卡片。把鼠标移到卡片上。

**做完后看到什么**：卡片右上角会出现两个小图标（平时是隐藏的，只有鼠标悬停时才会出现）：

```
┌───────────────────────────────┐
│ 📁 Q2 财务报表      [✏️] [🗑️] │  ← 鼠标悬停后出现
│ Today active                  │
└───────────────────────────────┘
```

- 左边的铅笔图标 ✏️——编辑空间
- 右边的垃圾桶图标 🗑️——删除空间（下一节讲）

### 第二步：点击铅笔图标

**操作方法**：把鼠标移到铅笔图标上，单击一次。

**做完后看到什么**：屏幕中央弹出一个「Edit Space」（编辑空间）对话框：

```
┌───────────────────────────────────────┐
│ Edit Space                            │
│                                       │
│ Space Name                            │
│ ┌───────────────────────────────────┐ │
│ │ Q2 财务报表                       │ │
│ └───────────────────────────────────┘ │
│                                       │
│ Icon                                  │
│ [📁][💻][🌐][📊][📄][🎨]             │
│ [🎮][🔧][📱][💡][🚀][⭐]             │
│                                       │
│                    [Cancel]   [Save]  │
└───────────────────────────────────────┘
```

### 第三步：修改名字或图标

- **改名字**：点击「Space Name」下方的输入框，用键盘删除旧名字，输入新名字
- **换图标**：在图标区域点击你想换的那个小方块

### 第四步：保存修改

**操作方法**：看对话框右下角，点击蓝色的「Save」按钮。

**做完后看到什么**：对话框消失，主页上那张空间卡片的名字和图标已经更新了。

> 如果你改完不想保存，点左边灰色的「Cancel」即可退出，不会有任何改动。

## 5.9 删除空间

当你不再需要某个专属空间时，可以把它删除。

### 第一步：找到删除按钮

和编辑操作一样，回到主页，在「Dedicated Spaces」区域找到你想删除的空间卡片，把鼠标移到卡片上。

卡片右上角出现两个小图标后，找到右边的**垃圾桶图标** 🗑️。

### 第二步：点击垃圾桶图标

**操作方法**：把鼠标移到垃圾桶图标上，单击一次。

**做完后看到什么**：屏幕上弹出一个系统确认对话框。根据空间类型不同，提示信息也不同：

**情况 A——关联了自定义文件夹的空间：**

> "Are you sure you want to delete this space?
>
> Only Halo data (conversation history) will be deleted, your project files will be kept."
>
> （你确定要删除这个空间吗？只有 Halo 的数据（对话历史）会被删除，你的项目文件会保留。）

**情况 B——使用默认位置的空间：**

> "Are you sure you want to delete this space?
>
> All conversations and files in the space will be deleted."
>
> （你确定要删除这个空间吗？空间里的所有对话和文件都会被删除。）

### 第三步：确认或取消

- 点击「确定」（或「OK」）：空间被删除，从主页上消失
- 点击「取消」（或「Cancel」）：什么都不会发生

> ⚠️ 重要区别——请务必理解：
>
> - 如果你创建空间时选了**「Custom Folder」**（关联了你电脑上的文件夹）：删除空间只会清除 Halo 的对话记录和配置，**你的文件不受影响**。你电脑上那个文件夹还在。
> - 如果你创建空间时选了**「Default Location」**（使用 Halo 默认目录）：删除空间会把空间里的**所有文件和对话记录一起清除**。

> ⚠️ 删除操作不可撤销。如果删错了，对话记录无法找回。建议删除前确认一下空间里没有重要的、只存在于 Halo 默认目录中的文件。

## 5.10 并行工作——多个空间同时运行

这是 Halo 与传统聊天工具最大的区别之一。

在 ChatGPT 或其他聊天工具里，你给 AI 一个任务后，必须等它做完才能继续。但在 Halo 里，**你可以切到另一个空间继续干别的事，之前的任务不会中断**。

### 怎么理解并行工作

想象你是一个经理，手下有多个助手。你不需要站在一个助手身边等他做完，再走到下一个助手身边。你可以：

1. 走到助手 A 的办公室，说：「帮我整理这份报表」
2. 不等他做完，走到助手 B 的办公室，说：「帮我写一份邮件」
3. 再走到助手 C 的办公室，说：「帮我搜集一下竞品信息」
4. 回来看看助手 A 做完了没有

在 Halo 里：
- 每个空间就是一个助手的办公室
- 「走到某个办公室」= 切换到某个空间
- 「不等他做完就走」= 切换到另一个空间，AI 在后台继续工作

### 实际操作示例

假设你同时在推进两件事：

**第一件事**：在「Q2 报表」空间里，你让 AI 帮你分析一份 Excel 文件。AI 回复「好的，我来分析」然后开始工作。

**你不需要等它做完。** 直接用左上角的空间选择器（5.7 节讲过），切换到另一个空间。

**第二件事**：在「竞品调研」空间里，你让 AI 帮你搜集某个产品的信息。AI 开始工作。

过一会儿，你再切回「Q2 报表」空间，AI 的分析结果已经出来了，显示在对话区域里。

### 怎么知道有多少任务在同时运行

Halo 左上角会显示当前有多少个任务正在并行执行。当你在多个空间里都给 AI 布置了任务时，这个数字会更新。

### 并行的限制

- 所有空间共享同一个 AI 密钥（即第零章配置的那个），所以并行任务越多，每个任务的速度可能会稍慢一些
- 空间之间**互相看不到**——空间 A 里的 AI 不知道空间 B 里发生了什么

## 5.11 数字人与空间的关系

如果你按照第二章创建了数字人，你可能会好奇：数字人和空间是什么关系？

每个数字人都关联了一个空间（在创建数字人时选择的）。数字人关联的空间里有两个重要的目录概念：

### 工作区（Workspace）

数字人**实际产出文件**的地方。AI 生成的代码、报告、下载的数据等都在这里。就是数字人绑定的那个空间文件夹。

你可以在数字人详情页的设置面板里，通过工作区旁边的文件夹图标，直接在电脑的文件管理器里打开这个目录（Windows 叫「资源管理器」，Mac 叫「访达」）。

### 记忆区（Memory Files）

数字人**保存运行记录**的内部目录。包括：
- `memory.md`：数字人跨次运行保留的记忆笔记（就像你的工作笔记）
- 运行历史：每次运行的日志

同样有「在文件管理器中显示」按钮可以快速打开。

> ⚠️ 在数字人详情页的「危险操作」区有一个「清空记忆」按钮。这个按钮**只清除记忆和运行历史**，不会删除工作区里的任何文件。所以不用担心误触会丢失数字人产出的文件。

## 5.12 实用建议：空间的组织方式

以下是一些适合金融行业用户的空间组织建议：

| 场景 | 建议的空间设置 |
|---|---|
| 日常临时提问（计算、翻译、查概念） | 不用创建空间，直接用 Halo 空间 |
| 某个季度的报表项目 | 创建专属空间 + 关联项目文件夹 |
| 每天帮你整理邮件的数字人 | 创建专属空间（用默认位置即可） |
| 学习新技能（如学 Excel 公式） | 不用创建空间，直接用 Halo 空间 |
| 团队共享的知识库整理 | 创建专属空间 + 关联共享文件夹 |
| 年度审计准备材料 | 创建专属空间 + 关联审计文件夹 |

**一个核心原则：一个项目一个空间，不混用。**

如果你把两个不同项目的文件放在同一个空间里，AI 可能会混淆，比如把项目 A 的数据写进项目 B 的报告里。

## 常见问题

### Q1：我创建空间时选了「Custom Folder」，但想换一个文件夹怎么办？

目前不能直接修改空间关联的文件夹。建议的做法是：删除这个空间（你的文件不会被删除），然后重新创建一个新空间，关联到正确的文件夹。

### Q2：我能不能让两个空间关联同一个文件夹？

技术上可以，但**不建议**这样做。两个空间的 AI 可能会同时修改同一个文件，导致冲突。一个文件夹只关联一个空间最安全。

### Q3：删除空间后，我的对话记录能恢复吗？

不能。删除是永久性的，对话记录无法找回。如果对话里有重要信息，建议在删除前先手动复制保存。

### Q4：主页上空间卡片显示的「3 days ago active」是什么意思？

这是最后一次使用这个空间的时间。比如「3 days ago active」表示你 3 天前最后一次在这个空间里和 AI 对话。它帮你快速判断哪些空间是最近在用的。

### Q5：空间越多会不会让软件变慢？

不会。空间只是 Halo 内部的一个组织方式，不占用额外的计算资源。你可以放心创建，不用担心性能问题。

### Q6：Halo 空间和专属空间里的 AI 能力有什么区别？

完全一样。两种空间里的 AI 能力相同，唯一的区别是：
- Halo 空间没有绑定固定文件夹，AI 操作文件时使用默认目录
- 专属空间绑定了一个文件夹，AI 直接在那个文件夹里工作

选哪种空间取决于你的使用场景，不影响 AI 的智能程度或可用功能。
