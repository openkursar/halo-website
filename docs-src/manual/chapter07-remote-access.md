# 第七章：随时随地用 Halo——远程访问

Halo 安装在你的电脑上，但你不一定总是坐在电脑前面。开会时想用手机查看 AI 的工作进度、下班后想在家里继续操控办公电脑上的 Halo——**远程访问**就是为这些场景设计的。

用生活中的例子来理解：你的电脑就像你的办公室，Halo 是办公室里的助手。**远程访问**相当于给办公室装了一个「远程门铃+门锁」——你在外面用手机按门铃（打开网页），输入密码（门锁），就能隔着玻璃窗指挥里面的助手干活。

本手册后面说到「远程访问」，就是指这个用手机、平板或其他电脑通过浏览器来操作你电脑上的 Halo 的功能。

---

## 7.1 远程访问能做什么

开启远程访问后，你可以在**任何有浏览器的设备**上操控你电脑上的 Halo，就像坐在电脑前面一样。

| 你在哪里 | 你用什么设备 | 你能做什么 |
|----------|-------------|-----------|
| 同一个 WiFi（如公司网络） | 手机、平板、同事的电脑 | 和 AI 对话、查看数字人状态、修改设置 |
| 任意地点（家里、出差） | 手机、平板、任意电脑 | 和上面完全一样（需要开启「互联网访问」） |

简单来说：**你的手机浏览器就变成了电脑上 Halo 的遥控器。**

> ⚠️ 注意：远程访问是 Halo **桌面客户端**独有的功能。你的电脑必须处于**开机且 Halo 正在运行**的状态，远程访问才能工作。如果电脑关机或 Halo 没有打开，手机上是打不开的。

---

## 7.2 两种访问模式

远程访问有两种模式，根据你的设备是否和电脑在同一个网络来选择：

**模式一：局域网访问**
- **适用场景**：你的手机/平板和电脑连的是**同一个 WiFi**（比如都在公司网络里）
- **特点**：开启即可使用，速度快，安全性高（数据不经过互联网）
- **类比**：就像在同一栋楼里，通过内部走廊（局域网）走到同事办公室

**模式二：互联网访问（公网隧道）**
- **适用场景**：你**不在电脑旁边**，比如在家里、在外出差、在路上
- **特点**：需要额外开启，约等待 10 秒生成公网地址，从任何地方都能访问
- **类比**：就像给你的办公室开了一个「远程视频通话」，不管你在哪里都能接入

**怎么选？问自己一个问题：**
> 「我的手机和电脑连的是同一个 WiFi 吗？」
> - **是** → 用局域网访问就够了
> - **不是**（或者不确定） → 需要开启互联网访问

## 7.3 打开远程访问设置页面

远程访问的所有设置都在 Halo 的**设置**页面里。让我们一步步找到它。

**第一步：打开设置**

在 Halo 界面的**顶部栏最右边**，找到那个看起来像**齿轮**形状的小图标 ⚙️，把鼠标移到上面，单击一下。

**做完后你会看到**：整个页面切换到设置界面。顶部栏变成 **← Settings** 的样式，下方分为左右两栏。

**第二步：找到「Remote Access」（远程访问）**

设置页面的左侧有一列菜单项，从上到下依次排列。往下看，找到一个带有地球图标的选项，文字写着 **Remote Access**（远程访问）：

```
设置页面左侧菜单：
┌────────────────────┐
│ 🤖 AI Model        │
│ 📨 Message Channels│
│ 🏪 App Store       │
│ 🎨 Appearance      │
│ 💻 System          │
│ ⌨️  Advanced        │
│ 🌐 Remote Access   │ ← 点击这里
│ ❤️  Recommend Halo  │
│ ℹ️  About           │
└────────────────────┘
```

把鼠标移到 **Remote Access** 上，按下鼠标左键单击一次。

**做完后你会看到**：右侧内容区域变成了远程访问的设置面板。面板顶部写着「Remote Access」，下面有一个黄色的安全警告框。

---

## 7.4 开启远程访问

远程访问默认是**关闭**的。你需要手动开启。

**第一步：阅读安全警告**

进入远程访问设置页面后，你首先会看到一个**黄色的警告框**：

```
┌───────────────────────────────────────────────────┐
│ ⚠️ Security Warning                                │
│                                                    │
│ After enabling remote access, anyone with the      │
│ password can fully control your computer            │
│ (read/write files, execute commands). Do not share  │
│ the access password with untrusted people.          │
└───────────────────────────────────────────────────┘
```

这段话的意思是：**开启远程访问后，知道密码的人可以通过 Halo 完全操控你的电脑（读写文件、执行命令）。不要把密码告诉不信任的人。**

> ⚠️ 重要安全提醒：远程访问的密码就像你家的钥匙。钥匙只能给自己人，绝不能随便发到群里或告诉不认识的人。如果你不确定该不该给某人密码，那就**不要给**。

**第二步：找到总开关**

在黄色警告框下方，你会看到一行文字和一个开关：

```
┌──────────────────────────────────────────────────┐
│ Enable Remote Access                    [  ○   ] │
│ Allow access to Halo from other devices          │
└──────────────────────────────────────────────────┘
       开关在这里 ──────────────────────→  ↑
       灰色 = 关闭状态
```

左边写着 **Enable Remote Access**（开启远程访问），下面一行小字写着「Allow access to Halo from other devices」（允许从其他设备访问 Halo）。

右边有一个**滑块开关**——灰色表示关闭，彩色表示开启。

**第三步：打开开关**

把鼠标移到右侧那个灰色的滑块开关上，按下鼠标左键单击一次。

**做完后你会看到**：
1. 开关从灰色变成**彩色**（蓝色或紫色，取决于你的主题设置）
2. 开关下方会**展开**出一块新的内容区域，显示访问地址和密码等信息

---

## 7.5 认识展开后的信息面板

开启远程访问后，开关下方会展开一个信息区域。这里有你需要的所有访问信息。让我们认识一下每一项：

```
┌──────────────────────────────────────────────────┐
│ Enable Remote Access                    [==●   ] │
│ Allow access to Halo from other devices          │
│                                                  │
│ ┌──────────────────────────────────────────────┐ │
│ │ Local Address    http://localhost:3456  Copy  │ │
│ │ LAN Address    http://192.168.1.100:3456 Copy│ │
│ │ Access Password  ••••••••  Show  Copy  Edit  │ │
│ │ Connected Devices              2 devices      │ │
│ └──────────────────────────────────────────────┘ │
│                                                  │
│ ──────────── Internet Access ─────────────────── │
│ │ Get public address via Cloudflare...          │ │
│ │                         [Start Tunnel]        │ │
│                                                  │
│ ──────────── Scan to Access ─────────────────── │
│ │        ┌──────────┐                           │ │
│ │        │ QR Code  │                           │ │
│ │        └──────────┘                           │ │
│ │  Scan the QR code with your phone to access   │ │
└──────────────────────────────────────────────────┘
```

从上到下分为三个区域：

**区域一：访问地址和密码**

| 项目 | 含义 | 用途 |
|------|------|------|
| **Local Address** | 本机地址（如 `http://localhost:3456`） | 在这台电脑自己的浏览器里打开 |
| **LAN Address** | 局域网地址（如 `http://192.168.1.100:3456`） | 在同一 WiFi 下的其他设备上打开 |
| **Access Password** | 访问密码（默认显示为 `••••••••`） | 打开网页后需要输入这个密码才能使用 |
| **Connected Devices** | 当前连接的设备数量 | 让你知道有多少设备正在访问（没有设备连接时不显示） |

每一行的右侧都有 **Copy**（复制）按钮，点击即可把对应内容复制到剪贴板，方便你粘贴到手机上。

**区域二：互联网访问（公网隧道）**

这是第二种访问模式的控制区域，7.7 节会详细介绍。

**区域三：二维码**

一个可以用手机扫描的二维码，扫描后自动打开访问地址。

## 7.6 用手机通过局域网访问

这是最简单、最常用的远程访问方式。前提是你的手机和电脑**连的是同一个 WiFi**。

**第一步：确保远程访问已开启**

按照 7.4 节的步骤开启远程访问。确认开关是彩色的，下方信息面板已展开。

**第二步：方法一——扫描二维码（推荐）**

在信息面板最下方，你会看到一个二维码图片，下面写着「Scan the QR code with your phone to access」（用手机扫描二维码访问）。

拿出你的手机，打开微信（或任何能扫码的 App），扫描这个二维码。

**做完后你会看到**：手机上自动打开一个网页，显示一个密码输入框。

**第二步：方法二——手动输入地址**

如果扫码不方便，你也可以手动操作：

1. 在电脑上，找到信息面板中的 **LAN Address**（局域网地址），点击右边的 **Copy** 按钮
2. 把复制的地址发到你的手机上（比如通过微信「文件传输助手」发给自己）
3. 在手机上点击这个链接，或者把它粘贴到手机浏览器的地址栏中打开

**做完后你会看到**：手机上打开一个网页，显示一个密码输入框。

> ⚠️ 注意：LAN Address 类似 `http://192.168.1.100:3456`，你的具体数字会不同，这是正常的。每台电脑在网络里的编号（IP 地址）都不一样，就像每栋楼的门牌号不同。

**第三步：输入密码**

在手机网页上的密码输入框中，输入你电脑上 Halo 显示的 **Access Password**（访问密码）。

密码怎么看？回到电脑上，在信息面板中找到 **Access Password** 那一行：
- 默认显示为 `••••••••`（隐藏状态）
- 点击右边的 **Show** 按钮，密码就会显示出来（如 `482619`）
- 点击 **Copy** 按钮，可以复制密码，再发到手机上粘贴

在手机上输入密码后，点击登录按钮。

**做完后你会看到**：手机上出现了 Halo 的完整界面。你可以像在电脑上一样和 AI 对话、查看数字人、调整设置。界面会自动适配手机屏幕大小。

---

## 7.7 开启互联网访问（公网隧道）

如果你**不在公司**（手机和电脑不在同一个 WiFi），需要开启「互联网访问」才能从外面连回电脑。

用类比来理解：局域网访问像是「在同一栋楼里走内部走廊」，而互联网访问像是「通过电话拨号连回办公室」。Halo 借助 Cloudflare 服务（一家全球知名的网络安全公司）帮你搭建一条**安全的通道**，让你在任何地方都能访问。

**第一步：找到「Internet Access」区域**

在远程访问设置面板中，往下看，你会看到一条分隔线，下方写着 **Internet Access**（互联网访问）。下面有一行灰色小字说明：「Get public address via Cloudflare (wait about 10 seconds for DNS resolution after startup)」——意思是通过 Cloudflare 获取公网地址，启动后大约等 10 秒。

**第二步：点击「Start Tunnel」按钮**

在 Internet Access 区域的右侧，有一个按钮，上面写着 **Start Tunnel**（开启隧道）：

```
┌──────────────────────────────────────────────────┐
│ Internet Access                                   │
│ Get public address via Cloudflare...              │
│                              [  Start Tunnel  ]  │
└──────────────────────────────────────────────────┘
                                     ↑ 点击这个按钮
```

把鼠标移到 **Start Tunnel** 按钮上，按下鼠标左键单击一次。

**做完后你会看到**：
1. 按钮文字变成 **Connecting...**（连接中），表示正在建立通道
2. 等待大约 10 秒后，按钮下方出现一个**绿色方框**，显示你的公网地址

```
┌──────────────────────────────────────────────────┐
│ Internet Access                                   │
│ Get public address via Cloudflare...              │
│                              [  Stop Tunnel  ]   │
│                                                   │
│ ┌──────────────────────────────────────────────┐ │
│ │ 🟢 Public Address                            │ │
│ │    https://xxxx-xxxx-xxxx.trycloudflare.com  │ │
│ │                                        Copy  │ │
│ └──────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

- **Public Address**（公网地址）：这是一个以 `trycloudflare.com` 结尾的网址
- 按钮变成了红色的 **Stop Tunnel**（停止隧道），表示隧道正在运行

**第三步：复制公网地址和密码**

1. 点击公网地址右边的 **Copy** 按钮，把地址复制下来
2. 回到上方的 Access Password 区域，也把密码复制下来
3. 把地址和密码通过安全的方式发到你的手机上（推荐发到微信的「文件传输助手」或者私人备忘录）

**第四步：在手机上打开**

在手机浏览器中打开复制的公网地址，输入密码，就能从任何地方访问你电脑上的 Halo 了。

> ⚠️ 重要安全提醒：公网地址 + 密码 = 你电脑的远程钥匙。**绝对不要**发到群聊、朋友圈或任何公开场所。只发给自己的设备，或者你完全信任的人。

---

## 7.8 修改访问密码

Halo 在开启远程访问时会**自动生成一个随机密码**（默认 6 位数字）。如果你觉得随机密码不好记，可以改成自己的密码。

**第一步：找到密码区域**

在远程访问信息面板中，找到 **Access Password** 那一行。右侧有四个小按钮：**Show**（显示）、**Copy**（复制）和 **Edit**（编辑）。

**第二步：点击 Edit 按钮**

把鼠标移到 **Edit** 按钮上，按下鼠标左键单击一次。

**做完后你会看到**：密码那一行变成了一个**输入框**，旁边有 **Save**（保存）和 **Cancel**（取消）两个按钮：

```
┌──────────────────────────────────────────────────┐
│ Access Password  [          ] [Save] [Cancel]    │
│                   ↑ 在这里输入新密码               │
└──────────────────────────────────────────────────┘
```

输入框里的灰色提示文字写着「4-32 characters」（4 到 32 个字符）。

**第三步：输入新密码并保存**

1. 在输入框中输入你想要的新密码（长度在 4 到 32 个字符之间）
2. 点击 **Save** 按钮

**做完后你会看到**：输入框消失，密码区域恢复为正常显示（`••••••••`），说明新密码已保存成功。

> ⚠️ 注意：修改密码后，**所有正在连接的设备**需要重新输入新密码才能继续使用。如果你正在用手机访问，修改密码后手机上会弹出重新输入密码的页面。

---

## 7.9 查看当前连接的设备

当有其他设备正在通过远程访问使用你的 Halo 时，信息面板中会显示连接数量。

找到信息面板中的 **Connected Devices**（已连接设备）那一行。右边会显示类似「**2 devices**」（2 台设备）的绿色文字。

```
┌──────────────────────────────────────────────────┐
│ Connected Devices              2 devices 🟢      │
└──────────────────────────────────────────────────┘
```

这个数字告诉你，当前有多少台设备正在远程使用你的 Halo。

> 💡 提示：如果没有任何设备连接，这一行**不会显示**（不是显示「0 devices」，而是整行隐藏）。所以看不到这行是正常的，说明当前没有其他设备在用。

---

## 7.10 关闭互联网访问（停止隧道）

如果你不再需要从外面访问 Halo，建议**关闭互联网访问**以提高安全性。

**操作方法**：在 Internet Access 区域，找到红色的 **Stop Tunnel** 按钮，点击一次。

```
                              [  Stop Tunnel  ]
                                     ↑ 红色按钮，点击停止
```

**做完后你会看到**：
1. 绿色的公网地址框消失
2. 按钮恢复为蓝色的 **Start Tunnel**

之前复制的公网地址将立即失效，任何人都无法再通过那个地址访问你的 Halo。下次需要时重新点击 Start Tunnel，会生成一个**新的**地址。

> ⚠️ 建议：不使用时关闭互联网访问。局域网访问（同一 WiFi）可以保持开启，因为局域网内的安全风险较低。

---

## 7.11 完全关闭远程访问

如果你完全不需要远程访问功能了，可以把总开关关掉。

**操作方法**：在远程访问设置面板顶部，找到 **Enable Remote Access** 右侧的彩色开关，点击一次。

**做完后你会看到**：
1. 开关从彩色变回灰色
2. 下方的所有信息面板（地址、密码、二维码等）全部收起消失
3. 所有正在连接的设备会立即断开

再次开启时，密码会**重新随机生成**。如果你之前设置了自定义密码，关闭后重新开启会变成新的随机密码，需要重新设置。

---

## 7.12 手机上的使用体验

通过远程访问在手机上打开 Halo 后，界面会自动适配手机屏幕。以下是你在手机上能做的事情：

| 功能 | 手机上能用吗 | 说明 |
|------|-------------|------|
| 和 AI 对话 | ✅ 可以 | 输入框在屏幕底部，体验和微信类似 |
| 查看数字人状态 | ✅ 可以 | 可以查看数字人运行记录 |
| 修改设置 | ✅ 可以 | 设置页面会自动适配手机宽度 |
| AI 浏览器 | ❌ 不可用 | AI 浏览器是桌面端独有功能，手机端不支持 |

支持的设备类型：
- **手机**：iPhone、安卓手机（自动适配移动端布局）
- **平板**：iPad 等（自适应布局，体验接近电脑）
- **其他电脑**：任何有浏览器的电脑（完整 PC 体验）

## 7.13 实用场景

以下是几个金融行业员工最可能用到远程访问的场景：

**场景一：下班回家继续工作**

下班前在电脑上开启互联网访问，把公网地址和密码发到自己手机上。回到家打开手机浏览器，继续让 AI 帮你整理报告、回复邮件。第二天到公司后关闭互联网访问。

**场景二：开会时查看 AI 进度**

在办公室 WiFi 下，用手机扫描二维码进入 Halo。开会时偷偷看一眼手机，查看 AI 有没有完成你布置的任务，或者发一条新指令让 AI 继续干活。

**场景三：给同事演示**

开启局域网访问后，让同事用他的电脑浏览器打开你的 Halo LAN 地址，输入密码，就能看到你的 Halo 界面。可以现场演示 AI 的能力，而不用在同事电脑上安装软件。

**场景四：出差期间操控数字人**

出差在外，发现数字人的设置需要调整。用手机打开 Halo，进入数字人的设置页面，修改提示词或运行计划，修改立即生效。

## 7.14 安全注意事项

远程访问让 Halo 变得更方便，但也带来了安全风险。以下几条务必记住：

**1. 密码不要外泄**

远程访问的密码相当于你电脑的远程钥匙。知道密码的人可以通过 Halo 读写你电脑上的文件、执行命令。只把密码发给**自己的设备**。

**2. 不用时关闭互联网访问**

局域网访问只在同一 WiFi 下有效，相对安全。但互联网访问（公网隧道）暴露在整个互联网上，不用时应该关闭。

**3. 每次公网地址不同**

每次开启公网隧道，Halo 会生成一个**新的随机地址**。这意味着就算有人知道了你上次的地址，关闭再重开后地址就变了，旧地址自动失效。

**4. 没有中心服务器**

Halo 的远程访问是**去中心化**的——你的数据直接在你的电脑和你的手机之间传输，不经过 Halo 公司的服务器。这意味着 Halo 公司看不到你的数据。

**5. 一个地址只控制一台电脑**

每台电脑有自己独立的远程访问地址。如果你有多台电脑都装了 Halo，需要分别记录每台电脑的地址和密码。

## 7.15 连接出了问题怎么办

如果远程访问不工作，按以下顺序排查：

**Check 1：电脑是否开机且 Halo 正在运行？**

远程访问依赖电脑上运行的 Halo。如果电脑休眠、关机或 Halo 被关闭了，远程访问就会断开。

- 解决方法：确保电脑处于唤醒状态，Halo 窗口或托盘图标可见

**Check 2：远程访问开关是否开启？**

打开 Halo 的 Settings → Remote Access，确认 Enable Remote Access 的开关是彩色的（开启状态）。

- 解决方法：如果开关是灰色的，点击开关打开

**Check 3：局域网访问——手机和电脑在同一 WiFi 吗？**

局域网访问只在同一个网络内有效。如果你的手机用的是流量（4G/5G）而不是 WiFi，局域网地址是打不开的。

- 解决方法：把手机连到和电脑相同的 WiFi，或者改用互联网访问（开启公网隧道）

**Check 4：互联网访问——隧道是否在运行？**

回到电脑上，查看 Internet Access 区域：
- 如果按钮显示 **Start Tunnel**（蓝色） → 隧道没开，需要点击开启
- 如果按钮显示 **Stop Tunnel**（红色）且下方有绿色公网地址 → 隧道正常
- 如果出现**红色错误提示**（如 `Tunnel connection failed`） → 网络问题，见下一步

**Check 5：隧道启动失败？**

如果隧道启动后出现红色错误提示，可能的原因：
- 公司网络限制了隧道连接（部分企业防火墙会阻止 Cloudflare 隧道）
- 电脑没有连接互联网

解决方法：
1. 确认电脑能正常上网（试试打开浏览器访问任意网站）
2. 点击 **Stop Tunnel** 关闭隧道，等几秒后重新点击 **Start Tunnel**
3. 如果反复失败，可能是公司网络策略限制，请联系公司 IT 部门咨询

**Check 6：密码输入正确了吗？**

在手机上输入密码时，注意：
- 密码区分大小写（如果你设置了自定义密码）
- 默认生成的数字密码没有空格
- 建议在电脑上点击 **Copy** 复制密码，再粘贴到手机上，避免手动输入出错

## 常见问题

**Q1：开启远程访问会不会很耗电脑资源？**

基本不会。远程访问的服务非常轻量，待机时几乎不占用 CPU 和内存。只有在有设备实际连接并操作时，才会产生和正常使用 Halo 一样的资源消耗。

**Q2：我关掉 Halo 窗口（点击 ×），远程访问还能用吗？**

取决于你的系统设置。Halo 通常在关闭窗口后会最小化到系统托盘（任务栏右下角），此时远程访问仍然有效。但如果 Halo 被完全退出（右键托盘图标选择退出），远程访问就会断开。

**Q3：多个人可以同时远程访问吗？**

可以。只要知道地址和密码，多台设备可以同时连接。你可以在 Connected Devices 处看到当前有几台设备在用。但请注意，所有连接者共享同一个 Halo 环境——这意味着大家能看到彼此发送的消息和操作。

**Q4：公网地址每次都会变吗？**

是的。每次关闭并重新开启公网隧道，都会生成一个新的随机地址。之前的地址立即失效。这实际上是一个安全特性——即使地址泄露，关闭再重开就安全了。

**Q5：手机上能不能用 AI 浏览器？**

不能。AI 浏览器（第六章介绍的功能）是桌面客户端独有的能力，远程访问的手机端不支持。但你仍然可以在手机上让 AI 做其他事情，比如对话、查资料、处理邮件等。

**Q6：远程访问和企微机器人有什么区别？**

两者都能在手机上操控 Halo，但方式不同：
| 对比项 | 远程访问 | 企微机器人 |
|-------|---------|-----------|
| 操作方式 | 在浏览器中看到完整 Halo 界面 | 在企微聊天窗口中发文字消息 |
| 功能范围 | 几乎所有 Halo 功能 | 仅限文字对话和数字人交互 |
| 适合场景 | 需要完整操控（改设置、看状态） | 简单问答和消息通知 |
| 前提条件 | 电脑上开启远程访问 | 配置企微机器人（第一章） |

简单来说：需要「完整操控」用远程访问，需要「快速问答」用企微机器人。两者可以同时使用，互不冲突。

**Q7：公司防火墙会不会阻止远程访问？**

局域网访问通常不受防火墙影响（因为数据只在内部网络传输）。但互联网访问（公网隧道）可能被公司防火墙阻止。如果隧道反复启动失败，请联系公司 IT 部门。
