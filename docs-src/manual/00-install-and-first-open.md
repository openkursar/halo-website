# 第零章：安装 Halo 并第一次打开

> 这一章帮你把 Halo 装到电脑上，第一次打开它，告诉它你的 AI 密钥，然后发出你的第一条消息。
>
> 全程不需要敲任何代码。每一步都告诉你：眼睛该看屏幕的哪里、鼠标该做什么动作、做完之后画面会变成什么样。

---

## 0.1 Halo 是什么？

### 用一个你熟悉的场景来理解

你可能用过微信、用过企业微信。现在再想象一个东西：

**一个住在你电脑里的全能助手。** 你用打字告诉它想做什么，它就帮你做——写文件、发邮件、查资料、整理表格、操作浏览器……甚至帮你 24 小时自动值班。

这个全能助手就是 **Halo**。

### Halo 和 ChatGPT 有什么不同？

你可能也用过 ChatGPT。ChatGPT 只能跟你聊天、回答问题。而 Halo 不一样——它不仅能聊天，还能**动手做事**：

| | ChatGPT | Halo |
|------|---------|------|
| 回答问题 | ✅ | ✅ |
| 帮你操作电脑上的文件 | ❌ | ✅ |
| 帮你发邮件 | ❌ | ✅ |
| 自动操作浏览器（填表、查信息） | ❌ | ✅ |
| 24 小时自动值班、定时执行任务 | ❌ | ✅ |
| 连接企业微信，自动回复消息 | ❌ | ✅ |

简单说：**ChatGPT 是一个只会说话的顾问，Halo 是一个能说能做的员工。**

### 几个词先认识一下

在后面的章节里，你会反复看到这几个词。现在先简单认识一下，看不懂也没关系，用到的时候会再详细解释：

- **Halo** —— 就是你要安装的这个软件。装完后它是电脑上的一个程序，像 Word 或微信一样双击就能打开
- **空间（Space）** —— Halo 里面的工作区。就像你电脑上的文件夹：不同的工作开不同的空间，互不干扰
- **数字人** —— Halo 里 24 小时自动运行的 AI 员工，可以定时做事、可以接收企业微信消息自动回复
- **AI 密钥（API Key）** —— 一串密码。Halo 需要拿着这串密码去调用 AI 大脑来回答你的问题

> 💡 **「AI 密钥」类比**：就像你坐出租车需要付钱一样，AI 也不是免费的。AI 密钥就是你预付的「出租车卡」，Halo 每次帮你做事就刷一次卡。卡里的钱用完了就需要充值。

## 0.2 下载 Halo 安装包

### 你需要准备什么

1. **一台电脑** —— Windows 电脑或苹果 Mac 电脑都行
2. **网络连接** —— 能上网就行

### 第一步：打开下载页面

1. 打开你电脑上的浏览器（Chrome 浏览器、Edge 浏览器、Safari 浏览器都行）
2. 在最上方那条长长的地址栏里，把里面的内容清空，输入下面这串地址，然后按键盘上的**回车键（Enter）**：

   ```
   https://hello-halo.cc
   ```

3. **做完之后你会看到**：网页打开后，出现 Halo 的官方网站。页面上会有一个醒目的**下载按钮**

> ⚠️ **注意**：如果你的网络打开这个网站比较慢，可以换一个地址试试：
> ```
> https://github.com/openkursar/hello-halo/releases/latest
> ```
> 这会打开一个叫 GitHub 的网站（全球最大的软件仓库），往下翻可以看到安装包文件列表。

### 第二步：选择适合你电脑的版本

**如果你用的是 Windows 电脑：**

- 找到文件名里带 `.exe` 的文件（比如 `Halo-x.x.x-setup.exe`），鼠标左键点它一次开始下载
- 下载完成后，你的电脑左下角或「下载」文件夹里会出现这个文件

**如果你用的是苹果 Mac 电脑：**

- 找到文件名里带 `.dmg` 的文件
- 苹果电脑有两种芯片，你需要选对：
  - **M 系列芯片（M1/M2/M3/M4）**：下载文件名带 `arm64` 的版本
  - **老款 Intel 芯片**：下载文件名带 `x64` 的版本

> 💡 **不知道自己的 Mac 是哪种芯片？**
> 点击屏幕最左上角的苹果图标  → 点「关于本机」→ 看到「芯片」一行，如果写的是「Apple M1/M2/M3/M4」就选 arm64 版本；如果写的是「Intel」就选 x64 版本。

## 0.3 安装 Halo

### Windows 电脑安装

1. 找到刚才下载的 `.exe` 文件（通常在「下载」文件夹里），**鼠标左键双击它**

2. 可能会弹出一个窗口写着「Windows 已保护你的电脑」或者「你要允许此应用对你的设备进行更改吗？」→ 点「**仍要运行**」或「**是**」

3. 出现安装向导界面 → 一路点「**下一步**」→ 最后点「**安装**」

4. **做完之后你会看到**：安装程序运行完毕，桌面上出现一个 Halo 的图标

> ⚠️ **Windows 重要提示**：安装过程中，如果弹出一个提示说需要安装 **Git Bash**，请点「**确定/安装**」。这是 Halo 在 Windows 上执行任务的必备工具。如果你的公司电脑不能联网下载，需要找 IT 同事帮你提前装好 Git for Windows。

### 苹果 Mac 电脑安装

1. 找到刚才下载的 `.dmg` 文件（通常在「下载」文件夹里），**鼠标左键双击它**

2. 屏幕上会弹出一个小窗口，里面有一个 Halo 图标和一个「Applications」文件夹图标

3. 用鼠标**把 Halo 图标拖到 Applications 文件夹图标上面**，松开鼠标

4. **做完之后你会看到**：小窗口可以关掉了。打开 Finder（访达）→ 点左边的「应用程序」→ 里面会出现 Halo

### Mac 首次打开的安全提示

苹果电脑第一次打开 Halo 时，可能会弹出一个提示：「无法验证开发者」或「Halo 已损坏」。这是苹果的安全策略，不是 Halo 有问题。

解决方法：

1. 点屏幕最左上角的**苹果图标** → 点「**系统设置**」（旧版系统叫「系统偏好设置」）
2. 在左边找到并点击「**隐私与安全性**」
3. 往下翻，你会看到一行字提到 Halo 被阻止打开 → 点旁边的「**仍要打开**」按钮
4. 可能需要输入你的电脑登录密码来确认
5. 再次双击打开 Halo，这次就能正常打开了

## 0.5 三种登录方式怎么选？

画面上列出的卡片，就是三种不同的方式让 Halo 连接到 AI 大脑。你只需要选**一种**就够了。

### 先看一张对比表

| 方式 | 适合谁 | 是否需要额外操作 | 费用模式 |
|------|--------|----------------|----------|
| Claude (OAuth) | 已有 Claude 账号的人 | 点一下就能登录 | 跟着 Claude 账号走 |
| GitHub Copilot | 公司已开通 Copilot 的人 | 需要去网页输入验证码 | 跟着 Copilot 订阅走 |
| 自定义 API | 公司有统一 API 密钥的人 | 需要手动填写密钥信息 | 按使用量付费 |

### 怎么判断该选哪个？

问自己三个问题（按顺序来，哪个先答「是」就选哪个）：

1. **你有 Claude 账号吗？**（就是能登录 claude.ai 网站的那个账号）
   - 是 → 选「Claude (OAuth)」，跳到 **0.6 节**
   
2. **你的公司给你开通了 GitHub Copilot 吗？**（不确定的话问 IT 同事）
   - 是 → 选「GitHub Copilot」，跳到 **0.7 节**

3. **你拿到了一串 API 密钥吗？**（通常是 IT 或领导给你的，长得像 `sk-ant-xxxxx` 这样一串乱码）
   - 是 → 选「自定义 API」，跳到 **0.8 节**

如果三个都答「不是」—— 你需要先去申请一个。最简单的方式是注册一个 Claude 账号，然后回来选第一个选项。

## 0.6 用 Claude 账号登录（OAuth 方式）

把鼠标移到写着「**Claude (OAuth)**」的卡片上，你会看到卡片稍微变色（表示鼠标已经对准了）。然后鼠标**左键单击一次**。

### 第二步：等待跳转

你有两种方式完成登录：

**方式一（推荐）：直接登录**

1. 点击那个**橙色的「打开登录窗口」按钮**
2. 会弹出一个新的小窗口，里面是 Claude 的登录页面
3. 在这个小窗口里输入你的 Claude 账号和密码，完成登录
4. 登录成功后，这个小窗口会自动关闭，Halo 主画面会自动跳转到主界面

**方式二：手动粘贴授权码**（如果弹出的小窗口打不开或者一片空白，用这种方式）

1. 看到「登录链接」旁边那串网址，点击旁边的「**复制**」按钮
2. 打开你的浏览器，粘贴这串网址到地址栏，按回车
3. 在浏览器里完成 Claude 登录
4. 登录成功后，浏览器页面上会显示一串**授权码**
5. 复制这串授权码
6. 回到 Halo，把授权码粘贴到「**粘贴授权码**」输入框里
7. 点击「**完成登录**」按钮

**做完之后你会看到**：Halo 画面切换，你来到了 Halo 的主页面。恭喜！你已经成功登录了。跳到 **0.9 节** 继续。

## 0.7 用 GitHub Copilot 登录

如果你选了画面上写着「GitHub Copilot」的那张卡片：

### 第一步：点击卡片

把鼠标移到写着「**GitHub Copilot**」的卡片上，鼠标**左键单击一次**。

### 第二步：看到验证码

**做完之后你会看到**：画面切换，中央出现以下内容：

```

画面上显示：
- 一个网址（`https://github.com/login/device`）
- 一个大号的**验证码**（比如 `ABCD-1234`）

1. 先记住或复制那个验证码（点旁边的「**复制**」按钮）

5. 登录后，页面上有一个输入框让你输入验证码 → 把刚才复制的验证码粘贴进去
6. 点击确认/继续

**做完之后你会看到**：浏览器页面显示授权成功。回到 Halo 软件，几秒钟后画面会自动跳转到 Halo 的主页面。跳到 **0.9 节** 继续。

### 第二步：逐格填写

下面一格一格教你填：

---

**第 1 格：服务商**

这个格子是一个下拉菜单，让你选择你的 AI 密钥是哪家公司提供的。

- 点击这个格子，会弹出一个列表，里面有很多公司的名字
- 最常用的是排在前面的几个：
  - **Claude (Anthropic) API** —— 如果你的密钥以 `sk-ant-` 开头，选这个
  - **OpenAI API** —— 如果你的密钥以 `sk-` 开头（没有 `ant`），选这个
  - **DeepSeek** —— 如果是国内的 DeepSeek 服务，选这个
  - **SiliconFlow（硅基流动）** —— 国内代理服务之一
  - **OpenRouter** —— 海外聚合服务
- 不确定选哪个？**问给你密钥的 IT 同事**，他们会告诉你

> 💡 **服务商 = 出租车公司**：还记得前面的出租车卡比喻吗？服务商就是出租车公司。不同公司的卡不通用，你得选对公司才能刷卡成功。

---

**第 2 格：API Key**

这是最重要的一格。把 IT 给你的那串密钥粘贴到这里。

1. 鼠标左键点击这个输入框一次（光标会在里面闪烁）
2. 按键盘上的 `Ctrl + V`（Mac 是 `Command + V`）把密钥粘贴进去
3. 格子里会显示一排小圆点（像密码一样隐藏起来了）
4. 如果你想核对粘贴的内容对不对，点格子右边的**眼睛图标**，密钥就会暂时显示出来

> ⚠️ **注意**：粘贴的时候，确保前后没有多余的空格。最常见的错误就是密钥前后多了一个看不见的空格。

---

**第 3 格：API URL（可选）**

大部分情况下，这一格**不用填**，留空就好。

只有以下情况才需要填：
- 公司有自己的 AI 代理服务器（IT 会告诉你地址）
- 你用的是第三方转发服务

> 💡 如果 IT 同事给你密钥的时候还给了一个「地址」或「URL」，就填在这里。如果只给了密钥没给地址，不用管这一格。

---

**第 4 格：模型**

这个格子用来选择 AI 的「大脑型号」。就像买车有高配低配，AI 也有不同档次的型号。

- 点击这个格子，弹出下拉列表
- **推荐选择**：`Claude Sonnet 4.6`（平衡性能和费用）
- 如果你不知道选什么，保持默认就好

| 模型名称 | 特点 |
|----------|------|
| Claude Opus 4.7 | 最聪明、最贵 |
| Claude Sonnet 4.6 | 聪明够用、价格适中（推荐） |
| Claude Haiku 4.5 | 速度最快、最便宜 |

### 第三步：测试连接

所有格子填完之后，别急着点「保存」，先测试一下能不能通：

1. 看到表单下方，左边有一个「**测试连接**」按钮，鼠标左键点它一次
2. 等几秒钟

**如果测试成功**：按钮旁边会出现一条**绿色的提示**，告诉你连接正常。

**如果测试失败**：会出现一条**红色的提示**，说明哪里填错了。最常见的原因：
- API Key 粘贴错了（前后有空格，或者漏了几个字符）
- 服务商选错了（比如你拿的是 OpenAI 的密钥，却选了 Anthropic）
- 公司网络有防火墙拦截（需要找 IT）

### 第四步：保存并进入

测试通过后，点击右边那个大大的「**保存并进入**」按钮。

**做完之后你会看到**：画面切换，你来到了 Halo 的主页面。恭喜！

画面上会出现一个**聚光灯效果**——整个屏幕变暗，只有 Halo 空间卡片被一圈亮光圈住，旁边有一个提示气泡：

### 各个部分是什么

**顶部栏（最上面一行）**

从左到右：
- **‹**（左箭头）：点一下回到主页面
- **空间名 ▾**：显示当前在哪个空间。点击可以切换到其他空间
- **+ 新对话**：开始一个新的对话（之前的对话不会丢失，保存在侧边栏里）
- **🔍**（放大镜）：搜索历史对话内容
- **模型名 ▾**：显示当前使用的 AI 模型。点击可以切换其他模型或 AI 提供商
- **⚙️**（齿轮）：打开设置

- 再点一下 → 面板收起来

> 💡 以后手册里说「**打开侧边栏**」，就是指点这个三条横线的图标。

**对话区域（中间的大片区域）**

这是你和 AI 聊天的地方。你发的消息和 AI 的回复会一条一条显示在这里。

**输入框（底部）**

输入框是一个带圆角的方框，里面分为上下两部分：
- **上半部分**：打字区域，写着「在这里输入你想说的话...」
- **下半部分**：一排工具按钮，从左到右依次是：
  - **[+]**（加号）：上传图片给 AI 看
  - **🌐 Web Control**：开启「AI 浏览器」功能（让 AI 帮你操作网页）
  - **⚛ Deep Thinking**：开启「深度思考」模式（让 AI 想更久、答更好）
  - **[发送 ↑]**（在最右边）：点击发送消息

**文件面板 📁（最右侧）**

当 AI 帮你创建了文件时，右侧会出现一个面板展示这些文件。如果还没有文件，这个区域是收起的。

## 常见问题

### Q1：我关掉 Halo 再打开，还需要重新登录吗？

不需要。登录信息会保存在你的电脑上，下次打开 Halo 直接进入主页面。

### Q2：我可以同时配置多个 AI 提供商吗？

可以。登录后，点击右上角的**齿轮图标**进入设置 → 点击左边的「**AI 模型**」→ 你会看到已配置的 AI 来源列表，下面有一个虚线边框的「**添加 AI 提供商**」按钮。你可以同时配置多个来源，在聊天时通过顶部的模型切换下拉菜单随时切换。

### Q3：我填的 API Key 安全吗？会不会被别人看到？

API Key 保存在你本机电脑上，Halo 不会把它上传到任何服务器。只有能登录你电脑的人才能看到。

### Q4：安装后桌面上没有出现 Halo 图标怎么办？

**Windows**：打开开始菜单（屏幕左下角的 Windows 标志），在搜索框里输入「Halo」，如果安装成功，会出现 Halo 的应用图标，点击即可打开。你也可以右键点击它选「固定到桌面」。

**Mac**：打开 Finder（访达），点左边的「应用程序」，找到 Halo 图标双击打开。想要更方便的话，打开后在屏幕底部的 Dock 栏右键点击 Halo 图标，选「在 Dock 中保留」。

### Q5：测试连接一直失败怎么办？

按以下顺序检查：

1. **密钥粘贴是否正确**：点眼睛图标显示密钥，看看前后有没有多余的空格，或者是否漏掉了几个字符
2. **服务商是否选对了**：拿着密钥问给你密钥的人，确认应该选哪个服务商
3. **网络能否访问**：打开浏览器试试能不能访问 `https://api.anthropic.com`（如果选的是 Anthropic）。如果打不开，可能是公司防火墙拦截了，找 IT
4. **密钥是否过期或额度用完**：登录对应平台（如 console.anthropic.com）检查密钥状态和余额

### Q6：我想换一个 AI 密钥或者换一种登录方式，怎么办？

点击顶部的**齿轮图标**进入设置 → 点击左边的「**AI 模型**」→ 你会看到当前配置的 AI 来源。你可以：
- 点击某个来源展开详情，点「**编辑**」修改密钥或设置
- 点「**删除**」删掉不需要的来源
- 如果是 OAuth 登录的，会显示「**退出登录**」
- 再通过下面的「添加 AI 提供商」按钮添加新的
