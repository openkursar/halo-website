# 更新 Halo

更新 Halo 这件事，Halo 里的 AI 帮不上忙，它没有更新自己的接口。按下面的方式操作即可。

## 自动更新 {#automatic}

Halo 开着时会自己检查新版本，你不用做什么。

| 什么时候检查 | 说明 |
|---|---|
| 启动后 5 秒 | 每次打开 Halo 都会查一次 |
| 每 60 分钟 | Halo 开着就一直按小时检查 |
| 电脑从睡眠中唤醒后 3 秒 | 睡眠结束后很快查一次 |
| 两次自动检查之间 | 至少间隔 5 分钟 |

1. 发现新版本后，Halo 在后台下载。检查和下载的过程中不弹任何提示，你可以照常工作。
2. 下载并准备好后，屏幕角落出现一条不会自动消失的提示，标题是「Halo X.Y.Z 新版本可用」（X.Y.Z 是新版本号）。正文列出这个版本的更新内容；没有更新说明时显示一句固定的话。
3. 点提示上的主按钮完成更新。按钮因系统而异：

| 系统 | 主按钮 | 没有更新说明时的正文 | 点了以后 |
|---|---|---|---|
| macOS | **立即重启** | 「重启只需几秒」 | Halo 退出，换成新版本后重新打开 |
| Linux | **立即重启** | 「重启只需几秒」 | 同上 |
| Windows（快速更新） | **立即重启** | 「重启只需几秒」 | 见 [Windows 快速更新](#windows-staged) |
| Windows（安装程序） | **立即安装** | 「Halo 即将关闭，安装程序将引导您完成后续步骤」 | Halo 关闭，跟着安装程序操作 |

4. 现在不方便？点 **稍后提醒我**。这个版本 6 小时内不会再提示你。到时间后，下一次检查会再弹出来。

- 已经下载好的更新，在你退出 Halo 时也会装上。只有 Windows 快速更新例外，它只在你点 **立即重启** 时生效。
- 更新会保留你的数据：工作区、会话记录、数字人都在原处。数据存放在哪里，见 [数据与配置位置](/advanced/config-paths)。
- 更新频道在安装包里就定好了，**设置** 里没有切换频道的开关。公开的正式版从 GitHub Releases 获取更新。

::: info
公司提供的 Halo 可能从公司自己的地址获取更新。
:::

## 强制更新 {#mandatory}

发布方可以把某个版本标为强制更新，通常是修复重要问题的版本。这个标记由发布方在更新信息里设置，你无法开关。

强制更新的提示和普通提示有三点不同：

- 没有 **稍后提醒我** 按钮
- 没有关闭按钮（×）
- 正文末尾多一句「此更新为强制更新，无法推迟」

你之前对这个版本点过的 **稍后提醒我** 也不再算数。提示会一直留着，直到你点 **立即重启** 或 **立即安装**；退出 Halo 时，下载好的更新同样会装上（Windows 快速更新除外）。

## 手动检查更新 {#check-manually}

想马上知道有没有新版本，不必等下一次自动检查：

1. 打开 [**设置**](/features/settings)，找到 **关于**。
2. **版本** 一行显示当前版本号和构建时间，例如 `3.0.4 (2026-10-17-1530)`。
3. 点这一行右侧的 **检查更新**。按钮文字会随进度变化：

| 按钮显示 | 含义 |
|---|---|
| **检查更新** | 还没开始，点它开始检查 |
| 「检查中...」 | 正在查询，按钮暂时不能点 |
| 「正在下载 X.Y.Z… N%」 | 发现新版本，正在后台下载，N 是下载进度 |
| 「正在准备 X.Y.Z…」 | 只在 Windows 快速更新时出现：正在后台解压新版本 |
| 「发现新版本: X.Y.Z」 | 已经准备好，同时会弹出更新提示。如果提示说无法自动更新，见 [遇到问题](#failures) |
| 「已是最新版本」 | 你用的就是最新版 |
| 「检查失败 — 点击重试」 | 这次没查成，点它再查一次 |

在 **设置 › 关于** 里手动检查，会清掉之前的 **稍后提醒我**，也不受「两次检查至少间隔 5 分钟」的限制。如果更新已经下载好，提示会重新弹出来。

macOS 上也可以从菜单检查：点菜单栏的 **Halo › Check for Updates...**（这个菜单只有英文）。从菜单检查不会清掉 **稍后提醒我**，稍后提醒期间不会弹出提示。Windows 和 Linux 上请用 **设置 › 关于** 里的 **检查更新**。

::: done
看到「已是最新版本」，或者弹出「Halo X.Y.Z 新版本可用」的提示，就说明检查完成了。
:::

## Windows 快速更新 {#windows-staged}

从 3.0 起，Windows 版的 Halo 会在后台把下一个版本下载并准备好。你点 **立即重启** 时，不再弹出安装程序。

- **后台准备**：下载后在安装目录里解压，**设置 › 关于** 显示「正在准备 X.Y.Z…」。这时你可以照常使用 Halo。
- **几秒完成**：点 **立即重启** 后 Halo 退出，一个小工具替换程序文件后重新打开 Halo。从点击到新窗口出现，实测约 8–12 秒。安装目录不变，桌面快捷方式和卸载程序照常可用。
- **自动回退**：如果新版本没能正常启动，Halo 会自动换回原来的版本并重新打开。这个出问题的版本以后会被跳过，Halo 会显示「已是最新版本」，直到有更新的版本发布。
- **中途被打断也没事**：替换过程如果被打断（例如电脑断电），下次打开 Halo 时会接着处理。
- **安全校验**：更新包带有签名，校验不通过就不会使用。
- **只用于正式版**：公开版的快速更新只覆盖正式版频道。预览版仍用安装程序更新。

快速更新在任何没把握的情况下都会悄悄改用安装程序，不会报错。例如更新工具缺失、签名校验不通过、磁盘空间不够、或连不上更新信息。这时提示上的按钮是 **立即安装**，跟着安装程序完成即可。

::: info
从 Halo 2.x 升级到 3.0，这一次仍然使用安装程序（**立即安装**），因为 2.x 还没有快速更新。装好 3.0 之后的更新才走快速更新。
:::

## macOS 和 Linux 的更新 {#macos-linux}

- **macOS**：Halo 在后台下载新版本的 `.zip` 包。点 **立即重启**，几秒后打开的就是新版本。
- **Linux**：Halo 是一个 `.AppImage` 文件，它会自己更新这个文件。点 **立即重启** 后生效。

两个系统上，下载好但还没重启的更新，都会在你退出 Halo 时装上。

## 预览频道 {#preview-channel}

如果 **设置 › 关于** 的版本号旁边有 **预览频道** 标签，说明你装的是预览版。预览版从预览频道接收更新，不会收到正式版频道的提示；在 Windows 上，预览版用安装程序更新。

预览版和正式版**共用同一个数据文件夹**（默认是 `~/.halo`），切换版本时工作区、会话和数字人都在。这也带来两点限制：

- **不能同时运行两个版本。** 一个版本开着时再打开另一个，会提示「已有另一个版本在运行」，并告诉你怎么退出正在运行的那个（它可能在托盘里）。
- **不能直接退回旧版本。** 较新的版本可能已经升级了数据格式。之后再用较旧的版本打开，会弹出「数据来自更新的版本」的对话框，并停止启动，以免损坏数据。对话框里有 **打开数据目录** 和 **退出** 两个按钮，文字语言跟随系统。这时请改用较新的版本；也可以从升级前自动留下的备份文件（文件名以 `.premigrate.bak` 结尾，保留最近 2 份）恢复。

数据文件夹的位置和备份文件说明，见 [数据与配置位置](/advanced/config-paths)。

## 旧系统继续使用 2.x {#older-systems}

Halo 3.0 不再支持部分旧系统。在这些电脑上，请继续使用对应的 2.x 版本：

| 系统 | 3.0 的要求 | 达不到要求时 |
|---|---|---|
| macOS | macOS 12 及以上（Apple 芯片或 Intel 芯片） | macOS 12 以下继续使用 Halo 2.x |
| Linux | 64 位（x64），glibc 2.34 及以上，例如 Ubuntu 22.04、Debian 12 或更新版本 | glibc 低于 2.34 继续使用 Halo 2.1.15 |
| Windows | Windows 10 及以上，仅 64 位（x64） | 没有 Windows ARM 版 |

完整的安装要求见 [安装 Halo](/getting-started/install#before-you-start)。

<!-- public:start -->
2.x 的最后一个版本是 2.1.15，安装包在 [GitHub 上的 Halo 2.1.15 发布页](https://github.com/openkursar/hello-halo/releases/tag/v2.1.15)。

::: tip 还在用 Halo 2.x？

## 遇到问题 {#troubleshooting}

### 提示「无法自动更新 — 您可以手动下载此版本」 {#failures}

新版本没能下载，或没能在后台准备好时，会出现这条警告提示，标题仍是「Halo X.Y.Z 新版本可用」。

1. 点 **前往下载**，打开这个版本的下载页。
2. 下载适合你系统的安装包，按 [安装 Halo](/getting-started/install) 的步骤覆盖安装。你的数据会保留。

暂时不想处理，可以点 **稍后提醒我**。强制更新的版本没有这个按钮。

### 「检查更新」显示「检查失败 — 点击重试」

这次检查没有成功，常见原因是网络连不上更新地址。确认网络正常后点它重试。

检查和下载更新只走系统代理，**设置 › 系统 › 代理** 里填的代理对更新不起作用。公司网络要经过代理才能上网时，请在操作系统里设置代理，见 [模型网关与代理](/advanced/gateway-and-proxy)。

### 别人已经用上新版本，我这里一直是「已是最新版本」

- Windows 上，如果某个版本快速更新后没能正常启动，Halo 已经自动退回旧版本，并会跳过那个版本，直到有更新的版本发布。等下一个版本发布后，Halo 会照常提示你更新。
- 你装的是预览版，或者对方装的是预览版。两个频道收到的版本不同，见 [预览频道](#preview-channel)。
- 你的系统低于 3.0 的要求，见 [旧系统继续使用 2.x](#older-systems)。

### 打开时提示「数据来自更新的版本」

你之前用较新的版本（例如预览版）打开过这份数据，现在换回了较旧的版本。改用较新的版本打开，处理方式见 [预览频道](#preview-channel)。
