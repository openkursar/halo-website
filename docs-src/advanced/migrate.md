# 换电脑迁移 Halo

Halo 没有单独的“整机导出”功能，但它的数据都在两个目录里。按下面的步骤拷贝过去，新电脑上的 Halo 就和原来一样：空间、对话、数字人、知识库、技能、MCP 和各项设置都在。

## 1. 先在旧电脑上退出 Halo

点击托盘（macOS 菜单栏）里的 Halo 图标，选择 **Quit Halo**，确认 Halo 已经完全关闭再开始拷贝，避免拷到写了一半的文件。

---

## 2. 拷贝这两个目录

| | macOS | Windows | Linux |
|---|---|---|---|
| **Halo 数据**（配置、空间与对话、数字人、知识库） | `~/.halo/` | `C:\Users\<用户名>\.halo\` | `~/.halo/` |
| **应用数据**（全局技能、AI 引擎的对话记录、内置浏览器数据） | `~/Library/Application Support/halo/` | `C:\Users\<用户名>\AppData\Roaming\Halo\` | `~/.config/halo/` |

两个目录都要拷：只拷 Halo 数据目录的话，旧对话的记录还在，但继续这些对话时，AI 会从新的上下文开始。

另外：如果某些空间用的是你自己的项目文件夹（工作目录不在 `.halo` 里），把这些文件夹也拷过去。

::: tip 品牌版 / 企业版
品牌版的目录名可能不同（例如 `.halo-enterprise`），以你电脑上实际存在的目录为准。
:::

::: warning 拷贝出来的文件里有密钥
Halo 数据目录里保存着你填写的 API Key、邮箱密码和 IM 机器人凭据。请妥善保管拷贝出来的文件，用完后删除中转副本，不要放到公开的网盘或仓库里。
:::

---

## 3. 在新电脑上放回原处

1. 安装 Halo（与旧电脑相同或更新的版本）。如果安装后已经打开过，先退出。
2. 把两个目录放到新电脑上的相同位置，覆盖新生成的同名目录。
3. 项目文件夹放到和旧电脑**相同的路径**下。
4. 打开 Halo，检查 AI 模型、空间、数字人和知识库是否都在。

::: warning 新电脑要用同一种系统和相同的用户名
Halo 记录的是每个空间的完整路径。新电脑请使用同一种操作系统和相同的用户名（用户目录路径不变），项目文件夹也放在原来的路径下；否则这些空间会显示为不可用。
:::

---

## 4. 需要重新登录的内容

- **内置浏览器里登录过的网站**：浏览器的登录状态和电脑绑定，搬过去后需要在 Halo 的浏览器里重新登录一次。
- **Claude Code CLI 登录（macOS）**：这种登录的凭据保存在系统钥匙串里，需要在「设置 → AI 模型」里重新登录。
- 其他 AI 来源、邮箱、IM 机器人的配置会一起带过去。如果某一项在新电脑上提示失效，到对应的设置里重新填写或登录即可。

---

## 5. 旧电脑怎么办

新电脑用起来以后，**不要让两台电脑同时运行同一套配置**：

- 同一个企微机器人同一时间只会在一台电脑上工作；同一个飞书机器人在两台电脑上同时连接时，消息会被随机分给两台电脑。
- 远程访问的固定地址会跟着配置一起搬到新电脑，旧电脑上不要再开启远程访问。

确认新电脑一切正常后，可以在旧电脑上卸载 Halo。卸载不会删除数据目录，如果不再需要，可以手动删除上面两个目录。

---

## 只想带走某个数字人

不需要整机迁移时，可以把单个数字人导出成安装包：

1. 旧电脑：打开这个数字人，点右上角的 **更多** → **分享** → **导出**，保存一个 `.dhpkg` 文件。
2. 新电脑：在 **我的数字人** 页点击 **创建数字人** → **导入**，选择这个文件。

安装包包含数字人的定义和它自带的技能，不包含对话记录、记忆、知识库内容和 IM 渠道的绑定。导入后需要在新电脑上重新连接 IM 渠道、勾选要用的知识库。
