# 换电脑迁移

Halo 没有“整机导出”按钮，但它的数据都在两个目录里。按下面的步骤拷过去，新电脑上的 Halo 就和原来一样：工作区、对话、数字人、团队、知识库、技能、MCP 和各项设置都在。

拷贝目录发生在 Halo 之外，这一步 Halo 帮不上，需要你自己操作。

## 要拷贝什么 {#what-to-copy}

| 目录 | 里面有什么 | macOS | Windows | Linux |
|---|---|---|---|---|
| **Halo 数据目录** | 设置和凭据（`config.json`）、工作区与对话、数字人、团队、知识库 | `~/.halo` | `%USERPROFILE%\.halo` | `~/.halo` |
| **应用数据目录** | AI 浏览器的数据、AI 引擎的对话记录、全局技能、Windows 上的 Git Bash | `~/Library/Application Support/halo` | `%APPDATA%\halo` | `~/.config/halo` |

- **两个目录都要拷。** 只拷 Halo 数据目录的话，旧对话的记录还在，但接着聊时，AI 会从新的上下文开始。
- **项目文件夹也要拷。** 如果某些工作区指向你自己的项目文件夹（不在 `.halo` 里），把这些文件夹一起带走，放法见 [路径要保持一致](#same-paths)。
- **用了 Claude CLI 默认配置目录的话**：在 **设置 › 高级 › Claude CLI 集成 › 配置目录** 里选了 Claude CLI 默认（`~/.claude`）时，AI 引擎的对话记录和全局技能在 `~/.claude` 里，这个目录也要拷。
- **改过数据目录位置的话**：如果你用环境变量 `HALO_DATA_DIR` 把 Halo 数据目录放在了别处，拷那个目录，并在新电脑上设置同样的变量。
- 公司定制版的 Halo 数据目录名可能不是 `.halo`，以你电脑上实际存在的目录为准。各目录的完整说明见 [数据与配置位置](/advanced/config-paths)。

::: warning 拷出来的文件里有明文密钥
公开版把 API Key、邮箱密码和 IM 机器人凭据以明文保存在 `config.json` 里，见 [密钥和凭据](/advanced/security#credentials)。用移动硬盘或局域网直接传，不要放到公开的网盘或代码仓库里；传完删掉中转副本。
:::

## 操作步骤 {#steps}

### 在旧电脑上

1. 退出 Halo。在 macOS 和 Windows 上，关窗口只会把 Halo 收到托盘，它还在运行。macOS 上点菜单栏里的 Halo 图标，Windows 上右键托盘里的 Halo 图标，选 **Quit Halo**。有后台任务在跑时会弹确认，确认后退出。
2. 确认 Halo 已经完全关闭，再拷贝 [上面的目录](#what-to-copy)。Halo 还开着时拷贝，可能拷到写了一半的文件。

在 Linux 上，关掉窗口就会退出 Halo。有的桌面环境看不到托盘图标，这是正常的。

### 在新电脑上

1. 安装 Halo，版本要和旧电脑相同或更新。装完如果自动打开了，先退出。
2. 把两个目录放到新电脑上的相同位置，覆盖新生成的同名目录。
3. 把项目文件夹放到和旧电脑相同的路径下。
4. 打开 Halo，检查 **设置 › AI 模型**、工作区、数字人和知识库是否都在。
5. 按 [需要重新登录的内容](#sign-in-again) 逐项检查。

::: done
打开工作区能看到原来的对话，接着发一条消息，AI 记得之前聊过的内容，就说明搬好了。
:::

## 路径要保持一致 {#same-paths}

Halo 记录的是每个工作区的完整路径，包括 Halo 数据目录里的工作区和指向项目文件夹的工作区。所以：

- **新电脑用同一种操作系统和相同的用户名**，让用户目录的路径不变。
- **项目文件夹放在原来的路径下。** 例如原来是 `~/code/app`，新电脑上也放到 `~/code/app`。

项目文件夹没法放回原路径时，工作区会显示 **不可用**，或者在对话里出现 **工作目录不可用** 卡片。改到新位置有两种办法：

- 在管理页卡片的 **⋮** 菜单里选 **编辑**，在 **工作目录** 旁点 **更改文件夹**，选文件夹的新位置。对话会保留历史和上下文。
- 在对话里的 **工作目录不可用** 卡片上点 **更改工作目录**，选新位置后再发一次消息。

两种办法都只能在桌面版里用，详细说明见 [工作目录不可用和已断开连接](/features/spaces#unavailable)。

## 需要重新登录的内容 {#sign-in-again}

大部分设置会跟着 `config.json` 一起搬过去，下面几项需要你在新电脑上看一下。

| 内容 | 搬过去后 | 怎么办 |
|---|---|---|
| **AI 浏览器里登录过的网站** | 登录状态可能带不过去 | 在 Halo 的浏览器里重新登录一次，见 [AI 浏览器](/features/ai-browser) |
| **Claude Code CLI 登录**（仅 macOS） | 凭据在 macOS 钥匙串里，不在拷贝的目录中 | 在 **设置 › AI 模型** 里移除这个来源，再从 **OAuth登录 › Claude Code CLI** 重新登录，见 [模型与账号](/features/models) |
| **企业微信智能机器人** | 同一个机器人同一时间只在一台设备上工作。旧电脑还开着时，新电脑上的卡片可能显示 **待机中** 和「在另一台设备上使用中」 | 先退出旧电脑上的 Halo；或在新电脑的 **设置 › 消息通道** 里点 **在此设备上使用** 接管，旧电脑会转为待机 |
| **飞书机器人** | 两台电脑同时连着同一个机器人时，消息会被随机分给两台电脑 | 只让新电脑运行 |
| **远程访问的固定地址** | 绑定这台设备身份的固定地址保存在 `config.json` 里，会一起搬到新电脑 | 旧电脑上不要再开 **远程访问**，见 [远程访问](/features/remote-access) |
| **跨电脑团队** | 团队用到的本机身份保存在 Halo 数据目录里，会随目录一起带走 | 不要让两台电脑同时运行同一份数据，见 [跨电脑团队](/digital-humans/cross-computer-teams) |
| **其他 AI 来源、邮箱、IM 机器人凭据** | 一起带过去 | 某一项提示失效时，到对应的设置里重新填写或登录 |

## 旧电脑怎么办 {#old-computer}

新电脑用起来以后，不要让两台电脑同时运行同一份数据。机器人、远程访问地址和团队身份都会互相冲突，原因见 [需要重新登录的内容](#sign-in-again)。

确认新电脑一切正常后，可以在旧电脑上卸载 Halo。卸载不会删除数据目录。不再需要的话，手动删掉 [要拷贝的那两个目录](#what-to-copy)，里面有明文密钥。

## 只搬一位数字人 {#one-digital-human}

不需要整机迁移时，可以把一位数字人导出成数字人包（`.dhpkg` 文件），在另一台电脑上导入。

**导出**（旧电脑）<Badge type="info" text="仅桌面版" />

1. 点左侧栏的 **数字人**，打开这位数字人。
2. 点右上角的 **更多 › 分享**，在弹窗里点 **导出**。
3. 选保存位置。看到「已保存至 …」就导出好了，文件名是 `短名-版本号.dhpkg` 的形式，短名由数字人的名称生成（英文转成小写，中文转成拼音）。

**导入**（新电脑）

1. 打开 **数字人 › 我的数字人**，点 **创建数字人**，切到 **导入**。
2. 把文件拖进来，或点击选择。支持 `.dhpkg`、`.zip`、`.yaml` 文件或一个文件夹，压缩包不超过 10 MB。
3. 选要装到哪个工作区，确认安装。看到 **安装完成** 就好了；显示 **部分安装** 说明有技能没装上。

数字人包里有数字人的定义和它自带的技能，不包含对话记录、记忆、知识库内容和 IM 机器人的绑定。导入后需要在新电脑上重新连接机器人、勾选要用的知识库。

::: tip 同一台电脑上换工作区不用导出
只是想让数字人换到本机的另一个工作区里工作，打开它，点 **更多 › 移动到其他工作区**，在 **更改默认工作区** 里选新工作区即可，见 [运行记录与管理](/digital-humans/manage)。打开 [操作 Halo](/features/operate-halo) 后，也可以直接对 Halo 说「把新闻助手移动到另一个工作区」。
:::

## 遇到问题 {#troubleshooting}

### 打开时提示「数据来自更新的版本」

新电脑上装的 Halo 比旧电脑的旧，无法打开这份数据，会弹出这个提示然后退出。把新电脑上的 Halo 升级到和旧电脑相同或更新的版本，再打开。

### 工作区显示「不可用」

工作区的文件夹不在原来的路径下。把项目文件夹放回原路径，或用 **编辑 › 更改文件夹** 改到新位置，见 [路径要保持一致](#same-paths)。如果是换了用户名，连 Halo 数据目录的路径都变了，改回相同的用户名最省事。

### 接着聊旧对话时，AI 不记得之前的内容

只拷了 Halo 数据目录，没拷应用数据目录（或 `~/.claude`）。退出 Halo，把 [应用数据目录](#what-to-copy) 也拷过来，再打开。

### 企业微信机器人显示「待机中」

旧电脑上的 Halo 还在运行，机器人被那边占着。退出旧电脑上的 Halo，或在新电脑的卡片上点 **在此设备上使用**。

### 导入数字人时提示「Archive is … MB, over the 10 MB limit.」

**创建数字人 › 导入** 只接受不超过 10 MB 的压缩包。这个数字人包超过了上限，在这里导入不了。

### 导入时提示「此工作区中已存在同名数字人」

目标工作区里已经有同名的数字人。先卸载原来的那位，或者换一个工作区导入。
