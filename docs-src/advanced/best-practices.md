## 一个项目一个工作区 {#one-workspace-per-project}

[工作区](/features/spaces)把一个项目的会话、文件和记忆放在一起，和别的项目隔开。

- 每个代码仓库或长期项目建一个自己的工作区，指向它的文件夹。AI 主要在这个文件夹里读写，所以只指向你愿意让它改动的文件夹。
- 临时问题、随手一问，用自带的 **Halo 工作区**，不会混进正式项目。
- 想做一次性的试验，单独建一个工作区，不影响正式项目。用完要删时先看清[删除工作区](/features/spaces#delete)的说明：放在默认位置的文件会被永久删除。
- 同一个项目里换话题，开新会话就够了，不用再建工作区，见下一条。

## 管好上下文 {#context}

模型每次回复都要读一遍这个会话里的内容。会话越长，越容易被早先的话题带偏，也越费 token。

- **一个会话只聊一个话题。** 写周报和排查报错分开两个会话。
- **会话太长时，在同一个工作区开新会话**，不用新建工作区。新会话一开始就会读到这个工作区的记忆，之前定下的长期结论不会丢。需要旧会话里的具体内容时，可以[引用那个会话](/features/cross-conversation)。
- **压缩是自动的。** 内容快装不下时，引擎会总结较早的部分，对话里出现「上下文已智能压缩」。回复右下角的 Token 用量在用到 80% 时提示「接近上下文限制」，到 95% 时提示「上下文即将自动压缩」。看到这两条提示，就是开新会话的好时机。
- 怎么看这些提示，见[读懂一条回复](/features/conversations#reading-replies)。

## 管好记忆 {#memory}

[记忆](/features/memory)是 AI 为自己记下的长期笔记，由它决定记什么。你也可以直接告诉它，比如：

- 「记住：周报一律用表格。」
- 「忘掉我之前给你的服务器地址。」

几点要知道：

- **工作区记忆由这个工作区里的所有会话共用。** 在一个会话里记下的偏好，同一工作区的新会话也会用上。这也是一个项目一个工作区的另一个理由：不同项目的偏好不会互相串。
- **整合会用模型，消耗 token。** AI 会在后台整理记忆：合并重复、归入主题、归档旧的历史。
- **按需选整合频率。** 在 **管理工作区** 里打开工作区卡片的 **⋮ › 编辑**，展开 **高级**，在 **整合频率** 里选：

| 整合频率 | 适合 |
|---|---|
| **勤勉**（默认） | 记得最全，用模型最多 |
| **均衡** | 记忆明显增多时才整理 |
| **经济** | 记忆很多时才整理，用模型最少 |

- 不要让 AI 记密码、密钥这类机密。

## 选模型和深度思考级别 {#models}

模型和 **深度思考** 级别都是**按会话**设置的，在输入框 **发送** 旁边的模型卡片里改。选好的模型会固定在这个会话，同时成为新会话的默认模型。

- **按任务选，不按名气选。** 模型卡片会显示 **上下文长度** 和 **图片输入**（「支持」或「不支持」）。资料很长时选上下文长的，常要看图时选支持图片输入的。
- **深度思考级别越高，回答越慢，用的 token 也越多。** 默认是 **高**。日常问答、改格式这类小事可以调低；难题、复杂方案再调到 **极高** 或 **最大**。
- 同时要做轻重不同的事，就开两个会话，各用各的模型和级别。
- 数字人的模型在它自己的设置里改，它的聊天里模型卡片只能看、不能换，见[数字人用的模型](/features/models#digital-human-model)。

具体操作见[模型与账号](/features/models)。

## 发图片给不支持看图的模型 {#images}

当前模型不支持看图时，照样可以发图片。输入框会提示「当前模型不具备视觉能力——图片将通过本地 OCR 转文字读取（仅文本）」，Halo 会自动打开 **文字识别**，在本机识别图片里的文字。

这种方式只拿得到文字，AI 看不到图本身。截图里的报错、表格文字够用；要判断配色、布局，就换一个支持图片输入的模型。详见[文字识别](/features/image-input#text-recognition)。

## 用知识库放要引用的资料 {#knowledge-base}

想让回答基于你的文档，并标明出自哪份文件，就把文档放进[知识库](/features/knowledge-base)，而不是只靠记忆。

- 记忆是 AI 自己记的笔记；知识库是你整理的资料。
- 在会话里点输入框的 **知识** 加载知识库，回答下方会出现 **来源**，点开就是原文件。
- 知识库的「学习」在本机提取文字，不调用模型，不消耗 token。

## 并行工作 {#parallel-work}

不用等一件事做完再开始下一件。几个会话、几个工作区可以同时在跑，详见[同时推进多件事](/features/parallel-work)。

- 正在跑的任务和等你回答的问题，都集中在 [任务](/features/tasks) 面板里。
- Halo 正在干活时，你可以接着发补充信息。它会在当前这一步做完后马上看到，不用等整条回复结束。
- **不用盯着思考过程。** 回复上方的思考过程会列出每一步，但日常只看结果就行。结果不对时再展开，用 **显示工具结果** 查看是哪一步出了问题。

## 把重复的活交给数字人 {#recurring-work}

每天、每周都要做的事，交给[数字人](/digital-humans/overview)：它按计划自己运行，做完向你汇报。你可以直接对 Halo 说，比如「帮我做个数字人，每个工作日早上 9 点汇总科技新闻发给我」，Halo 会先问你几个问题，再建好它。

- 定时提醒要在数字人的聊天里设置，见[提醒](/digital-humans/reminders)。
- 一件事需要调研、撰写、审核几个环节时，让 Halo 组一个[团队](/digital-humans/collaboration)分工完成，比如「组个小团队：一个调研、一个写稿、一个审稿，帮我出一份竞品报告」。

## 安全习惯 {#safety}

你本人使用时，AI 运行命令、改文件、删文件都**不会逐次征求同意**。**设置 › 系统** 的 **权限** 卡片上标着 **完全权限模式**，**信任模式** 一直打开，不能关闭。所以：

- **大改之前先备份，或先用 Git 提交一次。** 改坏了可以回退。代码项目可以在 [变更](/features/code-review) 里查看和提交改动。
- **不需要时关掉操作 Halo。** **操作 Halo** 默认关闭。打开后，AI 能改动这台 Halo 里所有的工作区、数字人和团队，删除也没有确认弹窗。新会话会沿用你上次的开关设置，用完记得在 **＋ › 能力** 里关掉。见[操作 Halo](/features/operate-halo)。
- **远程访问用强密码。** 任何拿到访问密码的人都能完全控制这台 Halo。自定义密码要 8–64 位，包含大小写字母和数字；不用时关掉远程访问。

更多见[安全、隐私与数据流](/advanced/security)。

## 在手机上远程使用 {#remote}

离开电脑后也能继续给 Halo 派活：比如下班路上看进度、回答它的提问，开会间隙补一句要求。

- 在电脑上打开 [远程访问](/features/remote-access)，再用手机浏览器或安卓 App 连接。没有 iOS App，iPhone 用浏览器。
- 干活的始终是电脑上的 Halo，所以电脑要开着、Halo 要在运行。
- 部分功能只有桌面版有，比如选择文件夹。手机上能做什么，见[在手机上用 Halo](/features/mobile)。
