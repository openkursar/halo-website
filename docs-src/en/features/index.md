# Guides

These guides explain every Halo 3.0.4 feature by what you want to do: everyday conversations and workspaces, the things the AI can do for you, developer tools, using Halo from your phone, the Settings reference, and pages for admins. Not sure where to start? Read [Just tell Halo](#just-tell-halo) first.

## Just tell Halo {#just-tell-halo}

You don't have to read the docs first for most things. Describe what you want in a conversation, and Halo does the work. Halo reads these docs itself, so you can also ask it questions like "How do I connect a WeCom bot?" and it walks you through the steps.

Some actions need a switch turned on first in the composer's **＋ › Capabilities**. For example, asking the AI to create a workspace or switch models needs **Operate Halo**, which is off by default. The AI can ask you to turn a switch on and highlight it for you, but it can't turn it on itself. What each switch does is in [Capabilities](/en/features/capabilities).

- [AI Terminal](/en/features/ai-terminal): share a terminal with the AI, for SSH and long-running commands.
- [Knowledge Base](/en/features/knowledge-base): add your documents so the AI answers from them.
- [Office documents](/en/features/office-documents): have the AI create and edit Word, Excel, PowerPoint and PDF files.
- [Files and the canvas](/en/features/files-and-canvas): find the files the AI made or changed, and preview them in the canvas.

- [Conversations that work together](/en/features/cross-conversation): reference another conversation, or let conversations pass messages, hand over work and ask for progress.
- [Let the AI operate Halo](/en/features/operate-halo): what the AI can change for you with **Operate Halo** on, and what stays manual.
