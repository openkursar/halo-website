# Contact

## Where to ask {#where-to-ask}

Picking the right place gets you an answer faster:

| You want to | Go to |
|---|---|
| Ask how a feature works | Ask Halo first; it reads these docs to answer you. Or see the [Help center](/en/troubleshooting/) |
| Report a problem or suggest something | [GitHub Issues](https://github.com/openkursar/hello-halo/issues) |
| Swap tips with other users | The WeChat user group |
| Discuss open-source collaboration, or talk privately | Email |
| Follow new releases and tutorials | X and Bilibili |

## WeChat user group {#wechat-group}

Add WeChat ID **go2halo** with the note `Halo` to be invited to the user group. It discusses using Halo, AI tools and new releases, and the founder is in the group. When you ask about a problem there, mention your Halo version and operating system so others can help more easily.

## Report a problem {#issues}

Open an issue or suggestion on [GitHub Issues](https://github.com/openkursar/hello-halo/issues). Say what you did, what you expected and what actually happened, and attach screenshots if they help. Including the exact error, your Halo version and a diagnostics report saves a round of questions; see [Still stuck](/en/troubleshooting/#get-help).
