# 错误信息速查

用 <kbd>⌘</kbd> <kbd>F</kbd> / <kbd>Ctrl</kbd> <kbd>F</kbd> 在本页搜你看到的那句话。不在这里的，把报错原文复制给 Halo 问一问。

## 对话中 {#conversation}

| 看到的提示 | 意思 | 怎么办 |
|---|---|---|
| 「模型响应已中断」 | 这次回复没正常结束 | 点 **继续**，Halo 会接着做 |
| 「模型响应已中断」＋「Reached the maximum turn limit. Send a message to continue.」 | 一条消息里的步骤数到了上限 | 发一条消息让它继续；经常遇到，可以调大 **设置 › 高级 › 每条消息最大轮次** |
| 「出现错误」 | 这一轮失败了 | 红框里写着原因。要完整报错，在回复上方的思考过程里找到出错的那一步：点 **复制**（提示「复制错误信息」）复制下来，发给 Halo 或技术支持；报错很长时，点 **展开完整错误** 看全文 |
| 「接近上下文限制」「上下文即将自动压缩」 | 对话快到模型能记住的上限 | 不用处理，Halo 会自动压缩；话题已经换了，就新开一个会话 |
| 「上下文已智能压缩」 | 较早的内容被压缩成了摘要 | 正常现象。重要的要求可以再说一遍 |
| "OAuth token expired or invalid. Please login again." | 账号登录过期了 | 按 [连接 AI 模型](/getting-started/setup-ai#troubleshooting) 重新登录 |

## 模型服务出错（会自动重试） {#retry}

模型请求失败、Halo 准备重试时，回复里会出现一张倒计时卡片，写着「第 N/M 次重试」，可以点 **停止**。卡片标题说明了原因：

| 卡片标题 | 意思 | 怎么办 |
|---|---|---|
| 「无法连接模型服务」 | 连不上模型服务 | 检查网络和代理 |
| 「模型服务过载」 | 服务方太忙 | 等它自动重试，或稍后再发 |
| 「模型服务正在限流」 | 请求太频繁，或者额度用完了 | 等一会儿；经常出现，换个套餐或换个模型 |
| 「模型服务拒绝了凭据」 | Key 或登录无效 | 检查 **设置 › AI 模型** 里的 Key，或重新登录 |
| 「模型服务商报告了计费问题」 | 账户欠费或额度不足 | 到服务商的控制台充值 |
| 「模型服务返回错误」「模型请求失败」 | 其他错误 | 看卡片上的状态码和说明，对照 [模型 API 错误码](/troubleshooting/api-errors) |

## 连接模型、获取模型列表时 {#model-setup}

| 看到的提示 | 意思 | 怎么办 |
|---|---|---|
| 「API 密钥无效或没有权限」 | Key 填错了，或者没有这个模型的权限 | 重新复制 Key；确认账户能用这个模型 |
| 「未找到端点，请检查 URL」 | API URL 不对 | 核对服务商文档里的地址 |
| 「请求频率受限或配额已用尽」 | 被限流，或额度用完 | 稍后再试，或充值 |
| 「请求超时，请检查服务器或代理」 | 服务器太慢或代理有问题 | 检查代理设置，稍后再试 |
| 「无法连接服务器，请检查网络或代理」 | 连不上 | 检查网络、代理和 API URL |
| 「获取模型失败」 | 其他原因 | 看冒号后面服务商给的说明 |

**测试连接** 的结果只有英文，比如 "Invalid API key"、"Rate limited - try again later"、"Cannot connect to API server - check URL"，意思和上表对应。详见 [获取 API Key](/getting-started/api-keys)。

## 图片和附件 {#attachments}

| 看到的提示 | 意思 | 怎么办 |
|---|---|---|
| 「图片过大 (…),最大 20MB」 | 单张图片超过 20 MB | 压缩或截取后再发 |
| 「不支持的图片格式:…」 | 只支持 JPEG、PNG、GIF、WebP | 换成这几种格式 |
| 「当前模型不具备视觉能力——图片将通过本地 OCR 转文字读取（仅文本）」 | 当前模型看不了图，Halo 只把图里的文字交给它 | 要它理解图片内容，换一个能看图的模型 |
| 「N 项无法附加：不是这台电脑上的文件或文件夹」 | 拖进来的不是本机文件 | 先把文件存到电脑上再附加 |

## Windows 命令执行环境 {#windows}

| 看到的提示 | 意思 | 怎么办 |
|---|---|---|
| 「未安装命令执行环境,AI 无法运行系统命令」 | 没装 Git Bash，AI 不能运行命令 | 点 **立即安装**，见 [安装与启动问题](/troubleshooting/install#git-bash) |
| 「初始化失败」 | 第一次打开时装 Git Bash 失败 | 见 [显示「初始化失败」](/troubleshooting/install#git-bash-failed) |

## 数字人 {#digital-humans}

| 看到的提示 | 意思 | 怎么办 |
|---|---|---|
| 「未启动」 | 它要用的连接没准备好 | 见 [运行记录显示「未启动」](/troubleshooting/digital-humans#not-started) |
| 「多次失败后已自动停止」 | 连续 5 次失败，自动任务停了 | 处理好原因后点 **恢复工作** |
| 「已有独立执行正在运行」 | 上一次还没跑完 | 等它结束，或点 **停止此执行** |
| 「节假日日历未涵盖今天，因此本次计划运行已被跳过。如有需要，请手动运行。」 | 节假日日历没下载到今天 | 需要的话点 **立即运行** |
| 「远程访问已关闭。启用后即可从其他设备通过 HTTP 触发此操作。」 | HTTP 触发器要先开远程访问 | 打开 **设置 › 远程访问 › 启用远程访问** |

## 机器人 {#bots}

| 看到的提示 | 意思 | 怎么办 |
|---|---|---|
| 「⚠️ 该机器人尚未绑定主人，暂时无法执行任务。」 | 开了权限控制，还没有主人 | 私聊机器人发一句话，见 [主人与访客权限](/digital-humans/permissions#auto-claim) |
| 「⚠️ 该机器人仅在群聊中响应，请联系管理员开通权限。」 | **回复范围** 是 **仅群聊** | 去群里 @ 它，或改回复范围 |
| 「⚠️ 该机器人仅在私聊中响应。」 | **回复范围** 是 **仅私信** | 私聊它，或改回复范围 |
| 「该机器人已被其他实例使用。每个机器人只能绑定一个数字人。」 | 同一个机器人接了两次 | 用已有的那个实例 |
| 「已连接 · 尚未收到消息」（飞书） | 连上了，但没收到消息 | 见 [飞书：一直收不到消息](/troubleshooting/channels#feishu-no-messages) |
| "File export denied: … Only files within the current space or temporary directory can be sent." | 要发的文件不在数字人的工作区里 | 先把文件放进它的工作区 |

更多见 [机器人不回复](/troubleshooting/channels)。

## 团队 {#teams}

| 看到的提示 | 意思 | 怎么办 |
|---|---|---|
| 「至少添加一名成员，或让 AI 组建团队」 | 新建团队时没有成员 | 加一位数字人，或点 **让AI根据目标组建团队** |
| 「请在设置中开启远程访问，以便他人加入该团队。」 | 邀请需要远程访问或联邦网关 | 见 [跨电脑团队](/digital-humans/cross-computer-teams#federation-gateway) |
| 「无法加入团队。请检查链接，并确认邀请你的人在线。」 | 连不上邀请人的电脑 | 见 [跨电脑团队](/digital-humans/cross-computer-teams#troubleshooting) |
| 「此邀请已失效——可能已过期、已被撤销，或团队已被关闭。请索取新的邀请链接。」 | 链接不能用了 | 请邀请人发新链接 |
| 「该团队要求所有成员将 Halo 更新至最新版本」 | 版本不一致 | 点 **检查更新** |
| 「某某 未收到此消息。某某 的电脑目前处于离线状态；……」 | 收消息的成员所在的电脑离线 | 等对方上线后重发，或把任务交给别的成员 |
| 「此消息未送达。」 | 收消息的成员已经不在团队里 | 把任务交给别的成员 |

## Halo 卡住或反复出错 {#stuck}

连续出错时，Halo 会自己重置 AI 引擎；还不行，会弹出英文的「Halo is having trouble」，可以选 **Restart App**（重启）或 **Try to Fix**（修复）。

也可以手动处理：打开 **设置 › 系统 › 系统诊断**，点 **运行诊断**，再点 **重置 AI 引擎**；还不行就点 **重启应用**，详见 [重置 AI 引擎或重启](/troubleshooting/diagnostics#recover)。要找人帮忙时，点 **复制报告** 或 **导出报告**。报告不含 Key 本身。错误信息里的 Bearer 令牌、JWT 和部分 `sk-` 开头的 Key 会被遮盖，但 Anthropic（`sk-ant-…`）和 OpenAI 项目 Key（`sk-proj-…`）这类格式不会；macOS、Linux 路径里的用户名会被隐去，Windows 路径的不会。发出前先通读一遍，删掉看到的 Key。
