# 机器人不回复

::: say
> 我的企业微信机器人不回复了，帮我查一下。

Halo 会对照官方的排查说明，一项项问你看到了什么。打开 **操作 Halo** 后（输入框 **＋ › 能力**），它还能直接查看机器人的连接状态，必要时帮你重新连接。
:::

## 先看有没有「已收到，正在处理…」 {#processing-notice}

**处理中提示** 默认开着：数字人 5 秒内还没回复时，机器人会先回「已收到，正在处理…」。

- **收到了这句**：消息已经到了数字人那里，它在处理。等一会儿；一直没有下文，看 [消息到了，但没有回复](#no-answer)。
- **这句也没有**：消息没到 Halo。从 [第一步](#halo-running) 开始查。

开着 **流式传输** 时，这句话会马上出现在正在写的回复里（企业微信显示「ℹ️ 已收到，正在处理…」）。关掉了 **处理中提示**、又没开流式传输时，不会有这句话。

## 1. Halo 开着，电脑没睡 {#halo-running}

机器人靠 Halo 连着聊天软件。Halo 退出、电脑睡眠或断网时，机器人收不到消息。见 [让数字人一直在线](/digital-humans/keep-running)。

**暂停自动任务** 不影响机器人：暂停的数字人照样回复聊天消息。

## 2. 机器人已连接 {#status}

打开 **设置 › 消息通道**，看机器人卡片的状态：

| 状态 | 意思 | 怎么办 |
|---|---|---|
| **已连接**（绿点） | 连接正常 | 继续往下查 |
| **已断开连接** | 连不上 | 点机器人右上角的 **⋮ › 重新连接**；手动填写的，核对 Bot ID、Secret 或应用 ID、应用密钥 |
| **待机中**（企业微信） | 同一个机器人在另一台电脑上用着 | 想在这台电脑上用，点 **在此设备上使用** |
| **已禁用** | 机器人被关掉了 | 打开机器人右上角的开关；微信机器人点 **连接微信** 重新扫码 |
| **未连接**（微信） | 多半是微信那边的登录过期了 | 点 **连接微信** 重新扫码 |
| **已连接 · 尚未收到消息**（飞书） | 连上了，但一条消息都没收到 | 见 [飞书：一直收不到消息](#feishu-no-messages) |

公司网络或代理拦住了企业微信、飞书的服务器时，机器人也会连不上，问一下网络管理员。

## 3. 机器人绑定了数字人 {#binding}

点开机器人，看 **后端**：

- 要选了一位数字人（或团队成员）。显示「绑定已失效」时，原来的数字人已经不在了，重新选一位。
- 全局数字人（没有工作区的）不能接机器人，要选工作区里的数字人。
- 后端是团队成员时，这位成员要在这台电脑上，并且还在团队里。

## 4. 回复范围和 @ 提及 {#scope}

- **回复范围** 选了 **仅群聊** 时，私聊会被拒绝，机器人回「⚠️ 该机器人仅在群聊中响应，请联系管理员开通权限。」；选了 **仅私信** 时，群消息会收到「⚠️ 该机器人仅在私聊中响应。」。
- 群聊里要 @ 机器人。企业微信只把 @ 机器人的消息转给它；飞书的 **在群聊中需要 @ 提及** 默认开着。
- 微信机器人不能在群里用。

## 5. 机器人有主人 {#owner}

打开了 **权限控制**、还没有主人时，机器人在群里什么也不做，只回「⚠️ 该机器人尚未绑定主人，暂时无法执行任务。」（每个群最多 10 分钟一次）。先私聊机器人发一句话，你就会成为主人。见 [主人与访客权限](/digital-humans/permissions)。

## 消息到了，但没有回复 {#no-answer}

1. 打开这位数字人，切到 **IM 会话** 标签，找到这个联系人，看对话记录里有没有这条消息和回复。
2. 正在回复但一直没完，可以点 **停止生成**，再在聊天软件里重发；也可以在聊天里发 `/stop`。
3. 回「The model returned an empty response. Please send your message again.」时，重发一次。
4. 数字人用的 AI 模型出了问题（比如 Key 失效、额度用完）时，它也回复不了。在 Halo 里和它聊一句试试，报错见 [错误信息速查](/troubleshooting/common-errors)。

## 企业微信 {#wecom}

- 同一个机器人同一时间只能接在一台电脑上。另一台电脑接走后，这台显示 **待机中**，见 [同一个机器人接在两台电脑上](/digital-humans/wecom-bot#standby)。
- 提示「该机器人已被其他实例使用。每个机器人只能绑定一个数字人。」：这个机器人已经接在另一个实例上，用那个实例，或先删掉它。
- 更多见 [企业微信智能机器人](/digital-humans/wecom-bot#troubleshooting)。

## 飞书 {#feishu}

### 一直收不到消息 {#feishu-no-messages}

卡片显示「已连接 · 尚未收到消息」时：

- 应用可能还在等公司管理员审核，批准后才能收到消息。
- 给它发消息的人可能不在应用的可用范围里。
- 在飞书里私聊它一句试试，收到后这条提示就会消失。

### 其他情况 {#feishu-other}

- 电脑上弹出「Feishu bot cannot connect」：核对 **应用 ID**、**应用密钥**，确认应用已经发布。
- 同一个飞书应用接在两台电脑上时，消息会随机分到两边。一个应用只在一台电脑上用。
- 群里没 @ 它的消息收不到，要在飞书开发者后台给应用开「所有群消息」权限，再关掉 **在群聊中需要 @ 提及**。

更多见 [飞书机器人](/digital-humans/feishu-bot#troubleshooting)。

## 微信 {#wechat}

- 显示 **未连接**：点 **连接微信** 重新扫码。
- Halo 重启后，数字人主动发给某人的消息发不出去：请对方先给机器人发一条消息。

更多见 [微信机器人](/digital-humans/personal-wechat#troubleshooting)。
