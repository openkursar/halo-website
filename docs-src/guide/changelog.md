# 更新日志

记录每次版本的主要新功能和改动。

---

## 2026.04

### 新功能

**个人微信接入**
扫码即可将个人微信号绑定为数字人的对话入口，无需企业微信账号。适合个人助理、个人工具等场景。
→ [配置个人微信](/digital-humans/personal-wechat)

**邮件 MCP**
数字人可直接收发邮件、搜索邮箱、管理日历（需 CalDAV）。基于标准 IMAP/SMTP 协议，兼容主流邮件服务。需在数字人设置中手动开启。
→ [邮件 MCP](/features/email)

**IM 渠道安全权限控制**
企业微信/微信机器人新增权限控制系统，区分 Owner（管理员）和 Guest（访客）角色，精细控制访客可使用的工具范围。Bash、Write、Edit 等危险工具**默认对访客关闭**，保护服务器安全。
→ [安全与权限控制](/advanced/security)

**个人微信渠道** 已加入消息通道选项，配置见上。

### 功能增强

**`/halo-clear` 命令**（IM 渠道专属）
在企业微信、个人微信、飞书、钉钉中发送 `/halo-clear` 可清空数字人的上下文，从全新会话开始。`/halo-stop` 可中断当前任务而不清除历史。
→ [命令](/features/commands)

**流式传输开关**
每个企业微信机器人实例可独立控制是否开启流式传输。关闭后数字人只在完整回复生成后才发消息，适合不希望展示中间思考过程的场景。
→ [机器人行为控制](/digital-humans/wecom-bot-features#机器人行为控制)

**回复范围控制**（支持私聊不回复）
企业微信机器人可设置只响应群聊、只响应私聊，或全部响应。默认仅群聊，避免意外的私聊触发。
→ [机器人行为控制](/digital-humans/wecom-bot-features#机器人行为控制)

**数字人浏览器登录快捷入口**
数字人详情页头部新增地球图标按钮，可直接输入任意 URL 在共享浏览器 session 中打开，方便预先登录需要认证的网站。spec 中可通过 `browser_login` 字段声明预设入口。
→ [浏览器登录快捷入口](/digital-humans/create#浏览器登录快捷入口)

**工作区 / 记忆区目录快速访问**
数字人设置面板中新增"在访达中显示"按钮，可分别快速打开工作区文件夹（数字人产出文件）和记忆区目录（`memory.md`、运行历史），两者的概念和路径也更清晰。
→ [数字人的两个目录](/features/spaces#数字人的两个目录)
