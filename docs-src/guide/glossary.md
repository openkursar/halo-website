# 术语表

文档和界面里常见的词，按主题排列。每个词给出简短说明、界面上显示的原文，以及详细介绍它的页面。

## 工作区 {#workspace}

一个文件夹，加上它里面的会话、记忆和资源。一个项目用一个工作区。

- 英文：workspace
- 界面上的文字：「工作空间」「Halo 工作区」「新建空间」「管理工作区」
- 详见：[工作区](/features/spaces)

## Halo 工作区 {#halo-workspace}

Halo 自带的工作区，打开 Halo 就在这里，适合临时的事。

- 英文：Halo Workspace
- 界面上的文字：「Halo 工作区」
- 详见：[工作区](/features/spaces)

## 会话 {#conversation}

在某个工作区里和 Halo 的一段对话。

- 英文：conversation
- 界面上的文字：「会话」「对话」「新对话」
- 详见：[会话](/features/conversations)

## 数字人 {#digital-human}

能自己干活的 AI 成员：按计划、按事件或在 IM 里被叫到时工作，有自己的记忆和设置。

- 英文：Digital Human
- 界面上的文字：「数字人」「我的数字人」
- 详见：[数字人概述](/digital-humans/overview)

## 团队 {#team}

几位数字人在一位负责人带领下分工、交接、交付结果；可以临时组建，也可以保存下来。

- 英文：team
- 界面上的文字：「团队」「保留此团队」
- 详见：[数字人团队](/digital-humans/collaboration)

## 临时协作 {#temporary-collaboration}

AI 为当前任务临时组建的团队，任务结束即解散，想保留可以说「保留这个团队」。

- 英文：temporary collaboration
- 界面上的文字：「临时协作」
- 详见：[数字人团队](/digital-humans/collaboration)

## 负责人 {#lead}

团队里负责拆分任务、分派工作、在团队决定不了时来问你的成员。

- 英文：lead
- 界面上的文字：「负责人」
- 详见：[数字人团队](/digital-humans/collaboration)

## 跨电脑团队 {#cross-computer-team}

有成员在同事电脑上的团队，凭邀请链接加入。成员在同一局域网里直接连到发起团队的电脑（需要打开远程访问），跨网络时经过你们自己部署的联邦网关。

- 英文：team across computers
- 界面上的文字：「邀请」「邀请链接」「加入团队」
- 详见：[跨电脑团队](/digital-humans/cross-computer-teams)

## 联邦网关 {#federation-gateway}

你自己部署的中继服务，让不在同一网络的电脑加入同一个团队，负责在它们之间转发消息。

- 英文：Federation Gateway
- 界面上的文字：「联邦网关」
- 详见：[部署联邦网关](/advanced/federation-gateway)

## 能力 {#capabilities}

输入框 ＋ 里按会话开关的能力。AI 可以请你打开，但不能自己打开。

- 英文：capabilities
- 界面上的文字：「能力」「网页控制」「AI 终端」「文字识别」「操作 Halo」「团队协作」
- 详见：[能力开关](/features/capabilities)

## 能力库 {#capability-library}

管理已安装技能和 MCP 服务器的地方。

- 英文：Capability library
- 界面上的文字：「能力库」
- 详见：[技能](/features/skills)

## 技能 {#skill}

一份可复用的做事说明（SKILL.md），AI 需要时会用，也可以用 / 调用。

- 英文：skill
- 界面上的文字：「技能」
- 详见：[技能](/features/skills)

## MCP 服务器 {#mcp-server}

通过 Model Context Protocol 接入的外部工具服务。

- 英文：MCP server
- 界面上的文字：「MCP」
- 详见：[MCP 服务器](/features/mcp)

## 知识库 {#knowledge-base}

你的资料，在本机提取成可检索的文字；AI 回答时查阅，并列出「来源」。

- 英文：knowledge base
- 界面上的文字：「知识库」「知识」「来源」
- 详见：[知识库](/features/knowledge-base)

## 记忆 {#memory}

Halo 在会话之间记住的东西：同一工作区的会话共享工作区记忆；每位数字人有自己的记忆（当前状态、历史、主题）。

- 英文：memory
- 界面上的文字：「记忆」「工作区记忆」「立即整合」「自动整合」「使用工作区记忆」「清除记忆」
- 详见：[记忆](/features/memory)

## 主题 {#topic}

记忆里关于某一件事的一页笔记，由 AI 编写和整理。

- 英文：topic
- 详见：[记忆](/features/memory)

## 任务面板 {#task-panel}

所有工作区里正在运行的工作和等你处理的问题，集中在一个列表。

- 英文：task panel
- 界面上的文字：「任务」「需要你处理」「运行中」「已置顶」
- 详见：[任务面板](/features/tasks)

## 变更 {#changes}

查看工作区 Git 仓库的改动、暂存、提交，并让 AI 评审。

- 英文：Changes view
- 界面上的文字：「变更」「查看变更」「快速评审」「团队评审」
- 详见：[变更、代码评审与 Git](/features/code-review)

## 画布 {#canvas}

右侧的多标签查看区，用来看文件、浏览器、终端、团队和变更。

- 英文：canvas
- 界面上的文字：「在画布中打开」
- 详见：[文件与画布](/features/files-and-canvas)

## 工作区资源 {#workspace-resources}

右侧栏，有文件、数字人、技能、MCP 几个标签。

- 英文：workspace resources
- 界面上的文字：「展开工作区资源」
- 详见：[文件与画布](/features/files-and-canvas)

## AI 浏览器 {#ai-browser}

Halo 内置的浏览器，AI 用你已登录的状态操作网页；你可以旁观和接手。

- 英文：AI Browser
- 界面上的文字：「打开浏览器」「网页控制」
- 详见：[AI 浏览器](/features/ai-browser)

## AI 终端 {#ai-terminal}

你和 AI 共用、一直开着的终端。

- 英文：AI Terminal
- 界面上的文字：「AI 终端」「打开终端」
- 详见：[AI 终端](/features/ai-terminal)

## 商店 {#store}

浏览并安装数字人和技能；「设置 › 应用商店」管理商店来源。

- 英文：Store
- 界面上的文字：「商店」「应用商店」「发布到商店」
- 详见：[商店](/digital-humans/store)

## 消息通道 {#message-channels}

连接 IM 和邮件：双向机器人绑定到一位数字人；单向通知渠道只负责发出消息。

- 英文：message channels
- 界面上的文字：「消息通道」「企业微信智能机器人」「飞书机器人」「微信机器人」「电子邮件」「Webhook」
- 详见：[消息通道概览](/digital-humans/channels)

## 机器人 {#bot}

IM 那一端的身份（企业微信、飞书、微信里），把消息转给一位数字人。

- 英文：bot
- 详见：[消息通道概览](/digital-humans/channels)

## 可联系的联系人 {#reachable-contacts}

一位数字人可以主动发消息的会话。

- 英文：Reachable Contacts
- 界面上的文字：「可联系的联系人」「从已有会话添加」「主动发送」
- 详见：[通知与主动推送](/digital-humans/notifications)

## 权限控制 {#permission-control}

决定通过机器人找数字人的人能让它做什么：主人拥有完整权限，访客只能用允许的工具。

- 英文：Permission Control
- 界面上的文字：「权限控制」「访客权限」「访客允许使用的工具」「访客访问权限」
- 详见：[主人与访客权限](/digital-humans/permissions)

## 主人 / 访客 {#owner-guest}

主人是机器人认定的你本人：第一个私聊这个机器人的人会成为主人；访客是通过机器人发消息的其他人。

- 英文：owner / guest
- 详见：[主人与访客权限](/digital-humans/permissions)

## 提醒 {#reminder}

在数字人的聊天里说一句就能设置的一次性或重复提醒。

- 英文：reminder
- 界面上的文字：「提醒」「取消此提醒」
- 详见：[提醒](/digital-humans/reminders)

## 计划任务 {#schedule}

数字人什么时候自己运行。

- 英文：schedule
- 界面上的文字：「计划任务」「立即运行」「仅限中国大陆工作日」
- 详见：[运行计划与触发方式](/digital-humans/triggers)

## 触发器 {#trigger}

让数字人开始一次运行的条件：计划、事件或消息。

- 英文：trigger
- 界面上的文字：「触发器」
- 详见：[运行计划与触发方式](/digital-humans/triggers)

## 运行 {#run}

数字人完成一次任务的过程，留有可查看的记录。

- 英文：run
- 界面上的文字：「运行」「未启动」
- 详见：[运行记录与管理](/digital-humans/manage)

## 能力与设置 {#dh-settings}

数字人的设置页：模型、工具与资源、记忆、通知等。

- 英文：Capabilities and settings
- 界面上的文字：「能力与设置」「工具与资源」
- 详见：[能力与设置](/digital-humans/capabilities)

## 模型 / AI 来源 / 提供商 {#model}

AI 来源是一个账号或一个 Key；每个来源提供若干模型；模型按会话选择。

- 英文：model / AI source / provider
- 界面上的文字：「AI 模型」「配置 AI 来源」「管理 AI 提供商」「切换模型」
- 详见：[模型与账号](/features/models)

## 深度思考 {#deep-thinking}

模型回答前思考的深浅，从「关闭」到「最大」，按会话设置。

- 英文：Deep Thinking
- 界面上的文字：「深度思考」
- 详见：[模型与账号](/features/models)

## 剩余配额 {#quota}

提供商报告的剩余额度，只在提供商支持时显示。

- 英文：remaining quota
- 界面上的文字：「剩余配额」
- 详见：[模型与账号](/features/models)

## Agent 引擎 {#agent-engine}

驱动 AI 干活的运行时：默认是 Claude Code SDK，另有 Halo SDK、Codex SDK 和 DeepSeek dsh（后三个为实验性）。

- 英文：agent engine
- 界面上的文字：「AI Agent 引擎」
- 详见：[Agent 引擎](/features/agent-engines)

## 远程访问 {#remote-access}

用手机或其他设备打开你的 Halo，局域网或互联网都可以；也是 HTTP API 的入口。

- 英文：Remote Access
- 界面上的文字：「远程访问」
- 详见：[远程访问](/features/remote-access)

## 操作 Halo {#operate-halo}

一项能力：打开后，AI 可以通过 Halo 自己的接口替你改设置、管理工作区和数字人。

- 英文：Operate Halo
- 界面上的文字：「操作 Halo」
- 详见：[让 AI 帮你操作 Halo](/features/operate-halo)

## 引用会话 {#reference-conversation}

让 AI 读取同一工作区的另一个会话，或直接给它发消息。

- 英文：Reference a conversation
- 界面上的文字：「引用会话」「与数字人聊天」
- 详见：[会话之间互相协作](/features/cross-conversation)

## 目标 {#goal}

给会话设定的目标和「完成标准」，上下文被压缩后也会保留。

- 英文：goal
- 界面上的文字：「目标」
- 详见：[会话](/features/conversations)

## 处理中提示 {#processing-notice}

IM 里回复超过一定时间时先发出的「正在处理」提示，可以关闭。

- 英文：Processing Notice
- 界面上的文字：「处理中提示」
- 详见：[企业微信机器人进阶](/digital-humans/wecom-bot-features)

## 数字人包 {#package}

可分享的数字人文件：.dhpkg、.zip、.yaml，或含 spec.yaml 的文件夹。

- 英文：Digital Human package
- 详见：[运行记录与管理](/digital-humans/manage)

## Halo Server {#halo-server}

以服务形式运行的无界面 Halo，用浏览器打开同样的界面。

- 英文：Halo Server
- 详见：[Halo Server 快速开始](/server/)

## 开发者模式 {#developer-mode}

打开后输出更详细的诊断日志。

- 英文：Developer Mode
- 界面上的文字：「开发者模式」
- 详见：[日志与诊断](/troubleshooting/diagnostics)
