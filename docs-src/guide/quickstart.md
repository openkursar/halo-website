# 30 秒开始第一个对话

## 第一步：创建空间

打开 Halo 后，你会看到主界面。点击左侧的 **「+」** 创建一个新空间。

空间有两种模式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **临时空间**（Halo Space） | 无需绑定文件夹，即开即用 | 临时问答、头脑风暴 |
| **专属空间** | 关联本地项目目录，AI 可读写其中的文件 | 代码开发、项目管理 |

初次使用，选临时空间即可。

---

## 第二步：发送第一条消息

在输入框中用自然语言描述你想做的事。Halo 的底层是 Claude Code，你可以：

```
帮我写一个 Python 爬虫，抓取 Hacker News 首页前 10 条内容
```

```
整理一下我桌面上的文件，按类型分类到对应文件夹
```

```
分析这段代码有什么性能问题
```

Halo 会调用 AI Agent 能力，自主规划步骤、执行命令、返回结果。

## 第三步：了解界面

<!-- 截图占位：screenshot-main-light.png（主界面亮色模式，含空间列表、对话区、工具栏） -->

**左侧栏**：空间列表，管理多个并行任务

**顶部**：模型切换（右上角），随时切换 API Key 和模型

**输入框左下角**：🌐 图标开启 AI 浏览器

**思考工具栏**：默认收起，点击展开可查看 AI 的原始工具调用过程

---

## 常用操作速查

| 操作 | 方法 |
|------|------|
| 新建空间 | 左侧栏点击「+」 |
| 切换模型 / API Key | 右上角下拉菜单 |
| 开启 AI 浏览器 | 输入框左下角 🌐 |
| 上传图片 | 点击「+」或直接粘贴 / 拖拽 |
| 压缩上下文 | 发送 `/compact` |
| 远程访问 | 设置 → 远程访问 |
