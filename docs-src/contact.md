# 联系我们

## 该去哪里问 {#where-to-ask}

选对地方，能更快得到回答：

| 你想 | 去哪里 |
|---|---|
| 问某个功能怎么用 | 先直接问 Halo，它会查这份文档回答你；或者看 [帮助中心](/troubleshooting/) |
| 报告问题、提建议 | [GitHub Issues](https://github.com/openkursar/hello-halo/issues) |
| 和其他用户交流用法 | 微信用户群 |
| 谈开源合作，或者需要私下沟通 | 邮件 |
| 关注新版本和教程 | X、B 站 |

## 微信用户群 {#wechat-group}

添加微信 **go2halo**，备注 `Halo`，会邀请你进用户群。群里讨论 Halo 的用法、AI 工具和新版本体验，创始人也在群里。在群里问问题时，顺便说一下你的 Halo 版本和电脑系统，别人更容易帮上忙。

## 问题反馈 {#issues}

在 [GitHub Issues](https://github.com/openkursar/hello-halo/issues) 提交问题或建议。写清你做了什么、想要什么结果、实际看到了什么；有截图的话一并附上。再准备好报错原文、Halo 的版本和诊断报告，能少来回问几次，详见 [还是解决不了](/troubleshooting/#get-help)。

## 邮件 {#email}

**imwangfu@gmail.com**（创始人直达），适合开源合作或需要私下沟通的事。问题反馈请走 GitHub Issues。

## X 和 B 站 {#social}
