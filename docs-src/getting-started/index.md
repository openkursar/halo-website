# 快速开始

这一页是路线图。前两步（安装、连接模型）需要你自己点；从第三步开始，有不会的都可以直接问 Halo，它会读这份文档回答你。

## 开始之前 {#before-you-start}

- **一台电脑**：macOS 12 及以上（Apple 芯片或 Intel）、Windows 10 及以上（64 位），或 64 位 Linux（glibc 2.34 及以上）。详细要求见 [安装 Halo](/getting-started/install#before-you-start)。
- **能上网**：下载安装包、登录 AI 账号都需要联网。
- **一种用 AI 的方式**，三选一就行：
  - 已经有 Claude、ChatGPT 或 GitHub Copilot 的会员账号；
  - 有一个 API Key（公司发的，或在 DeepSeek、Kimi、智谱等平台自己申请的）；
  - 什么都没有也可以：登录页上有免费的登录方式，第 2 步会教你怎么选。

Halo 本身免费开源。使用 AI 模型的费用，由你登录的账号或 API Key 所属的平台收取。

## 四步上手 {#steps}

| 步骤 | 做什么 | 做完你会看到 |
|---|---|---|
| 1. [安装 Halo](/getting-started/install) | 下载、安装、第一次打开 | 「让我们开始设置」 |
| 2. [连接 AI 模型](/getting-started/setup-ai) | 选一种登录方式，或者填 API Key | 「今天想做点什么？」 |
| 3. [完成第一个任务](/getting-started/first-chat) | 用一句话让 Halo 做出一份真实的文件 | 右侧文件栏出现新文件 |
| 4. [认识 Halo 界面](/getting-started/app-tour) | 了解左侧栏、会话页、任务面板和设置 | 知道以后去哪里找 |

Windows 电脑第一次打开时，还会多一个「需要首次设置」的页面，用来安装命令执行环境。保持默认选项点 **继续** 即可，详见 [安装 Halo](/getting-started/install#git-bash)。

::: done
四步做完，你会有一个连好 AI 模型的 Halo，Halo 工作区里有它为你做的第一份文件，而且你知道会话、数字人、知识库、商店、任务和设置分别在哪里。
:::
