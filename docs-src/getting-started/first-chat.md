# 3. 第一次对话

模型配置好了，现在来发送你的第一条消息，体验一下 Halo 能做什么。

---

## 创建一个空间

「空间」是 Halo 中用来组织工作的单位。你可以把它理解成**一个独立的工作区**——不同的项目、不同的事情，放在不同的空间里，互不干扰。

1. 在 Halo 左侧栏，点击 **「+」** 按钮
2. 选择 **临时空间**

<!-- screenshot: first-chat-create-space.png — 左侧栏 + 按钮和空间创建选项 -->

::: tip 临时空间 vs 专属空间
- **临时空间**：即开即用，适合临时提问、头脑风暴。不关联任何文件夹
- **专属空间**：关联你电脑上的一个文件夹，AI 可以读写里面的文件。适合具体项目

刚开始用，选临时空间就行。后面熟悉了再试专属空间。
:::

---

## 发送第一条消息

在输入框中用自然语言描述你想做的事情，然后按回车发送。

试试这些例子（复制任何一条发送即可）：

**改写文字**：
```
帮我把下面这段话改成正式的商务邮件语气：
老王，那个合同的事你看一下，尽快给我回复
```

**分析数据**：
```
我有一组销售数据，1月120万，2月95万，3月150万，4月130万。
帮我分析趋势，并给出下个月的预测
```

**写代码**（即使你不是程序员也可以试试）：
```
用 Python 写一个脚本，把当前文件夹里所有 .xlsx 文件名列出来
```

这些任务 AI 都可以**立即完成**并给你结果。后面配置好邮箱和企微 Bot 之后，AI 还可以帮你发邮件、回复企微消息等。

发送后，AI 会开始思考并回复。第一次可能需要几秒钟。

## 发送图片

如果你需要 AI 帮你分析图片内容（比如截图、表格、文档照片），有三种方式：

1. **直接粘贴**：截图后按 `Ctrl+V`（Mac: `Cmd+V`）
2. **拖拽**：把图片文件拖进对话区
3. **点击上传**：点击输入框旁边的 **「+」** 按钮，选择图片

<!-- screenshot: first-chat-image.png — 上传图片的几种方式 -->

::: warning 发送图片报错？
部分 AI 模型不支持图片（纯文本模型）。如果发送图片后报错，需要切换到支持图片的模型（多模态模型）。

解决方法：点击右上角模型切换，选择一个支持图片的模型。如果不确定哪个支持，问一下你的管理员。

**重要**：如果已经发了图片导致报错，需要**新建一个对话**（左侧栏点 +），在旧对话里继续发文字也会报错。
:::

## 常用操作速查

| 你想做什么 | 怎么操作 |
|-----------|---------|
| 新建空间 | 左侧栏点击「+」 |
| 切换模型 | 右上角下拉菜单 |
| 上传图片 | 输入框「+」或直接粘贴/拖拽 |
| 清空对话上下文 | 输入框发送 `/compact` |
| 开启 AI 浏览器 | 输入框左下角的地球图标 |
