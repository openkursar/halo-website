# 6. 配置邮箱

配置邮箱后，数字人可以帮你收发邮件、搜索邮件、管理日历。你可以让它：
- 每天早上汇总未读邮件，按优先级分类
- 帮你写邮件并发送
- 查看本周的会议安排

这一步是可选的——如果你暂时不需要邮件功能，可以跳过。

::: warning 先了解：邮件功能只在数字人 / Bot 入口生效
邮件工具**只能在数字人的对话或企业微信 Bot 中**调用，**普通空间对话里用不了**。这是产品设计——普通空间主要用于写代码等任务，加载过多工具会影响 AI 效果。

所以配置完成后，记得到[「在数字人中启用邮件功能」](#在数字人中启用邮件功能)手动开启，再到数字人 / Bot 入口使用。
:::

---

## 你需要准备什么

一个**邮箱客户端独立密码**。这不是你的邮箱登录密码，而是专门给第三方应用使用的授权密码。

::: warning 为什么不能用登录密码？
大部分邮件服务商出于安全考虑，不允许第三方应用直接用登录密码访问。你需要在邮箱网页版的设置中生成一个「客户端专用密码」或「应用专用密码」。
:::

---

## 获取客户端独立密码

不同邮箱的操作方式略有不同，但流程类似。以常见的企业邮箱为例：

### 步骤 1：登录邮箱网页版

用浏览器打开你的邮箱网页版，登录你的账号。

### 步骤 2：进入安全设置

1. 找到 **「设置」**（通常在页面左下角或右上角）
2. 找到 **「安全」**（Security）选项

<!-- screenshot: email-step2.png — 邮箱设置页面，标注"安全"入口 -->

### 步骤 3：生成客户端独立密码

1. 找到 **「客户端独立密码」**（Client-specific password）或类似选项
2. 点击 **「生成密码」**（Generate Password）
3. 给这个密码取一个名字（比如 `halo`）
4. **复制生成的密码**——关闭后就看不到了

<!-- screenshot: email-step3.png — 客户端独立密码生成界面 -->

::: tip 常见邮箱的操作路径
| 邮箱 | 路径 |
|------|------|
| QQ 邮箱 | 设置 → 账户 → 生成授权码 |
| 网易邮箱 | 设置 → POP3/SMTP/IMAP → 开启并获取授权码 |
| Gmail | Google 账户 → 安全 → 应用专用密码 |
| Outlook | 一般直接使用登录密码即可 |
:::

## 在 Halo 中配置

### 步骤 4：打开消息通道设置

1. 点击 Halo **右上角设置**
2. 找到 **「消息通道」**（Message Channels）区域
3. 找到 **「Email」** 或 **「电子邮箱」** 卡片，点击展开

<!-- screenshot: email-step4.png — Email 卡片位置 -->

### 步骤 5：填写邮箱信息

填入以下信息：

| 字段 | 填什么 | 示例 |
|------|--------|------|
| **Username** | 你的邮箱地址 | `zhangsan@company.com` |
| **Password** | 步骤 3 中获取的客户端独立密码 | （粘贴密码） |
| **IMAP Host** | 收件服务器地址 | `imap.company.com` |
| **SMTP Host** | 发件服务器地址 | `smtp.company.com` |
| **SMTP Port** | 发件端口 | `465` |
| **Default Recipient** | 默认收件人（通常填自己） | `zhangsan@company.com` |

<!-- internal:email-servers -->

<!-- screenshot: email-step5.png — 邮箱配置界面，各字段标注 -->

::: tip 不知道 IMAP / SMTP 地址怎么填？
常见邮箱的服务器地址：

| 邮箱 | IMAP Host | SMTP Host | SMTP Port |
|------|-----------|-----------|-----------|
| QQ 邮箱 | `imap.qq.com` | `smtp.qq.com` | `465` |
| 网易 163 | `imap.163.com` | `smtp.163.com` | `465` |
| Gmail | `imap.gmail.com` | `smtp.gmail.com` | `465` |
| Outlook | `outlook.office365.com` | `smtp.office365.com` | `587` |

如果是公司邮箱，问一下 IT 部门或在邮箱网页版的设置页面查找。
:::

### 步骤 6：测试连接

点击 **「测试」** 按钮。

<!-- screenshot: email-step6.png — 测试按钮和测试结果 -->

| 测试结果 | 说明 |
|---------|------|
| 测试通过 | 配置正确，可以使用了 |
| 连接失败 | 检查服务器地址和端口是否正确 |
| 认证失败 | 检查用户名和密码（是否用了客户端独立密码而不是登录密码） |

::: warning 报错 "unable to verify the first certificate"？
这是 TLS 证书验证问题，通常出现在公司内网邮箱环境中。请联系 IT 部门确认邮件服务器的证书配置，或咨询 Halo 管理员获取解决方案。
:::

## 在数字人中启用邮件功能

邮箱配置好后，还需要在数字人中**手动开启邮件工具**。默认是关闭的。

1. 进入数字人详情页
2. 在设置区域找到邮件相关的开关
3. 开启它

<!-- screenshot: email-enable.png — 数字人中开启邮件功能的开关 -->

开启后，你可以在**数字人的对话界面**或通过**企业微信 Bot** 跟它说：

```
帮我查看今天的未读邮件
```

```
帮我写一封邮件给 lisi@company.com，主题是项目进度更新，
内容是：本周完成了需求分析，下周开始设计阶段。
```

```
帮我看看本周的日历安排
```

::: warning 邮件功能只在数字人中可用
邮件工具只能在**数字人的对话**中使用，普通空间对话里无法调用。这是产品设计——普通空间主要用于写代码等任务，加载过多工具会影响 AI 效果。
:::

## 邮件功能能做什么？

配置完成后，数字人可以使用以下工具：

### 邮件操作

| 功能 | 说明 |
|------|------|
| 列出邮件 | 查看收件箱或指定文件夹的邮件列表 |
| 读取邮件 | 查看单封邮件的完整内容 |
| 搜索邮件 | 按关键词、发件人、时间等条件搜索 |
| 发送邮件 | 发送新邮件 |
| 回复/转发 | 回复或转发已有邮件 |
| 管理邮件 | 移动、标记已读/未读、删除 |
| 查看附件 | 读取邮件中的附件内容 |

### 日历操作（需要邮箱支持 CalDAV）

| 功能 | 说明 |
|------|------|
| 查看日历 | 列出指定时间范围内的日程 |
| 创建日程 | 创建新的会议/事项 |
| 删除日程 | 删除已有日程 |

## 使用场景举例

**场景 1：每日邮件摘要**
> 创建一个数字人，每天早上 8 点汇总未读邮件，按优先级分类，把重要邮件摘要发系统通知给我。

**场景 2：日程助手**
> 帮我查看本周的会议安排，如果周三下午有空，帮我创建一个和李明的 1:1 会议。

**场景 3：邮件搜索**
> 搜索过去一个月来自 vendor@supplier.com 的邮件，把所有带附件的邮件列出来。
