# 2. 配置 AI 模型

Halo 本身是一个工具，它需要连接一个 AI 模型才能工作——就像浏览器需要连接网络才能上网一样。

这一步我们来告诉 Halo 使用哪个 AI 模型。

---

## 你需要准备什么

一个 **API Key**（接口密钥）。这是 AI 模型提供商给你的一串密码，用来验证你的身份和扣费。

获取方式取决于你的情况：

| 情况 | 怎么获取 API Key |
|------|----------------|
| **公司统一提供** | 联系公司内部管理员获取，通常会给你一个 URL 地址和一串 Key |
| **自己购买** | 在 AI 模型官网注册账号并充值，创建 API Key |

::: tip 没有 API Key？
如果你不确定怎么获取，先问一下给你推荐 Halo 的同事——他们通常会告诉你公司内部的获取方式。
:::

---

## 填写配置

### 第一步：打开设置

点击 Halo 界面**右上角的齿轮图标**，进入设置页面。

![设置入口](/images/setup-ai-entry.png)

### 第二步：找到 AI 模型配置

在设置页面中，找到 **「AI 供应商」**（AI Provider）区域。

![AI 供应商区域](/images/setup-ai-providers.png)


### 第三步：填写 API 信息

你拿到 API Key 的时候，提供方通常会一起告诉你两样东西：

- **API 地址**（URL）：AI 服务的网络地址
- **API Key**：你的身份密钥

在 Halo 中按以下步骤填写：

1. 点击 **「添加 AI 供应商」**
2. 选择 **「供应商」** 下拉菜单（「OpenAI 兼容」或「Claude API 兼容代理」二选一，选哪个取决于大模型提供方告诉你的类型，如果没特别说明，选「OpenAI 兼容」）

![添加供应商](/images/setup-ai-add-provider.png)

3. 填写以下信息：
   - **API URL**：填提供方给你的地址
   - **API Key**：填提供方给你的 Key
4. 点击 **「获取模型」** 按钮——这会自动去拉取可用的模型列表
5. 从下拉列表中选择一个模型（如果不确定选哪个，问一下提供方推荐哪个），部分供应商获取不到列表，可以点击自定义模型ID，自己填入供应商给你的模型名。
6. 点击**保存**

![API 配置界面](/images/setup-ai-config.png)

::: tip 不确定选哪个供应商类型？
咨询给你提供 API Key 的供应商或管理员，他们会告诉你该选哪个。如果对方也说不清，先试「OpenAI 兼容」，大部分情况都能用。
:::

::: warning 点击"获取模型"没有反应或报错？
- 检查 API URL 是否填写正确（注意不要有多余的空格）
- 检查 API Key 是否复制完整
- 确认电脑能访问这个 URL 地址（如果是公司内网地址，需要在公司网络环境下操作）
:::

---

## 验证配置

配置完成后，回到 Halo 主界面，在输入框中输入：

```
你好
```

如果 AI 正常回复了，说明配置成功。

![AI 回复验证](/images/setup-ai-verify.png)

::: danger AI 没有回复或报错？
常见原因和解决办法：

| 报错信息 | 原因 | 解决 |
|---------|------|------|
| `fetch failed` | 网络不通，无法连接到 AI 服务 | 检查网络连接，确认 URL 地址是否正确 |
| `401` 或 `Unauthorized` | API Key 错误 | 检查 Key 是否复制完整，没有多余空格 |
| `429` 或 `rate limit` | 请求太频繁或额度用完 | 等一会再试，或检查账户余额 |
| `500` 或 `invoke model error` | AI 服务端异常 | 稍后重试，或换一个模型 |
:::

---

## 可以配多个模型吗？

可以。你可以同时添加多个 AI 供应商，然后在右上角随时切换。切换是全局生效的，所有空间都会使用当前选中的模型。比如：
- 日常对话用一个便宜的模型
- 重要任务用一个更强的模型

![模型切换下拉菜单](/images/setup-ai-switch.png)
