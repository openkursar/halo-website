# 技能

::: say
> 帮我装上商店里的 code-commit 技能

Halo 会按这个名字从商店安装技能，默认装到当前工作区；想让所有工作区都能用，就加一句「装到全局」。装好后，它出现在 **数字人 › 能力库 › 技能** 里。

**前提**：商店里要有这个名字的技能。不确定名字时，先到 **商店 › 技能** 搜一下。
:::

## 技能是什么 {#what-is-a-skill}

Halo 的技能是一个文件夹，里面有一个 `SKILL.md` 文件，写着 AI 做某类事情时要遵守的步骤、规范和示例。可以把它理解成「给 AI 的工作说明书」：写一次，以后每次都按同样的方式做。

技能有两种用法：

- **AI 自动选用**：AI 读每个技能的描述，判断当前任务用得上时自己加载，你不用点名。
- **你点名调用**：在输入框里输入 `/命令名`，例如 `/weekly-report`。

一个最小的技能长这样：

```
weekly-report/          ← 文件夹名就是命令名，调用时用 /weekly-report
└── SKILL.md
```

```markdown
---
name: weekly-report
description: 用户要写周报、整理本周工作时使用
---

1. 按「本周完成 / 进行中 / 下周计划」三段整理
2. 每条写清结果和负责人
3. 最后单独列出需要协调的问题
```

常见的技能用途：

| 技能 | 用途 |
|---|---|
| `weekly-report` | 按固定格式写周报 |
| `meeting-notes` | 把会议记录整理成纪要和待办 |
| `write-prd` | 按团队模板写产品需求文档 |
| `code-review` | 按团队规范审查代码 |

::: tip
`SKILL.md` 写得越具体，AI 做得越准。可以写进示例、限制条件和输出格式。所有字段、多文件技能和打包方式见[编写技能](/developers/skills)。
:::

## 使用技能 {#use}

- **让 AI 自己选**：直接说任务，例如「帮我写这周的周报」。描述匹配的技能会被自动加载。
- **用 `/` 点名**：在输入框输入 `/`，弹出的菜单里列着可用的技能和引擎自带的命令。用 <kbd>↑</kbd> <kbd>↓</kbd> 选择，<kbd>Enter</kbd> 确认，<kbd>Esc</kbd> 关闭。
- **从技能卡片开始**：在技能详情里点 **去使用**，输入框里会填好 `/命令名 `，接着写要求后发送。

`/` 菜单是否出现、列出哪些命令，取决于当前的 [AI Agent 引擎](/features/agent-engines)。在 Codex 引擎下菜单是空的，但 AI 仍可能按描述自动选用技能。新建的对话要等会话准备好或收到第一条回复后，菜单里才有内容。完整的命令列表见[命令与快捷键](/features/commands)。

## 管理技能的地方 {#manage}

所有已安装的技能都在 **数字人 › 能力库 › 技能**。这里是一面技能卡片墙，覆盖全局和每个工作区。

| 位置 | 作用 |
|---|---|
| **搜索技能** | 按名称和描述查找 |
| 作用域筛选 | **所有工作区**、**全局**，或某个工作区 |
| 来源筛选 | **所有来源**、**商店**、**自定义**、**内置**（含 Office 文档技能） |
| 卡片标记 | **手动**、**内置**、**捆绑**、**商店**，表示技能从哪里来 |
| 卡片按钮 | 电源图标 **启用** / **禁用**；**重新安装**；商店有新版本时出现 **更新至 v…** |
| **更多** 菜单 | **打开技能文件夹**（仅桌面版）、**移动到工作区**、**卸载** |
| 顶部按钮 | **手动添加技能**、**从市场安装** |

点卡片打开技能详情，能看到 **技能指令**（渲染后的 `SKILL.md`）。点 **编辑** 修改后保存；点 **保存自定义副本** 可以用新的 **命令名称** 另存一份，原技能不变，副本不再接收商店更新。命令名称只能用小写字母、数字和连字符。

技能是共享资源：修改、禁用或卸载，会影响同一作用域里的所有对话和数字人。在技能详情里保存修改、启用或禁用、改作用域和移除时，Halo 会先请你确认（例如「保存共享资源的更改？」）；从卡片的 **更多** 菜单卸载也会确认（「卸载此技能？」）。**卡片上的电源图标不确认**，点一下就立即启用或禁用。

### 禁用和卸载会删掉文件夹 {#disable-uninstall}

禁用或卸载技能时，Halo 会把它的文件夹从磁盘上删掉，AI 之后就加载不到它。Halo 自己保留着技能内容：重新 **启用**，或在 **已卸载** 分组里 **重新安装**，文件夹会按 Halo 保存的内容写回。

::: warning
直接在技能文件夹里手改的文件，禁用或卸载时会随文件夹一起删掉。要改 Halo 管理的技能，请用技能详情里的 **编辑**。
:::

### 未托管的技能 {#unmanaged}

你自己放进技能文件夹的技能，Halo 也能发现并使用。它们显示在 **未托管** 分组里，只有 **打开文件夹** 一个操作，不能在这里启用、禁用或卸载，要改就直接改文件夹里的文件。

## 从商店安装 {#install-from-store}

商店汇集了多个来源的现成技能。

1. 打开左侧导航栏的 **商店**，切到 **技能** 标签页。也可以在 **数字人 › 能力库 › 技能** 点 **从市场安装**，直接打开商店的技能列表。
2. 搜索或按分类找到技能，点开详情。详情里能看到技能文档和它的依赖项。
3. 点 **添加**。
4. 在 **安装到** 里选 **全局（所有工作区）** 或某个工作区，点 **安装**。需要下载多个文件的技能会显示进度。
5. 卡片变成 **已添加**，详情里出现 **去使用**。

安装和更新需要联网，离线时按钮显示 **离线**。单独安装技能时，它声明的其他技能不会自动装上，见[技能依赖](#dependencies)。浏览、更新和来源设置见[商店](/digital-humans/store)。

## 自己添加技能 {#add-skill}

在 **数字人 › 能力库 › 技能** 点 **手动添加技能**，打开添加技能对话框。它有三种方式：

| 方式 | 适合 | 怎么填 |
|---|---|---|
| **可视化** | 从零写一个简单技能 | 填 **技能名称**（必填）、**描述**（写清 AI 什么时候该用它）、**使用说明**。命令名按名称自动生成，点铅笔图标可以改，只能用 `a-z`、`0-9` 和 `-` |
| **Markdown** | 直接写完整的 `SKILL.md` | 文件开头的 `name` 和 `description` 必填 |
| **导入** | 已经有现成的技能 | 拖入，或点 **浏览技能文件夹...** 选择，见下表 |

**导入** 支持的内容：

| 导入内容 | 要求 |
|---|---|
| **单个 .md 文件** | 当作单文件技能，自动改名为 `SKILL.md` |
| **技能文件夹** | 根目录里要有 `SKILL.md` |
| **.zip 压缩包** | 文件可以在压缩包根目录，也可以在唯一的一层文件夹里；最大 10 MB |

最后在 **安装到** 里选 **全局（所有空间）**、Halo 工作区或某个工作区（默认是当前工作区），保存即可。写到一半想先关掉，点 **关闭并保留草稿**，下次打开还在。

添加技能对话框在桌面版和网页版里都能用。

::: tip
也可以把你的做法讲给 Halo 听，再说「把它做成一个技能装上」，Halo 会写好 `SKILL.md` 并安装。
:::

用过 Claude Code，技能放在 `~/.claude/skills/`？可以在 **设置 › 高级 › Claude CLI 集成** 里点 **从 Claude CLI 迁移技能** 一次导入，见[从 Claude Code / Codex 迁移](/guide/from-claude-code)。

## 全局技能和工作区技能 {#scope}

每个技能要么是全局的，要么只属于一个[工作区](/features/spaces)。

| | 全局技能 | 工作区技能 |
|---|---|---|
| 谁能用 | 所有工作区里的对话和数字人 | 只有这个工作区里的对话和数字人 |
| 卡片上写着 | 「在所有工作区中可用」 | 「仅在此工作区中可用：」加工作区名 |
| 存在哪里 | Halo 配置目录下的 `skills` 文件夹 | 工作区工作目录下的 `.claude/skills/` |

- **同名时工作区优先**：工作区技能和全局技能的文件夹名（也就是命令名）相同时，这个工作区里用的是工作区版本。比较的是命令名，不是显示名称。
- **装好后再换作用域**：在卡片的 **更多 › 移动到工作区** 里选 **全局（所有工作区）** 或某个工作区。
- 全局技能的位置跟着 **设置 › 高级 › Claude CLI 集成 › 配置目录** 走，默认是 **Halo 默认**。各系统的具体路径见[数据与配置位置](/advanced/config-paths)。

## 导出技能 {#export}

<Badge type="info" text="仅桌面版" />

想把技能发给同事，可以导出成 `.zip`：

1. 打开技能详情，点 **分享**。
2. 点 **导出**（「保存一个可手动共享的包文件」），选择保存位置。
3. 看到「已保存至」加文件路径，就导出好了。压缩包里是技能的整个文件夹，`SKILL.md` 在根目录。

同事用[添加技能对话框](#add-skill)的 **导入** 就能装上。网页版和安卓 App 里不能导出。想发布到商店，在同一个对话框里点 **分享到商店**，见[发布到商店](/developers/store-publishing)。

## 把已有技能复制到工作区 {#copy}

另一个工作区里有好用的技能，可以复制一份到当前工作区：

1. 打开当前工作区里的一位数字人，进入 **能力与设置 › 工具与资源 › 可用技能**。
2. 点 **选择现有的**，打开「选择现有技能」。
3. 找到要的技能，点 **复制到此工作区**。原技能保持不变，复制后这个工作区里的所有人都能用。

列表里每行会标出状态：**已可用**（当前工作区本来就能用）、**在此工作空间中已被覆盖**、**已在共享设置中禁用**、**名称已存在**。

## 内置的 Office 文档技能 {#office-skills}

Halo 自带 `docx`（Word）、`xlsx`（Excel）、`pptx`（PowerPoint）、`pdf` 四个全局技能，以及诊断用的 `office-runtime-check`。它们在 Halo 自带的运行环境里执行，不用另装 Office、Node.js 或 npm。

- 说「帮我做一份 PPT」，AI 会自己选用 `pptx`；也可以输入 `/docx`、`/xlsx`、`/pptx`、`/pdf` 点名。
- 在能力库里它们带 **捆绑** 标记，来源筛选选 **内置** 能看到。
- 卸载后重启 Halo 也不会自动装回，需要时在 **已卸载** 分组里重新安装。

能做什么、有哪些限制，见 [Office 文档](/features/office-documents)。

## 数字人怎么用技能 {#digital-humans}

[数字人](/digital-humans/overview)可以使用其工作区内及全局安装的所有技能。技能不是某位数字人私有的：同一个工作区里的数字人和对话，用的是同一套技能。

在数字人的 **能力与设置 › 工具与资源 › 可用技能** 里能看到它可用的技能，每行标着 **全局** 或 **此工作区**，工作区版本覆盖了全局版本时也会注明。这里还能直接 **选择现有的**、**新建技能**、**导入**，或打开技能商店安装。

::: warning
这里的改动会影响同一作用域里的其他数字人和对话，页面上也写着「技能继承自当前工作区和全局设置。更改可能会影响同一作用域中的其他数字人。」
:::

从商店安装数字人时，它带的技能会先装好；卸载这位数字人时，它带来的技能也会一起移除。各项设置见[能力与设置](/digital-humans/capabilities)。

## 访客能用哪些技能 {#guests}

你自己和数字人对话时，所有可用技能都能用。别人通过企业微信、飞书等机器人找数字人（访客），或其他电脑上的队友借用数字人时，技能要一个一个放开：

1. 打开机器人的 **访客权限**，开启 **访客访问权限**。
2. 在 **访客允许使用的工具** 的 **技能** 分组里，只开要给访客用的技能。默认全部关闭。

开了某个技能，不等于放开它要做的事。技能可以读取自己的文件夹；运行命令、更改文件、发邮件等操作，仍要看同一页上的其他开关。技能预先批准的工具超出这些开关时，它不会运行。例如 Office 文档技能要运行命令才能生成文件，访客默认用不了。

访客的完整权限见[主人与访客权限](/digital-humans/permissions)，队友的权限见[跨电脑团队](/digital-humans/cross-computer-teams)。

## 在对话里查看可用技能 {#workspace-resources}

在对话页点顶栏的 **展开工作区资源**，切到 **技能** 标签页，能看到当前工作区能用的所有技能（工作区技能，加上没被覆盖的全局技能）。这是只读列表：

- 每行带 **全局** 或 **此工作区** 标记。
- 单击一行，在画布中打开它的 `SKILL.md`。
- 悬停时点 **去使用**，输入框里会填好 `/命令名 ` 并显示技能描述。

一个都没有时显示「暂无可用的技能。」。资源栏的其他标签页见[文件与画布](/features/files-and-canvas)。

## 技能依赖 {#dependencies}

技能可以声明它需要的 [MCP 连接](/features/mcp)和其他技能：

- 从商店安装数字人时，它声明的技能会一起装好，有一个装不上就整体回滚。单独安装技能时，它声明的其他技能不会自动安装，需要另外装上。依赖的依赖不会继续展开。
- MCP 连接不会自动装上。数字人的 **可用技能** 里，声明了 MCP 连接的技能会显示「所需连接：」加连接名，缺的连接要你在能力库里添加。
- 发布到商店时，Halo 会检查依赖能否找到。

怎么声明依赖，见[编写技能](/developers/skills#dependencies)。

## 遇到问题 {#troubleshooting}

### 输入 / 后菜单里没有我的技能

- 先确认技能已启用，且作用域包含当前工作区：在 **展开工作区资源 › 技能** 里看看有没有它。
- 新建的对话要等第一条回复后菜单才完整。可以从技能详情点 **去使用**，命令会直接填进输入框。
- 在 Codex 引擎下 `/` 菜单始终是空的，这时直接说任务，或写明「用 weekly-report 技能」。

### 添加时提示「此作用域中已存在同名技能。请选择其他命令名称，或从能力库中编辑现有技能。」

同一个作用域里已经有这个命令名。点铅笔图标换一个命令名，或者到能力库里编辑已有的那个。

### 导入时提示「不支持的文件类型。请拖放 .md 文件、.zip 压缩包或技能文件夹。」

只能导入 `.md` 文件、`.zip` 压缩包或带 `SKILL.md` 的文件夹。压缩包不能超过 10 MB。

### 网页版里找不到导出，或打不开技能文件夹

导出 `.zip` 和 **打开技能文件夹** 只能在桌面版里用。网页版会提示「在桌面客户端中打开以查看技能文件夹。」

### Halo 说商店里找不到这个技能

Halo 按名字到商店里找，名字对不上就装不了。到 **商店 › 技能** 搜一下，确认商店里有这个技能；找到后在详情里点 **添加** 安装最直接。

### 技能在「未托管」分组里，不能禁用

这是你手动放进技能文件夹的技能，Halo 没有它的安装记录。点 **打开文件夹**，在文件夹里直接删除或修改。
