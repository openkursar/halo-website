# 任务面板

::: say
> 新闻助手上次跑得怎么样？

Halo 会查这位数字人的运行状态、上次运行时间和最近一次的结果，再告诉你。问团队也可以：「市场调研团队现在进展到哪了？」Halo 会读取这个团队最近一次工作的进度。

**前提**：数字人或团队在你当前对话所在的工作区里。想问另一个对话的进度，看 [会话之间互相协作](/features/cross-conversation)。
:::

## 打开任务面板 {#open}

1. 点导航栏底部的 **任务**。图标上的数字是条目数，超过 99 显示「99+」。面板在导航栏旁边展开，宽 340 px，会把右边的内容推开。
2. 窗口很窄时（Android 应用，或浏览器窗口窄于 640 px），点顶栏的 **导航**，再点 **任务**。面板从底部弹出，最高占屏幕的 70%。
3. 在新对话的首页，点 **继续最近的任务** 也会打开任务面板。
4. 看面板顶部的摘要，例如「需要你处理 2 · 运行中 1」。
5. 用面板右上角的 × 关闭。底部弹出时，点面板外的区域也能关闭。

面板列出所有工作区的条目，不只是当前工作区。桌面版、通过 [远程访问](/features/remote-access) 打开的浏览器和 Android 应用看到的是同一份列表，一边有变化，另一边会同步更新。

没有任何条目时，面板显示「暂无进行中的任务」和「此处显示任务和已固定对话」。

::: info 从 2.x 升级过来
2.x 把置顶的对话放在会话列表里。从 3.0 起，它们和运行中的工作一起，移到了导航栏的任务面板。
:::

## 三个分组 {#groups}

任务面板分成 **需要你处理**、**运行中**、**已置顶** 三组。导航栏上的数字统计除「已置顶」以外的所有条目。

| 分组 | 里面是什么 |
|---|---|
| **需要你处理** | AI 在对话里向你提问；数字人在等你、登录过期或多次失败；团队在等你决策；出错的对话；已经完成但你还没看的对话 |
| **运行中** | 正在生成回复的对话；正在运行或排队的数字人 |
| **已置顶** | 你固定过、当前没有待处理事项的对话 |

条目按紧急程度排序：等你回答的 › 出错的 › 完成未看的 › 运行中的 › 已置顶的。同一级里，最近更新的排在前面。

每一行右上角显示它所在的工作区名，鼠标悬停显示「工作区：工作区名」。不属于任何工作区的数字人显示 **全局**。团队不显示工作区名。

### 需要你处理 {#needs-you}

「需要你处理」组收集所有在等你的事：

- **对话里的提问**：AI 在对话里弹出问题卡片，等你回答。
- **数字人在等你**：显示它的问题；没有问题文字时显示「等待您的输入」。
- **数字人登录过期**：显示「登录已过期，请重新登录」。
- **数字人出错**：显示最近的错误；多次失败后显示「多次失败，已暂停」。
- **团队等你决策**：显示「等待您的决策」。临时协作不会出现在这里。
- **出错的对话**：你自己停止的对话不算出错，不会进这一组。
- **完成未看**：对话跑完了，但你还没打开看过。

### 运行中 {#running}

「运行中」组列出正在生成回复的对话和正在工作的数字人。运行中的数字人显示已用时间，格式是「分:秒」或「时:分:秒」。排队的数字人显示 **已排队**。

### 已置顶 {#pinned}

「已置顶」组放你固定过、当前没有待处理事项的对话。一个置顶对话开始运行或需要你处理时，会暂时移到对应的分组。

固定或取消固定一个对话：

1. 把鼠标移到任务面板里的对话行上。
2. 点 **固定**，对话进入「已置顶」组。再点 **取消固定**，它就离开这一组。

按钮写的是 **固定**，分组标题写的是 **已置顶**，两者指的是同一件事。只有普通对话能在任务面板里固定。数字人对话要在会话列表里固定，见 [会话](/features/conversations)。

## 打开一项任务 {#open-item}

点任务面板里的一行，Halo 会带你回到那件事：

| 条目 | 点开后 |
|---|---|
| 对话 | 打开这个对话。它在别的工作区时，Halo 会先切换到那个工作区 |
| 数字人对话 | 打开和这位数字人的对话 |
| 数字人的运行 | 打开 **数字人 › 我的数字人** 里这位数字人的 **工作动态**。在等你时，直接跳到那个问题，回答后点 **提交并继续这项工作** |
| 团队 | 打开 **数字人 › 团队** 里这个团队的工作台 |

想一次看完所有数字人和团队的问题，打开 **数字人 › 我的数字人**，点 **全部处理（N 项）**，进入「需要我的关注」。详见 [管理数字人](/digital-humans/manage)。

## 看过后保留或移除 {#keep-or-remove}

你打开一个已完成或出错的对话后，它在任务面板里还会留 60 秒：

1. 这一行变淡，底部出现 60 秒的倒计时条。
2. 鼠标悬停时显示「即将移除」，以及 **保留** 和 **移除** 两个按钮。
3. 点 **保留**，这一行一直留着，直到你点 **移除**。
4. 什么都不点，倒计时结束后这一行自动移除。

数字人的运行和团队不走这个流程：它们不再运行、也不再等你时，直接离开面板，没有倒计时。

完成未看的对话、点过 **保留** 的对话，Halo 会存下来。Halo 关着或窗口隐藏时跑完的工作，重启后仍在「需要你处理」里。对话、数字人或工作区被删除后，对应的条目也会消失。

## 任务面板里没有的 {#not-in-panel}

- **没有停止按钮**：要停下一项工作，打开它再停。
- **不能在面板里直接回答**：点开条目，在对话或工作动态里回答。
- **这些对话不会出现**：飞书、企业微信等消息通道里的聊天，团队成员之间的对话，以及知识库里的问答对话。

## 会话旁的状态点 {#status-dots}

不用打开对话，看颜色就知道它的状态：

| 颜色 | 含义 |
|---|---|
| 蓝色 | 正在生成回复 |
| 琥珀色 | 在等你回答 |
| 绿色 | 已完成，你还没看 |
| 红色 | 出错 |
| 没有点 | 空闲 |

状态点出现在会话列表的每一行、聊天历史面板，以及输入 @ 选对话时的列表里。会话列表某一组折叠后，组标题上显示这组里最紧急的那个颜色。会话列表收起成头像时，状态点显示在头像上。

## 任务完成通知 {#notifications}

<Badge type="info" text="仅桌面版" />

想在切到别的软件时知道 AI 干完了：

1. 打开 **设置 › 系统**。
2. 打开 **任务通知**（「后台任务完成时通知我」）。这个开关默认是关的。
3. 确认操作系统允许 Halo 发送通知。

之后，只要 Halo 窗口不在前台，每次 AI 回复完一轮，系统都会弹出标题为「Halo」的通知。Halo 窗口在前台时不会弹。

| 情况 | 会不会通知 |
|---|---|
| 一轮回复完成（包括后台跑的 [代码评审](/features/code-review) 对话） | 会 |
| AI 在等你回答问题 | 不会。只看得到琥珀色状态点和「需要你处理」组 |
| 远程访问的浏览器或 Android 应用 | 不会，只在运行 Halo 的电脑上弹 |

点通知会把 Halo 窗口带到前台，但不会打开那个对话。通知正文目前只有英文：`Task complete: <对话标题>`。

数字人的通知是另一套，不受 **任务通知** 开关影响。数字人需要你决定、报告进展或交付结果时：Halo 窗口在前台，应用里弹出提示（每位数字人只保留最新的一条）；窗口不在前台，系统弹出通知，点它会打开这位数字人的工作动态。

## 关掉窗口后工作继续 {#window-closed}

AI 回复、数字人和代码评审都在后台运行，关掉窗口不会让它们停下。各系统表现不同：

<PlatformTabs>
<template #macos>

点窗口的关闭按钮，窗口隐藏，Halo 仍在 Dock 里，工作继续。点 Dock 图标、菜单栏 Halo 图标里的 **Show Halo**，或重新打开 Halo，窗口就回来了。

</template>
<template #windows>

点窗口的关闭按钮，Halo 隐藏到系统托盘，工作继续。点托盘图标或重新打开 Halo，窗口就回来了。

</template>
<template #linux>

关闭最后一个窗口会退出 Halo，所有工作随之停止。想让工作继续，把窗口最小化，不要关闭。

</template>
</PlatformTabs>

有工作在后台运行时，在托盘菜单里点 **Quit Halo**，Halo 会先请你确认。窗口隐藏期间完成的工作，回来后会出现在「需要你处理」组。

想让数字人一直在线，看 [让数字人一直在线](/digital-humans/keep-running)。

::: done
导航栏的 **任务** 上出现数字，点开能看到「需要你处理」或「运行中」的条目，点一行就回到那件事，就说明任务面板在正常工作。
:::

## 遇到问题 {#troubleshooting}

### 后台跑完了，却没收到通知

- 确认 **设置 › 系统 › 任务通知** 已打开，它默认是关的。
- Halo 窗口在前台时不会弹通知。
- 在系统设置里检查 Halo 的通知权限。
- 远程访问的浏览器和 Android 应用收不到这类通知。

### AI 在等我回答，却没有通知

这是目前的设计：AI 等你回答时不发系统通知。留意会话旁的琥珀色状态点，或任务面板的「需要你处理」组。数字人等你决定时会单独通知。

### 打开过的对话过一会儿从面板消失了

看过的已完成或出错的对话只保留 60 秒。想留下它，在倒计时期间悬停这一行，点 **保留**。

### 飞书或企业微信里的聊天不在任务面板里

消息通道里的聊天、团队成员之间的对话和知识库问答都不会进任务面板。数字人在消息通道里的工作，到 **数字人 › 我的数字人** 里查看。

### 导航栏的数字和列表里的条目数对不上

导航栏的数字不统计「已置顶」组里的对话，只统计需要你处理和运行中的条目。

### 在 Linux 上关掉窗口后，数字人停了

在 Linux 上，关闭窗口会退出 Halo。改用最小化，或参考 [让数字人一直在线](/digital-humans/keep-running)。
