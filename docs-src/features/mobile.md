# 在手机上用 Halo

手机连接和远程访问的设置不对 AI 开放，Halo 没法替你打开远程访问或添加设备，下面的步骤需要你自己操作。

手机上有两种用法：

| 我想… | 用这个 |
|---|---|
| 在安卓手机上长期用，保存几台电脑，App 在后台时也能收到完成通知 | [安卓 App](#android-app) |
| 不装 App，或者用的是 iPhone | [手机浏览器](#phone-browser) |

两种方式打开的都是电脑上的同一个 Halo：同一套会话、工作区、数字人和知识库。手机只是一个遥控端，AI 本身不在手机上运行，模型调用、文件读写和命令都发生在电脑上。

## 开始之前 {#before-you-start}

- **电脑上已打开远程访问**：在电脑的 Halo 桌面版里打开 **设置 › 远程访问 › 启用远程访问**，步骤见 [打开远程访问](/features/remote-access#turn-on)。手机上没有这个设置。
- **电脑要开着，Halo 要在运行**：电脑关机、休眠或退出了 Halo，手机就连不上。在 macOS 和 Windows 上关掉窗口 Halo 仍在后台运行；在 Linux 上关掉窗口就是退出。想让它一直在线，见 [让数字人一直在线](/digital-humans/keep-running)。
- **手机能连到电脑**：和电脑在同一个 Wi-Fi 时用 **局域网地址**；不在同一个网络时，先在电脑上打开 [互联网访问](/features/remote-access#internet-access)，用 **永久地址**。
- **准备好访问密码**：在电脑的 **设置 › 远程访问 › 访问密码** 点 **复制**，发到手机上。密码区分大小写，粘贴比手输更稳。

也可以连接一台 [Halo Server](/server/)，用法和连接电脑一样，见 [连接多台电脑](#several-computers)。

## 安卓 App {#android-app}

安卓 App 适合每天在手机上用：它能保存多台电脑，在后台保持连接，任务完成时发通知。

| 项目 | 说明 |
|---|---|
| 系统要求 | Android 7.0 及以上 |
| 安装包 | `.apk` 文件，需要在手机上手动安装 |
| 它做什么 | 连接你电脑上的 Halo 或一台 Halo Server，自己不运行 AI |

<!-- public:start -->
安装包在 [Halo 官网的下载区](https://hello-halo.cc/#download)，选 Android 的那一个。文件名和其他系统的安装包见 [安装 Halo](/getting-started/install#download)。
<!-- public:end -->

### 连接电脑 {#connect}

1. 打开 App。第一次打开时显示 **连接到您的桌面**。
2. 在 **服务器地址** 里填电脑上显示的地址，例如 `192.168.1.100:3456`（这也是输入框里的示例）。地址在电脑的 **设置 › 远程访问** 里，同一个 Wi-Fi 用 **局域网地址**，在外面用 **永久地址**。不写 `http://` 时 App 会自动补上。
3. 点 **连接**。App 会检查这个地址上是否有 Halo 在运行，最多等 10 秒。
4. 进入第二步 **访问码**（提示文字「PIN 或密码」）。这里填的就是电脑上的 **访问密码**，粘贴后点 **继续**。少于 8 个字符时 **继续** 不可点。
5. 验证通过后，App 打开 Halo 的界面，里面是电脑上的会话。

地址填错了，在第二步点地址旁边的 **更改** 回去重填。

**用二维码代替手输地址**：电脑开着 [互联网访问](/features/remote-access#internet-access) 时，**设置 › 远程访问** 里会出现 **扫码访问** 二维码。在第 2 步点 **扫描二维码**，按「将您的相机对准桌面 Halo 上的二维码」扫码，地址会自动填好，然后照样输入访问码。第一次扫码时 App 会请求相机权限。

- 局域网地址没有二维码，只能手输。
- 二维码里只有地址，不含密码，所以扫完仍要填访问码。

::: done
App 打开了 Halo 的界面，能看到电脑上已有的会话，就说明连好了。下次打开 App 会自动连上这台电脑。
:::

### 后台连接和通知 {#notifications}

- **后台保持连接**：登录后，App 会在通知栏常驻一条低优先级通知「Halo · Connected to desktop」（这条是英文）。它让 App 在后台也保持连接，被系统结束后会自己重新启动。切换到别的电脑时，这个连接才会断开。
- **通知权限**：第一次运行时 App 会请求通知权限，请允许。
- **什么时候通知**：只在 App 处于后台时才发，App 在前台时不打扰你。

| 通知 | 什么时候出现 |
|---|---|
| 「任务完成」·「您的 AI 任务已完成。」 | 这台电脑上有一轮 AI 回复完成 |
| 「应用完成」·「数字人已运行完毕。」 | 一位数字人跑完一次运行 |
| 「需要操作」+ 问题内容，或「数字人需要您的输入。」 | 数字人有问题要你决定 |

「任务完成」针对的是这台电脑上的所有会话，不只是你在手机上打开的那个。所以在电脑上或由数字人发起的任务完成时，手机也会收到。

Halo 不使用推送服务，通知由 App 自己发出。如果系统仍然结束了 App，就收不到通知，回到 App 后会自动补上错过的内容。

### 安卓 App 的其他操作

- **返回键**：在设置、数字人、知识库等页面按返回键回到工作区；在添加设备页按返回键回到设备列表。返回键不会退出 App。
- **连接是明文的**：局域网地址走 `http://`，传输不加密。在公共 Wi-Fi 或在外面连接时，请用互联网访问的 HTTPS 永久地址。
- **App 会在手机上保存密码**：每台电脑的访问密码都保存在这台手机里。手机给别人用之前，先在 [设备列表](#several-computers) 里移除这些电脑。

## 连接多台电脑 {#several-computers}

App 可以保存多台电脑或 Halo Server，随时切换。

1. 在 Halo 界面里点顶部右侧的显示器图标（屏幕较宽时旁边显示当前电脑的名字），回到 **我的设备**（「选择要连接的设备」）。
2. 每台电脑显示 **在线** 或 **离线**。点一台 **在线** 的电脑就切换过去。
3. 要加一台，点 **添加设备**，在 **添加新设备** 页按 [连接电脑](#connect) 的步骤填地址和访问码。

关于设备列表：

| 项目 | 说明 |
|---|---|
| 名字 | 自动取地址里的主机名（例如 `192.168.1.100`），不能改名 |
| 同一个地址再加一次 | 不会多出一条，只更新保存的访问密码 |
| 删除 | 在卡片上向左滑，点出现的删除按钮，在「是否移除此设备？」里点 **移除** |
| 电脑改了访问密码 | App 会回到 **我的设备**，重新添加这台电脑并输入新密码即可 |

**连接 Halo Server**：[Halo Server](/server/) 是在 Linux 容器里运行、没有窗口的 Halo。添加设备时填它的地址（默认端口 `8080`，例如 `http://example.com:8080`），访问码填部署时设置的 `HALO_REMOTE_PASSWORD`。这个密码至少要 8 个字符，否则 App 无法登录；部署方法见 [Halo Server 快速开始](/server/)。

## 手机浏览器 {#phone-browser}

不想装 App，或者用 iPhone 时，可以直接在手机浏览器里打开 Halo。

1. 在手机浏览器里打开电脑上显示的地址：同一个 Wi-Fi 用 **局域网地址**（例如 `http://192.168.1.100:3456`）；在外面用 **永久地址**，或者用手机相机扫 **扫码访问** 二维码。
2. 页面显示英文登录页「Halo Remote Access」。
3. 在输入框（提示文字「Access Code」）里输入电脑上的 **访问密码**，点 **Connect**。
4. 显示「Connected! Loading...」后，Halo 的界面就打开了。

::: done
浏览器里出现 Halo 的界面，能看到电脑上的会话，就说明连好了。浏览器会记住登录，下次打开同一个地址不用再输密码。
:::

手机浏览器和安卓 App 的区别：

| | 安卓 App | 手机浏览器 |
|---|---|---|
| 保存多台电脑 | 有 **我的设备** 列表 | 每台电脑一个地址，自己收藏 |
| 扫码连接 | App 内 **扫描二维码** | 用手机相机扫码打开地址 |
| 后台保持连接 | 有 | 没有，切回浏览器时自动重连 |
| 系统通知 | 有，App 在后台时发 | 没有 |

登录页「Halo Remote Access」只有英文，这是正常的。电脑改了访问密码后，浏览器会回到这个登录页，用新密码重新登录即可。

## 手机上的界面 {#narrow-layout}

在安卓 App 里，或者手机浏览器的屏幕宽度小于 640 像素时，Halo 换成窄屏布局。电脑上的桌面版窗口不会变成这种布局。

- **导航**：左侧导航栏换成顶部的 **导航** 按钮，点开是一个底部面板，里面有 **会话**、**数字人**、**知识库**、**商店**、**任务** 和 **设置**。
- **对话历史**：会话列表收进顶部的 **对话历史** 按钮，点开后可以切换、置顶、重命名或删除会话。旁边的 **工作空间** 按钮用来切换工作区。会话本身的用法见 [会话](/features/conversations)。
- **更多**：右上角的按钮收进 **更多**，点开是一个底部面板：

| 项目 | 说明 |
|---|---|
| **模型** | 显示当前模型，点开切换。在数字人的对话里会打开这位数字人的模型设置 |
| **搜索** | 搜索会话、文件、任务、知识库和数字人 |
| **设置** | 打开设置，部分分区只在桌面版有，见 [只能在电脑上做的事](#desktop-only) |
| **打开终端** | 在当前工作区打开终端，命令在电脑上运行。只在电脑是 macOS 或 Windows、并且打开了工作区时出现 |
| **变更** | 查看和提交当前工作区的 Git 变更，Git 在电脑上运行。需要先打开工作区 |

**打开浏览器** 在桌面版的 **更多** 里有，但在手机上不会出现，见下一节。

在手机上打开文件或 [变更](/features/code-review) 时，画布占满整个屏幕，点 **返回对话** 回到聊天。AI 正在回复时，你可以继续发消息补充信息，不用等它说完。

## 只能在电脑上做的事 {#desktop-only}

下面这些操作在安卓 App 和手机浏览器里都做不了，请到电脑上的 Halo 桌面版里操作 <Badge type="info" text="仅桌面版" />：

| 在手机上 | 情况 |
|---|---|
| **设置 › 系统**、**高级**、**远程访问** | 这三个分区不显示，**远程访问** 里的 **联邦网关** 也在其中。**系统** 里的 **任务通知** 开关也只在电脑上有 |
| **设置 › 外观** | 没有 **显示大小** |
| **设置 › AI 模型** | 没有 Claude Code CLI 登录；需要网页授权的账号只能用 **手动登录**（复制链接、粘贴授权码） |
| 新建工作区 | **自定义文件夹** 不可用，显示「请在桌面应用中选择文件夹」；改工作区文件夹显示「文件夹只能在桌面应用中更改。」 |
| 添加附件 | 不能选电脑上的文件或文件夹，只能从手机上传，见 [从手机上传文件](#uploads) |
| 打开工作区文件 | 点击文件会下载到手机；没有 **在文件夹中显示**，也不能用电脑上的应用打开 |
| AI 浏览器 | 没有 **打开浏览器**，浏览器标签页显示「浏览器功能仅在桌面客户端中可用」。AI 仍可以在电脑上用 [AI 浏览器](/features/ai-browser) 操作网页，但手机上停不了它正在进行的浏览会话 |
| 知识库 | 不能添加文件（「添加文件需要桌面应用。」），也不能 **添加文件夹** 作为 **监视的文件夹**；浏览、提问、删除可以 |
| 技能 | 不能导出 `.zip`，也不能打开技能文件夹（「在桌面客户端中打开以查看技能文件夹。」） |
| 跨电脑团队 | 不能加入别人的团队，显示「加入团队仅在桌面应用中可用。」 |
| 数字人的 HTTP 触发器 | 显示「打开桌面应用查看并复制 HTTP 触发命令。」 |
| 剩余配额 | 输入框旁边的配额圆环不显示 |

任务完成的系统通知：电脑上的 **任务通知** 只在电脑上弹出；手机上的通知由 [安卓 App](#notifications) 自己发出，和这个开关无关。

## 从手机上传文件 {#uploads}

在手机上，输入框 **＋** 里的附件项是 **文件**（「从本设备上传到工作区；图片会直接发送给 AI」），而不是桌面版的「文件和文件夹」。

1. 先打开一个工作区。没有工作区时会提示「打开工作区以附加文件」。
2. 点输入框的 **＋ › 文件**，选手机上的文件。
3. 文件上传到电脑上这个工作区的文件夹里，再作为附件发给 AI。上传时显示「正在上传 1 个文件…」，传完前 **发送** 不可点。

| 规则 | 说明 |
|---|---|
| 单个文件大小 | 最大 100 MB，超过的不上传 |
| 文件夹 | 不能上传，会提示「此设备仅支持上传文件」 |
| 图片 | 直接发给 AI 看，见 [图片输入](/features/image-input) |
| 重名 | 工作区里已有同名文件时，自动换一个不冲突的名字 |
| 电脑上的路径 | 不能在手机上附加电脑本地的文件路径；要用电脑上已有的文件，直接在消息里告诉 AI 文件名或位置 |

## iOS {#ios}

Halo 3.0.4 没有 iOS App，App Store 里也没有。在 iPhone 和 iPad 上请用 [手机浏览器](#phone-browser)。

- 浏览器里的功能和安卓 App 一样，但没有后台保持连接和系统通知，这两项只有安卓 App 有。
- 开发者可以从源码自行构建 iOS 版本。

## 遇到问题 {#troubleshooting}

### App 提示「无法连接到服务器。请检查地址并确保 Halo 正在运行。」

1. 确认电脑开着、没有休眠，Halo 正在运行，**启用远程访问** 是打开的。
2. 用局域网地址时，确认手机连的是和电脑同一个 Wi-Fi，而不是移动数据。不在同一个网络时，改用 [互联网访问](/features/remote-access#internet-access) 的永久地址。
3. 在电脑上重新复制地址：端口被占用时 Halo 会换端口，旧地址就打不开了。
4. 仍然不行时，检查电脑的防火墙是否拦截了 Halo。

### App 提示「服务器响应异常」或「无效的 URL 格式」

地址上不是 Halo，或者格式不对。对照电脑上 **设置 › 远程访问** 里的地址，确认 IP 和端口都一致，例如 `192.168.1.100:3456`。

### 提示「无效的访问码」，或 **继续** 一直不可点

- 访问码就是电脑上的 **访问密码**，不是单独的 PIN。在电脑上点 **复制** 再粘贴，避免大小写输错。
- 少于 8 个字符时 **继续** 不可点。连接 Halo Server 时，`HALO_REMOTE_PASSWORD` 要设成至少 8 个字符。
- 失败次数过多会被锁定：同一个 IP 5 分钟内失败 5 次锁 15 分钟；所有设备 1 小时内合计失败 10 次，全部锁 30 分钟。锁定期间密码对了也登录不上，等锁定结束或在电脑上重启 Halo 后再试，详见 [输错太多次会被锁定](/features/remote-access#lockout)。

### 点「扫描二维码」后提示「相机访问被拒绝或不可用」

在安卓的系统设置里允许 Halo 使用相机，再试一次；也可以直接手输地址。

### 电脑上找不到二维码

**扫码访问** 只在 **互联网访问** 的隧道运行时显示，局域网地址没有二维码。同一个 Wi-Fi 时请手输 **局域网地址**。

### 页面顶部显示「正在重新连接...」

手机和电脑之间的连接断了，Halo 会自动重连，间隔从 1 秒逐渐拉长到 30 秒。从后台切回 App 或浏览器时会立刻重连。连上后，离开期间完成的回复和等你回答的问题会自动补上。一直连不上时，按上面「无法连接到服务器」的步骤检查。

### App 回到了「我的设备」，或浏览器回到了登录页

电脑上的访问密码被修改过，所有设备都要用新密码重新登录。App 里重新 **添加设备** 并输入新密码即可。

### 收不到通知

- 确认在安卓设置里允许了 Halo 的通知。
- 通知只在 App 处于后台时发出；手机浏览器不发系统通知。
- 系统结束了 App 时收不到通知，打开 App 后会补上错过的内容。
