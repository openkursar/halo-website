# 让 AI 帮你操作 Halo

::: say
> 把这个对话改名为「Q3 复盘」

Halo 会找到当前对话并改好名字，对话列表里随即显示新名字。同样可以说「新建一个叫「年度规划」的工作区」「把这个工作区的记忆关掉」「先把新闻助手暂停」。

**前提**：在输入框 **＋ › 能力** 里打开 **操作 Halo**。它默认关闭，AI 只能请你打开，不能自己打开。
:::

## 打开操作 Halo {#turn-on}

**操作 Halo** 是一项[能力](/features/capabilities)，在任何地方都默认关闭。打开后，AI 才能通过 Halo 自己的接口替你改工作区、数字人、知识库和设置。

### 在普通对话里打开

1. 点输入框左边的 **＋**（提示文字是「添加文件、上下文和能力」；AI 正在回复时显示「能力」）。
2. 在 **能力** 一组里打开 **操作 Halo**。它的说明是「AI 通过接口帮你操作 Halo：空间、数字人、知识库和设置」。
3. 发送下一条消息。开关从**下一条消息**起生效，正在进行的回复不受影响。

新对话会沿用你上次设置的能力开关。所以打开过一次以后，之后新建的对话也会带着它，直到你关掉。

### 给数字人打开

数字人对话的输入框里没有能力开关，要在数字人自己的设置里打开：

1. 打开 **数字人**，选中这位数字人。
2. 进入 **能力与设置 › 模型与能力**。
3. 打开 **操作 Halo**。这里的说明是「允许此应用管理 Halo 自身：空间、数字人、知识库和设置」。

打开后，你和这位数字人的对话、它的计划任务运行都能用上操作 Halo。通过 IM 找它的访客、来自其他电脑同事的请求，永远拿不到这项能力。

### AI 需要时会请你打开

如果你让 AI 做的事需要操作 Halo，而开关还关着，AI 会说明原因，Halo 会打开 **＋** 面板并高亮 **操作 Halo** 开关。你打开它，再发一条消息让 AI 继续。AI 没有办法自己打开这个开关。

在桌面版、通过[远程访问](/features/remote-access)打开的网页和 Android 应用里，这个开关都能用：AI 始终在运行 Halo 的那台电脑上工作。

::: done
打开开关后发一句「把这个对话改名为「Q3 复盘」」。对话列表里的名字变了，就说明操作 Halo 已经生效。
:::

## AI 能帮你做什么 {#what-it-can-do}

打开操作 Halo 后，你可以直接用一句话让 AI 做下面这些事。表里的说法只是示例，换成你自己的话也行。

| 范围 | AI 能做的事 | 可以这样说 |
|---|---|---|
| 对话 | 改名、加星标、删除；新开一个对话并让 AI 在那里开始工作；停止正在运行的对话 | 「把这个对话改名为「Q3 复盘」」「删掉上周的测试对话」「让那个正在跑的对话先停下」 |
| 工作区 | 新建、改名、调整顺序、换对应的文件夹；打开或关闭工作区记忆、立即整合记忆；查看、新建、改名、移动文件，或把文件移到废纸篓 | 「新建一个叫「年度规划」的工作区」「把这个工作区的记忆关掉」 |
| 数字人 | 暂停和恢复；改计划任务；单独设置模型、深度思考和记忆；调整权限；移到另一个工作区；清除记忆；列出或取消提醒；查看运行记录；替你回答它在等的问题；让失败的运行继续 | 「先把新闻助手暂停」「把新闻助手改成每两小时跑一次」「新闻助手上次跑得怎么样？」 |
| 团队 | 新建团队、把临时协作保存成团队、增减成员、开始或停止一次运行、设置计划任务、查看任务板 | 「每周一 9 点让这个团队出周报」 |
| 知识库 | 新建、按文件路径添加文件、监听一个文件夹、绑定到工作区或数字人、设为默认、重新索引 | 「把桌面上的「产品手册」文件夹加进知识库，并绑定到这个工作区」 |
| 消息通道 | 查看连接状态、重新连接、重新加载、发一条测试通知 | 「我的企业微信机器人连上了吗？」 |
| 设置 | 切换模型来源或模型；修改或删除已有的模型来源；查看哪些 Agent 引擎可用；测试 MCP 服务器 | 「这个对话换成 DeepSeek 那个模型源」「帮我测一下 MCP 服务器能不能连上」 |
| 商店 | 浏览和搜索、安装、检查和应用更新、管理商店来源、下架你发布过的内容 | 「帮我装上商店里的「HN 每日简报」」 |

暂停没有定时恢复：说「把新闻助手暂停到下周一」，它会**马上暂停**，到了下周一不会自己恢复。下周一再说一句「把新闻助手恢复」即可。

切换模型时，模型来源必须已经在 **设置 › AI 模型** 里添加好，AI 不能替你添加。详见[模型与账号](/features/models)。

## 哪些事仍要你自己来 {#what-stays-manual}

下面这些事，即使打开了操作 Halo，AI 也做不了。你问到时，AI 会告诉你在界面的哪里操作，并一步步带你做。

| 要做的事 | 在哪里做 |
|---|---|
| 添加账号或模型来源 | **设置 › AI 模型**，见[模型与账号](/features/models) |
| 外观、语言、权限等通用设置 | **设置**，见[设置](/features/settings) |
| 远程访问的开关和密码 | **设置 › 远程访问**，见[远程访问](/features/remote-access) |
| 扫码添加企业微信、飞书、微信机器人；新建通道；配置邮件 SMTP 和 Webhook | **设置 › 消息通道**，见[消息通道](/digital-humans/channels) |
| 邀请同事加入团队、设置同事的权限 | 团队设置里的 **邀请加入该团队**，见[跨电脑团队](/digital-humans/cross-computer-teams) |
| 把数字人或技能发布到商店 | 见[商店](/digital-humans/store) |
| 更新 Halo | 见[更新 Halo](/advanced/updates) |
| 回答对话里 AI 向你提出的问题卡片 | 在对话里自己选择或填写答案 |
| 打开或关闭能力开关（包括操作 Halo 本身） | 输入框 **＋ › 能力**，或数字人的 **能力与设置** |

**密钥和令牌请你自己在设置里填。** 少数接口能接收密钥：你把值给 AI，它能给已有的微信机器人填上 Token、给商店来源填上 API Key；修改已有模型来源的接口也能接收 API Key，但 Halo 让 AI 不要这样做。无论哪种，在对话里打出来的密钥都会留在对话记录里，也会发给模型服务商。API Key 请到 **设置 › AI 模型** 改，机器人的 Token 到 **设置 › 消息通道**，商店来源的密钥到 **设置 › 应用商店**。

## 安全须知 {#safety}

::: danger 删除会立即生效
操作 Halo 没有确认弹窗。删除工作区、删除对话、清除记忆、解散团队，都会在 AI 执行的那一刻完成，无法撤销。只有这类不可撤销的操作，AI 才会被要求先用白话和你确认一遍。提这类要求时，请把对象说清楚。
:::

其他你需要知道的事实：

- **返回内容里的密钥会被遮盖**：AI 通过接口读到的内容里，API Key、密码、Token 一类的值都会被遮盖。
- **只在这台电脑内部开放**：AI 使用的接口只在运行 Halo 的电脑上监听，网络上的其他设备连不上。
- **关掉就收回**：关闭 **操作 Halo** 后，从下一条消息起 AI 就失去这项权限。不需要时请关掉，尤其是新对话会沿用上次的开关。
- **访客拿不到**：IM 访客和来自其他电脑的请求，即使找的是开了操作 Halo 的数字人，也用不了它。

::: warning 范围是整个 Halo，不只当前工作区
打开操作 Halo 后，AI 能动的是你这台 Halo 里的**所有**工作区、数字人和团队，不限于你正在用的这个工作区。
:::

Halo 的整体安全模型（包括工具调用不逐次确认、密钥的存放方式）见[安全说明](/advanced/security)。如果你是开发者，想自己调用这些接口，请看 [HTTP API](/developers/api/)。

## 不开操作 Halo 也能管理数字人 {#digital-humans-without-operate-halo}

管理数字人和装技能**不需要**操作 Halo。在任何普通对话或数字人对话里，默认就能直接说：

| 你可以说 | AI 做什么 |
|---|---|
| 「帮我建一个数字人，每个工作日早上 9 点汇总科技新闻」 | 先问你几个问题，再建好数字人，见[创建数字人](/digital-humans/create) |
| 「把新闻助手改成每两小时跑一次」 | 修改它的计划任务 |
| 「现在就让新闻助手跑一次」 | 立即开始一次运行，不等计划时间 |
| 「把新闻助手暂停」「把新闻助手恢复」 | 暂停或恢复 |
| 「帮我装上商店里的 code-commit 技能」 | 安装或卸载技能 |

两者的区别：

| | 默认就有的数字人管理 | 操作 Halo |
|---|---|---|
| 默认状态 | 开启 | 关闭 |
| 管的范围 | 当前工作区的数字人和技能 | 整个 Halo：对话、工作区、数字人、团队、知识库、消息通道、设置、商店 |
| 典型用途 | 新建、修改、安排、运行、暂停、删除数字人，安装技能 | 数字人的权限、记忆、提醒、运行记录，以及上表里的其他事 |

::: danger 在对话里删除数字人是永久删除
不开操作 Halo 时，让 AI「删掉某个数字人」会把它和它的全部数据永久删除，没有确认弹窗。
:::

默认的数字人管理由 **设置 › 高级 › 内置MCP扩展 › 数字人** 控制，默认打开。高级设置只在桌面版里有。

## 遇到问题 {#troubleshooting}

### AI 说需要打开「操作 Halo」

开关还没打开。在已经高亮的 **＋ › 能力 › 操作 Halo** 里打开它，再发一条消息让 AI 继续。

### 打开了开关，AI 还是说做不了

- 开关从**下一条消息**起生效。打开后再发一条消息。
- 你是在数字人对话里吗？数字人要在 **数字人 › 能力与设置 › 模型与能力** 里打开，输入框里没有这个开关。
- 这件事可能在[仍要你自己来](#what-stays-manual)的清单里。AI 会告诉你在哪里操作。

### 同事在 IM 里找数字人，它不能改 Halo

这是设计如此。IM 访客和来自其他电脑的请求永远拿不到操作 Halo，只有你本人可以。
