# 会话

::: say
> 把这个对话改名为「Q3 复盘」，再把上周那个测试对话删掉。

Halo 会改好名字、删掉那个对话，左侧列表随之更新。删除不会再问你确认，也不能撤销。

**前提**：在输入框 **＋ › 能力** 里打开 **操作 Halo**（默认关闭）。Halo 可以请你打开它，但不能自己打开。
:::

一个会话就是一件事的来回记录。Halo 每次回复都参考当前会话里说过的内容，所以不同的事最好分开开会话：同一个会话里先聊邮件、再聊年报，两件事容易搅在一起。

## 新建会话 {#new-conversation}

1. 在左侧栏点 **会话**，再点会话列表顶部的 **新对话**。也可以按 <Shortcut mac="⌘ K" other="Ctrl K" />，在 **快捷操作** 里选 **新建对话**。
2. 屏幕中间出现「今天想做点什么？」和输入框，下面有几个按钮，比如 **生成代码**、**分析文档**。点按钮只会把一句话填进输入框，不会直接发出去。
3. 写下你要做的事，按 <kbd>Enter</kbd> 发送。

新会话先以日期和时间当标题。发出第一条消息后，这条消息的前 50 个字会成为标题，除非你已经改过名。

## 整理会话列表 {#conversation-list}

会话列表在会话页左侧，分三组，每组都能折叠：

| 分组 | 里面是什么 |
|---|---|
| **已置顶** | 你置顶的会话 |
| **数字人** | 与本工作区里数字人的对话，按数字人分组 |
| **对话** | 你和 Halo 的直接对话 |

把鼠标移到一行上，右边会出现两个按钮：

- **固定** / **取消固定**：置顶，或取消置顶。
- **更多** › **重命名**：直接在原处改名，按 <kbd>Enter</kbd> 保存，<kbd>Esc</kbd> 取消。
- **更多** › **删除**：删除这个会话。

::: danger 删除工作区会话不会确认，也不能撤销
点 **删除** 后，工作区里的会话立即消失，无法找回。数字人的会话会先问「删除此对话？」，数字人的默认会话则是 **清空聊天**，同样要先确认。
:::

每行前面的小圆点表示状态，不用打开就能看出进度：

| 圆点 | 意思 |
|---|---|
| 蓝色 | 正在生成 |
| 琥珀色 | 在等你回答或拍板 |
| 绿色 | 已完成，你还没看 |
| 红色 | 出错了 |
| 没有圆点 | 空闲 |

所有工作区里正在跑和等你处理的会话，也会汇总在 [任务面板](/features/tasks) 里。

不是用默认引擎跑的会话，标题旁会有一个小标签，比如「Halo」或「Codex」。会话一旦建好，用的引擎就固定了。

列表可以拖动右边缘调宽窄；打开画布时，它会缩成一列小圆标，鼠标停上去能看到名字。在手机或窄屏上，会话列表在顶栏的 **对话历史** 按钮里。

## 找到以前的对话 {#search}

会话列表本身没有搜索框。要找以前的对话或其中某句话，用全局搜索：

1. 按 <Shortcut mac="⌘ K" other="Ctrl K" />，或点顶栏右侧的 **搜索** 图标。
2. 输入关键词。最上面能直接跳到匹配的对话、数字人、任务和知识库。
3. 要搜消息内容，选范围：**当前对话**、**当前工作区** 或 **所有工作区**。
4. 点一条结果，Halo 会跳到那条消息并高亮关键词。用浮动条上的 ↑（更早）、↓（更近）在结果间切换，<kbd>Esc</kbd> 关闭。

| 快捷键 | 搜索范围 |
|---|---|
| <Shortcut mac="⌘ K" other="Ctrl K" /> | 打开或关闭全局搜索 |
| <Shortcut mac="⌘ F" other="Ctrl F" /> | 当前对话（只在桌面应用里有效，网页里会交给浏览器） |
| <Shortcut mac="⌘ ⇧ F" other="Ctrl Shift F" /> | 当前工作区 |

## 发送消息与发送键 {#send-key}

默认按 <kbd>Enter</kbd> 发送，<kbd>Shift</kbd> + <kbd>Enter</kbd> 换行。想反过来，打开 **设置 › 外观 › 发送键**，选 **Ctrl+Enter**：之后 <kbd>Enter</kbd> 换行，<kbd>Ctrl</kbd> + <kbd>Enter</kbd> 发送。

- 在 macOS 上，Ctrl+Enter 模式按的就是 <kbd>Control</kbd> 键，<kbd>⌘</kbd> + <kbd>Enter</kbd> 在输入框里不会发送。
- 宽度小于 768 px 的触屏设备上，<kbd>Enter</kbd> 总是换行，用发送按钮发送。
- 用中文、日文或韩文输入法选词时按 <kbd>Enter</kbd>，不会把消息发出去。
- 没发出去的草稿按会话分别保留，切到别的会话再回来还在；退出 Halo 后不保留。
- 发送失败时，文字、图片和引用会退回输入框，不会丢。

输入框旁边还有这些，各有专门的页面：

- **＋**（「添加文件、上下文和能力」）：附加文件和图片，见 [文件和图片](/features/image-input)；打开网页控制、操作 Halo 等开关，见 [能力开关](/features/capabilities)。
- **知识**：把知识库加载到这个会话，见 [知识库](/features/knowledge-base)。
- 发送按钮左边的模型名：给这个会话换模型、调 **深度思考**，见 [模型与账号](/features/models)。

## Halo 工作时继续补充 {#queue}

Halo 工作时你可以接着打字、接着发，不用等它整段回复结束。发送按钮这时显示「加入队列」。

1. 写下补充，比如「标题换成深蓝色」，按发送。
2. 消息先出现在正在进行的回复下方，标着 **已排队**。
3. Halo 做完手上这一步就会读到它，标记变成 **已附加**，并按新要求继续。

- 排队的消息可以带文字和引用，不能带图片。
- 已排队的消息不能修改或撤回。
- 如果在 Halo 读到之前按了停止，这条消息会标成 **已停止，未处理**，不会执行。

## 停下与继续 {#stop}

- **停下**：点发送按钮旁边的方块按钮（「停止生成 (Esc)」），或在输入框里按 <kbd>Esc</kbd>。正在进行的回复和排队的消息都会停下。
- **继续**：回复意外中断时，会出现一张「模型响应已中断」卡片，点 **继续**，Halo 接着往下做（相当于发了一条 `continue`）。

<kbd>Esc</kbd> 的顺序：＋ 面板开着时，第一下先关面板；在目标模式里，第一下先退出目标模式；再按一下才停止回复。

中断卡片上的说明可能是英文，例如手动停下且已经写了一部分时显示 "Stopped by user."；步数用完时显示 "Reached the maximum turn limit. Send a message to continue."，再发一条消息就能继续。步数上限在 **设置 › 高级 › 每条消息最大轮次**，默认 999，可设 10–9999。

## 回答 Halo 的提问 {#question-card}

需要你拍板时，比如风格选哪种、发给谁，Halo 会停下来，在回复底部弹出一张问题卡片，一次 1–4 个问题。思考过程的标题这时显示「等待用户响应...」，会话列表里的圆点变成琥珀色。

1. 每个问题选一个或几个选项；都不合适就点 "Other..."，自己写答案。
2. 所有问题都答完后，点 "Submit"。卡片消失，Halo 接着做。

这张卡片目前只显示英文，中文界面也一样。Halo 执行工具时不会逐个问你批准，问题卡片是唯一会让它停下等你的地方。

## 用 @ 指向数字人、文件和对话 {#mentions}

在开头或空格后输入 **@**，会弹出一个菜单，分三组：

| 分组 | 选中后 |
|---|---|
| **数字人** | 把这条消息交给这位数字人，并新开一个与它的会话（见 [和数字人聊天](#digital-human-chat)） |
| **对话** | 插入一个指向那个对话的链接，Halo 会去读它（见 [会话之间互相协作](/features/cross-conversation)） |
| **文件** | 插入工作区里那个文件或文件夹的路径 |

- 只输入 @ 时每组显示 4 条，继续打字可以筛选（「输入以查看更多」）。
- 用 ↑ ↓ 移动，<kbd>Enter</kbd> 或 <kbd>Tab</kbd> 选中，<kbd>Esc</kbd> 关闭。
- Halo 工作时，**数字人** 分组暂时不出现，文件和对话仍可引用。
- **＋ › 上下文** 里的 **引用会话** 和 **与数字人聊天** 会打开同一个菜单。

## 用 / 调出命令和技能 {#slash-menu}

在消息开头输入 **/**，会列出可用的命令：上面是 **技能**，下面是 **内置** 命令。选中一条会把它填进输入框，你补完再发送。

- 列表来自当前的 AI 引擎和你启用的技能，Halo 自己不在聊天窗口里加命令。Codex 和 DeepSeek 引擎不提供命令，所以不会出现菜单。
- `/halo-stop`、`/halo-clear` 这类 Halo 命令只在企业微信、飞书等消息通道里有效，见 [命令与快捷键](/features/commands)。

## 读懂一条回复 {#reading-replies}

每条回复都可以拆开看 Halo 做了什么：

| 你看到的 | 是什么 |
|---|---|
| 回复上方可折叠的思考过程 | Halo 的思考、调用的工具和结果。进行中时标题写着正在做的事，结束后显示「已经思考」和用时。步骤超过 8 个时可以切到 **完整视图** |
| 每个步骤的 **显示工具结果** | 打开这一步的结果：代码、搜索命中、文件列表或网页内容，带 **复制** 按钮 |
| **任务计划** | 复杂任务里 Halo 列出的清单，显示已完成、进行中、待处理的数量。只显示最新的一份，不能手动勾选 |
| 回复右下角的灰色数字（如 12K） | 这次回复时模型看到的上下文大小。鼠标停上去显示「Token 用量」：已使用 / 限额、输入、输出等 |
| 「上下文已智能压缩」 | 会话太长时，引擎把较早的内容总结压缩，腾出空间。上面的消息仍留在对话里可以翻看 |
| 重试卡片，如「无法连接模型服务」「模型服务正在限流」 | 模型请求失败，Halo 正在倒计时重试，并显示这是第几次重试。卡片上的 **停止** 可以放弃 |
| 红色的「出现错误」 | 这次回复失败了。按报错原文到 [错误信息速查](/troubleshooting/common-errors) 查原因 |

- Token 用量的提示在用到 80% 时显示「接近上下文限制」，到 95% 时显示「上下文即将自动压缩」。
- 回复里写出的工作区文件路径，比如 `src/app.ts:12`，可以点开，在画布里定位到那一行。表格可以 **在画布中打开**。
- 回复右下角的 **复制消息** 会复制这条回复的 Markdown 原文。这是消息上唯一的操作：发出去的消息不能编辑、重发或重新生成。想换个说法，直接再发一条。
- 你发的很长的消息会折叠，点 **显示全部** 展开。往上翻时点 **返回最新** 回到底部。

## 引用回复里的片段 {#references}

想让 Halo 针对某一段改，不必复制粘贴，直接把那一段指给它：

1. 在一条 **已结束** 的回复里选中文字，或者在画布里选中文件、预览、差异或终端输出中的内容。
2. 选区旁出现两个按钮：
   - **评论**：写下针对这段的要求（「给 AI 的评论…」，最多 4,000 字），按 <kbd>Enter</kbd> 添加。
   - **添加到对话**：只引用这段，不写说明。
3. 引用以小标签出现在输入框上方，比如「3 条评论」「2 个已选片段」。点开可以查看，点 × 移除整组（可以撤销）。
4. 需要的话再写几句话，然后发送。只发引用、不写文字也可以。

- 一条消息最多 50 个引用，附加的文件和文件夹也算在内。
- 引用会按添加顺序编号交给 Halo。
- 太长的摘录会被截短：文件和差异保留 2,000 字，终端输出和聊天片段保留 20,000 字。
- 发出去的消息里，点引用能跳回原处；原文变了时会提示。
- 只能选中主聊天里的回复，团队协作视图和运行详情里的内容不行。

## 给会话设定目标 {#goal}

<Badge type="warning" text="实验性" /> 目标只在 **Halo SDK** 引擎下可用。这个引擎在 **设置 › 高级 › AI Agent 引擎** 里切换，标着「实验性功能」，切换后要重启，只对新会话生效。详见 [Agent 引擎](/features/agent-engines)。

设定目标后，Halo 会一直朝它推进，上下文压缩也不会把目标丢掉。

1. 点输入框的 **＋**，在 **上下文** 里选 **设置目标**。输入框进入目标模式，显示 **目标** 标签。
2. 写下你要的结果。以 `-`、`*`、`1.` 或 `[ ]` 开头的行会变成完成条件，其余的行是目标本身。
3. 按 <kbd>Enter</kbd>（「设置目标并开始」）。

输入框上方会出现目标栏，显示「正在追求目标」「目标已达成」或「目标已放弃」，可以编辑、换 **新目标** 或 **清除目标**。Halo 自己也可能更新、完成或放弃目标。Halo 工作时再发消息，会改写正在进行的目标，而不是排队。

按 <kbd>Esc</kbd>，或在空输入框里按退格，会退出目标模式并保留已写的文字。数字人的会话里没有目标。

## 和数字人聊天 {#digital-human-chat}

在会话页就能把一件事交给某位数字人：

1. 在输入框输入 **@** 并选一位数字人，或点 **＋ › 上下文 › 与数字人聊天**。
2. 输入框左边出现一个写着它名字的标签（鼠标停上去显示「正在与 … 对话」），Halo 会为你新开一个和它的会话。发出的消息由这位数字人处理。
3. 想换人，点这个标签，从列表里另选一位；想回到 Halo，点标签旁的 ×（「切换回 Halo」）。回复进行中不能切换。

用 @ 或标签选人，每次都会新开会话。要接着聊以前的，在会话列表的 **数字人** 分组里点那个会话；分组里每位数字人旁的 **＋** 可以和它新建对话。

数字人的会话与普通会话的区别：

| | 普通会话 | 数字人的会话 |
|---|---|---|
| ＋ 里的 **能力** 开关、**知识** 按钮、**目标** | 有 | 没有，数字人的工具和知识库在它自己的设置里配置 |
| @ 里的 **对话** 分组 | 有 | 只有这位数字人开了 **对话协作** 才有 |
| 回复署名 | Halo | 数字人的名字 |
| 清空记录 | 删除会话 | 对话底部的 **清空聊天**，确认后清空 |
| 它主动发来的消息 | — | 标着「主动发送」 |

提醒只能在数字人的会话里设：对它说「明天早上 9 点提醒我交周报」。普通会话里没有提醒功能。详见 [提醒](/digital-humans/reminders)。

::: done
左侧列表里出现你的新会话，标题变成你发的第一句话；Halo 工作时你补充的消息标着「已附加」，就说明它已经读到了。
:::

## 遇到问题 {#troubleshooting}

### 误删了一个会话

工作区会话删除后无法恢复。重要的会话可以先 **固定**，放进 **已置顶** 分组，减少误操作。

### 列表里找不到以前的会话

会话列表没有搜索。按 <Shortcut mac="⌘ K" other="Ctrl K" />，在 **所有工作区** 里搜消息内容。也可能是会话在别的工作区里，见 [工作区](/features/spaces)。

### 在 Mac 上按 ⌘ Enter 发不出去

Ctrl+Enter 模式按的是 <kbd>Control</kbd> + <kbd>Enter</kbd>。也可以在 **设置 › 外观 › 发送键** 改回 **Enter**。

### 按 Esc 停不下来

<kbd>Esc</kbd> 只在光标位于输入框时有效。＋ 面板开着或处在目标模式时，第一下 <kbd>Esc</kbd> 先关面板或退出目标模式，再按一下才停止。也可以直接点停止按钮。

### 输入 / 没有出现菜单

当前引擎是 Codex 或 DeepSeek 时没有命令菜单。另外，/ 必须是消息的第一个字符，后面不能有空格。

### ＋ 里没有「设置目标」

当前引擎不是 Halo SDK，或者你在数字人的会话里。见 [给会话设定目标](#goal)。

### 排队的消息加不了图片

Halo 工作时发的补充只能带文字和引用。等这次回复结束，或者先停下，再发图片。

### 选中回复里的文字，没有出现「评论」按钮

回复还没结束时不能选中引用，等它结束再选。团队协作视图和运行详情里的内容也不能引用。
