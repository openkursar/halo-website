# AI 终端

::: say
> 帮我 SSH 到测试服务器看看日志

如果 **AI 终端** 还关着，AI 会用一句话请你打开，同时 Halo 打开输入框的 **＋** 面板并高亮这个开关。打开后再发一条消息，AI 就会新建一个终端，你在右侧画布里看到它输入的每条命令。需要密码时，由你自己在终端里输入。

**前提**：在输入框 **＋ › 能力** 里打开 **AI 终端**（默认关闭）。AI 只能请你打开，不能自己打开。
:::

## 开始之前 {#before-you-start}

::: warning 注意
AI 终端只支持 macOS 和 Windows。Linux 版没有 AI 终端：**＋ › 能力** 里没有这个开关，**更多** 菜单里也没有 **打开终端**。
:::

AI 终端和 AI 平时执行命令不是一回事。AI 一直可以用自己的命令工具跑一次性的命令，比如 `git status`、`npm install`，不需要打开任何开关。

AI 终端用来做需要“一直开着”的事：登录状态、当前目录和正在运行的程序都会保留。它适合 SSH、数据库命令行和 Python 这类交互式环境（REPL）、交互式安装程序、其他 AI 的命令行工具，以及耗时的构建和部署。

| 我想… | 用这个 |
|---|---|
| 让 AI 跑一条命令、看结果 | 直接说，不用开开关 |
| 登录服务器后让 AI 接着操作 | AI 终端，见 [登录服务器后交给 AI](#ssh) |
| 跑一个要很久的任务，过一会儿再看 | AI 终端，见 [跑长任务](#long-tasks) |
| 在 REPL 或交互式工具里一步步操作 | AI 终端 |

## 打开 AI 终端 {#turn-on}

1. 在会话输入框点 **＋**（提示文字「添加文件、上下文和能力」）。
2. 在 **能力** 一组里找到 **AI 终端**，说明是「交互式 AI 终端，可人机协同：SSH、操作其他 CLI、长任务」。
3. 打开开关。从你发的下一条消息起生效。之后 AI 自己决定什么时候新建终端、输入命令和读取输出。

- 这个开关属于每个会话。新会话沿用你上一次调过的开关组合。其他能力开关见 [能力开关](/features/capabilities)。
- 和数字人聊天时，**＋** 面板里没有能力开关。数字人用自己的开关：**能力与设置 › 模型与能力 › AI 终端**（「允许此应用运行 Shell 命令和交互式终端」），默认打开。详见 [数字人的能力与设置](/digital-humans/capabilities)。
- 通过企业微信、飞书等聊天工具找数字人的访客，默认用不了终端，除非你在 [权限控制](/digital-humans/permissions) 里允许。

::: info 2.1.x 版本的入口
在 2.1.x 中，在输入框的 **工具** 菜单里打开 **终端**；自己打开终端的 **打开终端** 按钮在右侧的文件面板中。
:::

## 自己打开一个终端 {#open-terminal}

想先自己登录、准备好环境，再交给 AI，可以自己打开终端：

1. 在会话顶部点 **⋯ 更多 › 打开终端**（「当前工作区目录」）。窗口较窄时，同一项在溢出菜单里。
2. 终端在右侧画布里打开，起始目录是当前工作区的文件夹。
3. 在里面照常输入命令。打开 **AI 终端** 开关后，AI 可以接着用这个终端。

AI 用过终端后，会话里会出现一张终端卡片，写着「已启动终端会话」、它输入的命令或「读取终端输出」。点卡片上的 **打开终端**，就能在画布里打开那个终端。

## 和 AI 共用同一个终端 {#shared-session}

AI 终端是一个真实的终端，不是命令记录。你和 AI 看到的是同一个画面，也都能往里输入。

- **随时接管**：直接在画布的终端里打字即可。按 <kbd>Ctrl</kbd> <kbd>C</kbd> 总是发给终端，用来中断正在运行的命令。
- **知道谁在输入**：AI 正在输入时，终端四周会出现高亮边框。
- **把输出交给 AI**：在终端里选中一段输出，点 **添加到对话**，它就作为引用放进输入框，见 [引用回复里的片段](/features/conversations#references)。
- **只看本工作区**：AI 只能看到和操作当前工作区里的终端，包括你自己打开的那些。
- **数量上限**：同时最多运行 12 个终端。AI 可以开多个终端，分别连不同的机器。
- **外观**：终端跟随 Halo 的浅色或深色主题即时切换。浅色主题下用的是加深过的颜色，黄色等文字也看得清。字号 13 px，可以往回翻 10,000 行。
- **重新打开**：关掉画布或换到别的标签后再打开，终端会带着颜色重放最近的输出。

### AI 能对终端做什么 {#ai-tools}

| AI 的动作 | 说明 |
|---|---|
| 新建终端 | 可指定起始目录和标题，默认在当前工作区的文件夹 |
| 列出终端 | 看本工作区有哪些终端、谁开的、闲置了多久 |
| 输入并等结果 | 替你按回车，等输出停下来再读 |
| 读取输出 | 读新增的输出、当前屏幕，或往回读历史 |
| 搜索历史 | 在输出历史里查找报错之类的文字 |
| 等某段文字出现 | 比如等“构建完成”，单次最长等 10 分钟 |
| 关闭终端 | 结束这个终端的进程 |

AI 每次读取最多拿到 2,000 行或 50 KB 的输出。Halo 不会往你的命令提示符里注入任何东西。

::: danger 警告
AI 在终端里能运行任何命令，执行前不会逐条问你确认，见 [AI 执行工具不会逐次确认](/advanced/security#tool-permissions)。连接重要服务器时，留意 AI 在做什么，必要时直接在终端里接管，或者在活跃会话里停止它。
:::

## 登录服务器后交给 AI {#ssh}

1. 打开 **AI 终端** 开关，然后让 AI 开一个终端，或者用 **⋯ 更多 › 打开终端** 自己开一个。
2. 在终端里自己输入 `ssh` 命令登录，例如 `ssh deploy@example.com`。密码或密钥口令由你在终端里输入，不会出现在对话里。
3. 看到服务器的命令提示符后，在对话里告诉 AI 接着做什么，比如「在刚登录的终端里看看最近的错误日志」。AI 在同一个终端里继续操作。

- 要连几台机器，就每台开一个终端。
- 不要把密码贴进对话让 AI 代输。
- Windows 上终端默认是 PowerShell，`ssh` 用的是 Windows 自带的 OpenSSH，不需要别的工具。

## 跑长任务 {#long-tasks}

构建、部署、下载这类耗时任务，可以交给 AI 终端：

1. 让 AI 在终端里启动任务，例如「在终端里跑一遍完整构建，结束后告诉我结果」。
2. AI 会等某段输出出现，或者隔一段时间回来读输出。这期间你可以继续在对话里补充要求。
3. 任务结束后，AI 读取结果并告诉你。

AI 用过、还在运行的终端会出现在输入框上方的活跃会话条里，显示终端标题，或「2 个会话正在运行」这样的数量。点开后是 **活跃会话** 列表，每一行可以 **打开** 或 **停止**。停止前 Halo 会确认「停止此会话？」「正在运行的进程将被终止。」

终端会运行多久：

| 情况 | 终端会怎样 |
|---|---|
| 切换模型、收起画布、换到别的会话 | 继续运行 |
| 切换到别的工作区 | 继续运行，标签页留着，切回来还在 |
| 退出或重启 Halo | 全部结束，不会恢复 |

## 关闭终端标签 {#close-tab}

关闭标签和结束进程是两件事。用标签上的 ×、鼠标中键、<Shortcut mac="⌘ W" other="Ctrl W" /> 或右键菜单关闭终端标签时：

| 终端的状态 | 关闭标签时 |
|---|---|
| 已经结束 | 直接关闭 |
| 你自己打开、AI 没用过、还在运行 | 终端随标签一起结束 |
| AI 用过（AI 开的，或你开的但 AI 操作过），还在运行 | 弹出「此终端已被 AI 使用」，说明「保持其在后台运行可让 AI 继续使用；完全关闭会结束该进程。」 |

在弹出的提示里选：

- **保持在后台运行**：标签关掉，进程继续跑，AI 还能用，你也能从活跃会话里重新打开。
- **完全关闭**：结束进程。
- **取消**：什么都不做。

一次关闭全部标签或移除工作区时不会弹提示：你自己的终端会结束，AI 用过的终端留在活跃会话里继续运行。

## 终端在单独的进程里运行 {#separate-process}

所有终端都跑在一个单独的后台进程里，不在 Halo 主窗口的进程里。

- 某个 Shell 启动很慢或卡住（比如被杀毒软件扫描），Halo 窗口不会跟着卡住。
- 这个后台进程在你第一次用终端时才启动，不拖慢 Halo 启动。
- 输出特别多时，Halo 会控制刷新速度，界面不会被拖垮。
- 这个进程如果崩溃，正在运行的终端都会结束，标签上显示「会话已结束（输出不再可用）」，只能查看。下次打开终端时会换一个新进程，之前的终端不会恢复。

## 平台和 Shell {#platforms}

| 平台 | AI 终端 | 默认 Shell |
|---|---|---|
| macOS | 支持 | 你的默认登录 Shell（通常是 zsh），会加载你的提示符和别名；取不到时用 `/bin/bash` |
| Windows | 支持 | PowerShell |
| Linux | 不支持 | — |

- **Windows 不需要 Git Bash**：AI 终端默认打开 PowerShell，没装 Git Bash 也能用。Git Bash 是 Claude Code 引擎执行它自己的命令时用的，和 AI 终端无关。安装见 [安装 Halo › 命令执行环境](/getting-started/install#git-bash)。
- **远程访问和手机**：通过 [远程访问](/features/remote-access) 或 Android 应用打开 Halo 时，也能打开终端、在里面输入，前提是运行 Halo 的电脑是 macOS 或 Windows。屏幕宽度不足 640 px 时，终端下方会出现一排按键：Esc、Tab、Ctrl+C 和方向键。
- **数字人**：数字人的 **AI 终端** 开关同样只在 macOS 和 Windows 上起作用。

::: done 完成
画布里出现终端，AI 输入命令时边框高亮，会话里出现「已启动终端会话」的卡片，就说明 AI 终端在工作了。
:::

## 遇到问题 {#troubleshooting}

### 输入框 ＋ 里找不到 AI 终端

- 你用的是 Linux 版。Linux 不提供 AI 终端。
- 你在和数字人聊天。数字人的开关在它的 **能力与设置 › 模型与能力** 里。

### AI 说需要终端，但开关已经打开了

开关从下一条消息起生效。打开后再发一条消息，比如「打开了，继续」。

### AI 说终端数量到了上限

同时运行的终端最多 12 个，新建时会报 `Terminal session limit reached (12). Close a session first.`。在输入框上方的 **活跃会话** 里 **停止** 不用的终端，或关掉你自己开的终端标签，再新建。

### 终端显示「会话已结束（输出不再可用）」

Halo 重启过，或者终端的后台进程崩溃了，原来的终端已经结束。用 **⋯ 更多 › 打开终端** 开一个新的，或者让 AI 重新开。

### 关掉标签后，终端还在跑

这是 AI 用过的终端，你选了 **保持在后台运行**。在 **活跃会话** 里点 **停止** 就能结束它。

### Windows 上没装 Git Bash，AI 终端能用吗

能。AI 终端默认用 PowerShell。没装 Git Bash 只影响 Claude Code 引擎自己执行命令，见 [安装 Halo › 命令执行环境](/getting-started/install#git-bash)。
