# 知识库：让 AI 基于你的文档回答

知识库是你交给 Halo 的一组资料。Halo 在本机把文档里的文字提取出来，对话时 AI 会先查阅这些资料再回答，并在回答下方列出用到的出处。

## 支持哪些文件

| 类型 | 格式 |
|---|---|
| 文本 | Markdown、TXT、reStructuredText、Org、CSV、TSV、HTML |
| 文档 | PDF、Word（.docx）、PowerPoint（.pptx）、Excel（.xlsx） |
| 图片 | PNG、JPG、WebP、BMP、TIFF、GIF——用本机文字识别（OCR）提取图中文字 |

源代码、配置文件和日志不会被收进知识库；导入文件夹时，`.git`、`node_modules`、构建目录等也会自动跳过。

---

## 创建知识库

1. 打开左侧导航栏的 **知识库**。
2. 点击 **新建知识库**，起个名字；也可以在这一步把它连接到某些空间（可选）。
3. 在 **文件** 页把文件或文件夹拖进来，或者点 **浏览文件** / **浏览文件夹**。文件夹会连同子文件夹一起导入。
4. 点击 **学习 N 个新文件**。每个文件显示 **已学习** 后就可以使用了。

“学习”只是在本机提取文字，不调用模型，几十个文件通常几秒钟就能完成。没有可读文字的文件（例如扫描版 PDF、没有文字的图片）会标记为 **已跳过 — 无可读文本**，可以一键清理。

## 在对话中使用

有几种方式让 AI 用上知识库：

- **当前对话**：点击输入框工具栏上的 **知识** 按钮，勾选要加载的知识库。
- **某个空间的新对话都用**：在 **知识** 菜单里勾选“在此工作区中始终启用”，或者在知识库的 **设置** 页把它连接到这个空间。
- **所有新对话都用**：在知识库的 **设置** 页打开 **默认知识库**。
- **数字人**：在数字人的设置里勾选要使用的知识库。
- **直接提问**：在知识库的 **聊天** 页“向这个知识库提问”，回答只基于这个知识库的文档。

AI 回答时会在知识库里搜索、阅读相关文档，回答下方的 **来源** 列出它读过的文件，点击即可打开原文。

---

## 监视文件夹

在知识库的 **设置** 页点击 **添加文件夹**，Halo 会持续学习这个文件夹里新增和修改的文件，适合放一个经常更新的资料目录。

- 一个监视文件夹最多 500 个可学习的文件。超过这个数量的文件夹不能添加；已添加的文件夹之后超过 500 个，会被暂时跳过，直到文件数回落。
- 不能把整个磁盘（如 `C:\` 或 `/`）作为监视文件夹。
- 文件夹无法监视时（例如已被移走），会显示为 **不可用**。

---

## 设置与维护

- **继续学习**：关闭后知识库进入“已暂停”，不再学习新文件，也不会在对话和数字人中使用，直到重新打开。
- **重建文档索引**：从源文件重新提取所有文字，适合在修改过文件之后使用。
- **删除知识库**：删除 Halo 中保存的文件副本和提取出的文字；你电脑上的原始文件（包括监视文件夹里的文件）不受影响。

知识库保存在本机的 Halo 数据目录里（默认是用户目录下的 `.halo/knowledge-bases`）。

---

## 注意事项

::: warning 图片和扫描件只能读出文字
图片通过 OCR 识别文字，读不懂图表和版式；扫描版 PDF 没有文字层，目前无法提取内容。
:::

::: tip 资料放少而精
知识库适合放你真正需要 AI 参考的文档。把整个项目目录或大量杂项文件放进来，会让 AI 更难找到有用的内容。
:::
