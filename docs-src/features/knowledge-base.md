# 知识库

::: say
> 新建一个叫「产品资料」的知识库，把 ~/Documents/产品资料 设为监视文件夹

Halo 会建好知识库，把这个文件夹设为监视文件夹并开始学习。之后可以接着问「学习进度怎么样了」。

**前提**：在输入框 **＋ › 能力** 里打开 **操作 Halo**。它默认关闭，AI 只能请你打开，不能自己打开。
:::

## 打开知识库页面 {#open}

点左侧导航栏的 **知识库**。窗口较窄或在手机上时，在 **导航** 面板里找到 **知识库**。

页面上每个知识库是一张卡片，按最近编辑排序，最后一张虚线卡片是 **新建知识库**。卡片上显示文档数、学习进度、大小和使用它的数字人数量。鼠标移到卡片上会出现暂停按钮和 **更多** 菜单（**设为默认**、**删除**）。

点开一张卡片进入详情页，有 **聊天 · 文件 · 设置** 三个标签，默认打开 **文件**。

## 新建知识库 {#create}

1. 在知识库页面点 **新建知识库**（还没有知识库时，页面中间也有这个按钮）。
2. 填写 **名称**，例如「产品资料」。
3. 需要的话，在 **连接到工作区(可选)** 里点选工作区。这些工作区的**新对话**会自动加载这个知识库。
4. 点 **创建**。详情页随即打开，里面还是空的。

建知识库和学习文件都不需要 AI 模型。描述、默认知识库和监视文件夹，之后在 **设置** 标签里修改。

![还没有知识库时的知识库页面，中间是「创建你的第一个知识库」和新建知识库按钮](/images/features/knowledge-base/empty-state.zh.webp)

## 添加文件和文件夹 {#add-files}

<Badge type="info" text="仅桌面版" />

1. 打开知识库，切到 **文件** 标签。
2. 把文件或文件夹拖到「把文件或文件夹拖到这里」区域，或者点 **浏览文件** / **浏览文件夹**。
3. 学习会自动开始。上方的进度卡片显示「学习中…」和当前文件，完成后显示「学习完成」。

添加的文件会被**复制**进知识库。之后你在原位置修改文件，知识库里的副本不会跟着变。经常更新的资料，请用[监视文件夹](#watched-folders)。

添加文件只能在桌面版里做。通过[远程访问](/features/remote-access)打开的网页和 Android 应用里，这个区域显示「添加文件需要桌面应用。」

### 支持的文件 {#supported-files}

| 类型 | 扩展名 | 能读出什么 |
|---|---|---|
| 文本 | `.md` `.markdown` `.txt` `.text` `.rst` `.org` `.csv` `.tsv` `.html` `.htm` | 全文 |
| PDF | `.pdf` | 文字层。扫描版 PDF 没有文字层，读不出内容 |
| Word | `.docx` | 段落文字 |
| PowerPoint | `.pptx` | 幻灯片上的文字，按页序 |
| Excel | `.xlsx` | 单元格里的文字。数字和公式不会提取 |
| 图片 | `.png` `.jpg` `.jpeg` `.webp` `.bmp` `.tif` `.tiff` `.gif` | 本机文字识别（中文、英文）读出的文字 |

不支持的文件会被跳过，并提示「已跳过 N 个不支持的文件」。不支持的包括旧版 `.doc` `.ppt` `.xls`、源代码、JSON / YAML / XML 配置和日志。这条提示没有列出图片，但图片是支持的。

Office 锁文件（`~$*`、`.~lock.*`）、`.DS_Store`、`Thumbs.db`、`desktop.ini` 总是被忽略。

### 导入文件夹的规则 {#folder-import}

- 子文件夹一并导入，目录结构保留。
- 跳过 `.git` `.svn` `.hg` `node_modules` `.venv` `__pycache__` `dist` `build` `.next` `target` `vendor` `coverage` `.idea` `.vscode` `.cache` `.gradle`，也不跟随符号链接。
- 同名且内容相同的文件不会重复复制。同名但内容不同的文件改名为 `名称-2.扩展名`、`名称-3.扩展名`。名字不同的文件即使内容相同，也会各复制一份。
- 单个文件没有大小限制，文件数量也没有上限。但一次导入最多遍历 20,000 个目录条目，超出的部分不会导入，也没有提示。

## 学习是怎么回事 {#how-learning-works}

Halo 的「学习」是在你的电脑上把每个文件的文字提取出来，再生成一份文档目录（每篇的名称和一句话摘要）。整个过程不调用模型，不做向量化，也不消耗 token，可以离线完成。几十个文件通常几秒钟就学完。

回答问题时，AI 读这份目录，在提取出的文字里搜索、打开相关文档，再作答。所以知识库适合放你真正需要 AI 参考的资料。放得少而精，AI 更容易找到有用的内容。

| 环节 | 用不用模型 | 消耗 token |
|---|---|---|
| 新建、添加文件、学习、重建索引 | 不用 | 不消耗 |
| 在知识库里[提问](#ask) | 用当前的默认模型 | 按正常对话消耗 |
| 在对话里[加载知识库](#use-in-conversation) | 用这个对话的模型 | 每轮多一点输入 token |

其他细节：

- 图片用本机文字识别，图片不会上传。它只读出文字，看不懂图表和版式。
- 文本文件的编码会自动识别，支持 UTF-8、UTF-16、GBK、Big5、Shift_JIS 和 Windows-1252。
- 文件一个一个处理。只有文件内容变了才会重新学习。
- 单个文件学习失败不会影响整个知识库。每次启动 Halo，没学完的文件会接着学。

## 文件列表 {#files-list}

**文件** 标签列出所有资料，包括监视文件夹里的文件，分成三组：

| 分组 | 含义 |
|---|---|
| **尚未学习** | 等待学习，或学习失败等待重试 |
| **已学习** | 可以使用了。点一下在画布中打开 |
| **已跳过 — 无可读文本** | 没有读出文字，默认折叠。点 **清理 N 项** 只删除知识库里的副本 |

文件下方会写明原因，例如「无文字图层 — 似乎是扫描件」「此图片中未找到文字」「未找到可读文本」「无法读取此文件」。

有文件待学习时，会出现 **学习 N 个新文件** 按钮，点它手动开始学习。

要移除文件，点文件旁的垃圾桶，或点 **选择文件**，勾选文件或整组，再点 **移除所选**。移除会永久删除知识库里的副本，你磁盘上的原文件不受影响。监视文件夹里的文件不能在这里移除，提示「来自监视文件夹——在设置中管理」。

## 监视文件夹 {#watched-folders}

<Badge type="info" text="仅桌面版" />

监视文件夹不复制文件，而是在原位置学习，文件夹里新增或修改的文件会自动重新学习。适合放一个经常更新的资料目录。

1. 打开知识库，切到 **设置** 标签。
2. 在 **监视的文件夹** 里点 **添加文件夹**，选择文件夹。
3. 文件夹出现在列表里，它的文件出现在 **文件** 标签，并开始学习。

| 限制 | 数值 | 超出时看到的提示 |
|---|---|---|
| 每个文件夹支持的文件数 | 最多 500 个 | 「文件夹中的文件过多（…）。监视文件夹限制为 500 个文件。」 |
| 一次扫描的目录条目 | 最多 20,000 个 | 「该文件夹过大，无法监视。监视文件夹用于存放少量文档。」 |
| 整个磁盘 | 不允许（如 `/`、`C:\`、`/Volumes/` 下的磁盘） | 「无法监视整个磁盘。请改为选择文档文件夹。」 |

请选一个小的文档文件夹。整个用户目录几乎一定会超出 20,000 个条目。`node_modules`、`.git` 这类依赖、版本管理和缓存目录会被忽略。

添加之后，文件夹变大超过上限，这个文件夹的学习会暂停，文件也会从列表和计数里消失。回落到上限以内后自动恢复。知识库详情页顶部会显示「N 个监控文件夹未学习」，点它跳到设置。

文件夹找不到时（例如移动硬盘拔掉了、网络共享没挂载），它显示为 **不可用**。接上之后点 **重试**，Halo 每次启动时也会再找一次。

点文件夹行的 X 只是停止监视，文件夹和文件都不受影响。已提取的文字会保留到下次[重建索引](#re-index)。

在远程网页和 Android 应用里看不到 **添加文件夹**，但可以查看和移除已有的监视文件夹。

## 暂停知识库 {#pause}

在 **设置 › 学习** 里关掉 **继续学习**，或点卡片上的暂停按钮，知识库就变为 **已暂停**：

- 不再监视文件夹，新复制进来的文件也不会自动学习。**学习 N 个新文件** 按钮仍然可用。
- 对话和数字人从下一条消息或下一次运行起不再使用它。重新打开后自动恢复使用，不用重新加载。
- 知识库自己的 **聊天** 标签仍然可以基于它回答。

重新打开 **继续学习** 后，Halo 会恢复监视，并检查一遍暂停期间变了哪些文件。

## 默认知识库 {#default}

默认知识库会自动加载到**每个工作区的每个新对话**里，最多只有一个。新安装的数字人也会带上它。

设置方法任选其一：

- **设置 › 学习** 里打开 **默认知识库**
- 卡片上 **更多 › 设为默认**
- 对话输入框 **知识** 菜单里点星标

设新的默认会取消原来的默认。卡片菜单只能设为默认，要取消默认，请用设置里的开关或星标。已有的对话不受影响。

## 重建文档索引 {#re-index}

**设置 › 学习 › 重建文档索引 › 重建索引** 会清掉已提取的文字和学习状态，再从知识库里的副本和监视文件夹重新提取一遍。资料本身保留，通常很快。正在学习时不能重建。

重建索引读的是知识库自己的副本，所以你修改了原位置的文件，重建索引也拿不到新内容。要更新添加过的文件，请把新版本再添加一次；监视文件夹本来就会自动学习改动。

## 删除知识库 {#delete}

**设置** 底部点 **删除知识库 › 删除**，或卡片上 **更多 › 删除**。

::: danger 删除无法撤销
删除会永久移除这个知识库里复制的文件、提取的文字和文档目录。你电脑上其他位置的原文件和监视文件夹里的文件不受影响。
:::

## 向知识库提问 {#ask}

想只基于一个知识库问答，点详情页顶部的 **提问**，或切到 **聊天** 标签。在「提个问题…」里输入问题，按 <kbd>Enter</kbd> 发送（<kbd>Shift</kbd> + <kbd>Enter</kbd> 换行）。回答过程中会显示「正在搜索知识库…」「正在撰写回答…」，回答下方列出[来源](#sources)。

这里的问答是**临时的**：

- 不会出现在对话列表、搜索和任务面板里。
- 切换标签不会丢，但点 **清空聊天**、离开这个知识库或去别的页面，问答就会被删除。
- 用当前的默认模型，按正常对话消耗 token，需要先[连接模型](/features/models)。
- 不使用工作区记忆。

想保留问答，或者同时用多个知识库，请在普通对话里[加载知识库](#use-in-conversation)。

## 来源 {#sources}

回答下方的 **来源** 列出 AI 这次真正打开读过的文档，每篇只列一次。点一下在画布中打开：添加的文件打开知识库里的副本，监视文件夹的文件打开原文件。

**聊天** 标签和普通对话里都有来源。普通对话的来源随消息一起保存。原文件已经不存在的文档不会列出。

## 在对话里使用知识库 {#use-in-conversation}

::: say
> 根据知识库里的合同模板，帮我列出付款条款

先用输入框的 **知识** 按钮加载放着合同模板的知识库，再发这句话。Halo 会在知识库里找到合同模板，读完后列出条款，回答下方显示 **来源**。
:::

1. 在对话的输入框里，点 **＋** 旁边的 **知识**（提示「把知识库加载到这个对话中」）。
2. 在「加载知识库」菜单里点一个知识库，就为**这个对话**加载或卸下它。按钮上的数字是已加载的数量。
3. 发下一条消息。改动从下一条消息起生效。

![输入框的「知识」菜单：已加载的知识库「产品资料」打了勾，右边是图钉和星标，下面是「管理知识库」](/images/features/knowledge-base/knowledge-menu.zh.webp)

菜单里每一行还有两个图标：

| 图标 | 作用 | 影响范围 |
|---|---|---|
| 图钉 | 在此工作区中始终启用（适用于新对话），行上显示 **工作空间** | 这个工作区之后的新对话 |
| 星标 | 设为[默认知识库](#default)，行上显示 **默认** | 所有工作区之后的新对话 |

图钉和知识库 **设置 › 已连接的工作区**、新建时的 **连接到工作区(可选)** 是同一件事。新对话创建时，会带上所在工作区连接的知识库和默认知识库，之后每个对话各自增减，互不影响。还没有知识库时，菜单显示「暂无知识库内容」和 **添加知识**；底部的 **管理知识库** 打开知识库页面。

::: warning 加载的知识库每轮都消耗少量 token
加载后，每个知识库的文档目录会加进这个对话每一轮的提示里（最多 200 篇，每个知识库最多 24,000 个字符），即使这一轮没用上。不需要的知识库请卸下。
:::

几点说明：

- 已暂停的知识库会被跳过；还在学习的知识库只带上已经学完的文档。
- 模型需要支持工具调用（搜索和读取文件），不需要特定的提供商。
- AI 正在回复时、数字人对话里，看不到 **知识** 按钮。数字人要在它自己的设置里[绑定知识库](#digital-humans)。

::: done
回答下方出现 **来源**，列出知识库里的文档，就说明 AI 用上了知识库。
:::

## 给数字人用知识库 {#digital-humans}

1. 打开 **数字人**，选中一位数字人。
2. 进入 **能力与设置 › 工具与资源 › 知识**。
3. 点知识库行勾选或取消。提示是「数字人可引用已勾选知识库中的文档。」

勾选后，数字人的每次运行和每次对话都能读这些知识库。改动从下一次运行或下一条消息起生效，不用重启。数字人安装时，会自动带上所在工作区连接的知识库和默认知识库。数字人的其他设置见[能力与设置](/digital-humans/capabilities)。

知识库 **设置 › 已连接的工作区** 下方也会列出使用它的数字人，点名字打开那位数字人。

## 让 AI 管理知识库 {#operate-halo}

打开[操作 Halo](/features/operate-halo) 后，AI 可以替你新建、改名、暂停知识库，设默认，连接工作区或数字人，按文件路径添加文件，设监视文件夹，开始学习，重建索引和删除。规则和限制与界面相同，例如监视文件夹最多 500 个文件。

这也是在远程访问和 Halo Server 上给知识库加文件的唯一方式：告诉 AI 文件或文件夹在运行 Halo 的那台电脑上的路径。

## 远程访问和 Halo Server {#remote}

| 场景 | 能做 | 不能做 |
|---|---|---|
| 远程网页、Android 应用 | 浏览、新建、改名、暂停、设默认、连接工作区、移除复制的文件、重建索引、删除、提问、来源、输入框的 **知识** 按钮 | 添加文件（显示「添加文件需要桌面应用。」）、添加监视文件夹 |
| [Halo Server](/server/) | 学习和监视照常运行 | 在浏览器界面里添加文件 |

在这两种场景下加文件，请用[操作 Halo](#operate-halo)，给出服务器上的路径。

## 数据存放在哪里 {#storage}

知识库全部保存在本机的 Halo 数据目录 `~/.halo/knowledge-bases/` 里，监视文件夹留在原位置。各平台的目录见[数据与配置位置](/advanced/config-paths)。

## 知识库和记忆的区别 {#memory-vs-knowledge-base}

知识库放的是**你**收集的文档，[记忆](/features/memory#memory-vs-knowledge-base)是 **AI** 工作时为自己记下的决定、偏好和经验。

## 遇到问题 {#troubleshooting}

### 提示「已跳过 N 个不支持的文件」

文件格式不在[支持的文件](#supported-files)里。旧版 `.doc` `.ppt` `.xls` 请先另存为 `.docx` `.pptx` `.xlsx` 再添加。源代码和配置文件不收进知识库，处理代码请直接在[工作区](/features/spaces)里让 AI 读。

### 文件显示「无文字图层 — 似乎是扫描件」

这是扫描版 PDF，没有可提取的文字，Halo 目前不对 PDF 页面做文字识别。可以把页面导出成图片再添加，图片会用本机文字识别读出文字。

### 文件一直在「尚未学习」

- 知识库是否 **已暂停**？暂停时新文件不会自动学习。点 **学习 N 个新文件**，或重新打开 **继续学习**。
- 扩展名是文本、内容却像二进制的文件，永远不会被学习，会一直留在这一组。

### 改了原文件，回答还是旧内容

添加的文件是副本，不会跟着原文件变，重建索引也一样。把新版本再添加一次，或者把这个目录改成[监视文件夹](#watched-folders)。

### 监视文件夹显示「不可用」

文件夹所在的硬盘或网络位置没有连接。连接后点 **重试**。仍然提示「该文件夹仍不可用」时，检查文件夹是否被移动或改名。

### AI 回答时没用知识库

- 看输入框 **知识** 按钮上的数字，确认知识库加载到了**这个**对话。连接工作区和设默认只影响新对话。
- 确认知识库没有暂停，文件显示 **已学习**。
- 加载或卸下后，从下一条消息起才生效。
- 在问题里点明「根据知识库里的……」，AI 会更明确地去查。
