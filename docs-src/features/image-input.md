# 图片输入

Halo 支持在对话中直接发送图片，AI 可以识别、分析图片内容并做出回应。

## 如何添加图片

三种方式均可：

1. 点击输入框左侧的 **「+」** 按钮，选择文件
2. 直接将图片文件**拖拽**到输入框
3. 使用 **Ctrl/Cmd + V** 粘贴剪贴板中的截图

## 支持格式与限制

| 项目 | 说明 |
|------|------|
| 支持格式 | PNG、JPEG、WebP、GIF |
| 单张最大体积 | 20MB |
| 单次最多数量 | 10 张 |

---

## 重要：必须使用多模态模型

::: danger 非多模态模型会报错
图片输入**仅支持多模态模型**，如 Claude 4.5、Claude 3.7 Sonnet、GPT-4o 等。

使用不支持视觉的模型（如部分国产模型 API）时，上传图片会导致报错，且由于上下文中已包含图片参数，**必须新开对话**才能继续正常使用。
:::

切换多模态模型的方式：右上角模型选择菜单。

---

## 典型用例

- 截图给 AI，让它分析 UI 设计或代码错误信息
- 上传图表，让 AI 解读数据
- 发送设计稿，让 AI 生成对应代码
- 拍照文档，让 AI 提取或翻译文字
