# 文件和图片

::: say
> 帮我总结这份合同的风险点。

先用 **＋ › 文件和文件夹** 把合同附上，再发送这句话。Halo 会读取文件内容，列出它找到的风险点。Word、Excel、PPT 和 PDF 都能直接读，不需要先装任何东西。
:::

## 三种添加方式 {#ways-to-add}

文件、文件夹和图片都可以用下面三种方式放进输入框，效果一样：

| 方式 | 怎么做 |
|---|---|
| ＋ 菜单 | 点输入框左边的 **＋**（「添加文件、上下文和能力」），在 **添加** 里选 **文件和文件夹**（网页和安卓端叫 **文件**） |
| 拖入 | 把文件或图片拖到输入框上，看到「拖到这里，附加文件或文件夹」时松手 |
| 粘贴 | 在文件管理器里复制文件，或者截一张图，回到输入框按 <Shortcut mac="⌘ V" other="Ctrl V" /> |

Halo 会自动分开处理：图片作为图片发给模型，其他文件和文件夹变成输入框里的卡片。

## 附加文件和文件夹 <Badge type="info" text="仅桌面版" /> {#attach-files}

在桌面版里，附上的文件和文件夹**不会被上传或复制**。Halo 把它们在电脑上的位置告诉 AI，AI 直接在原处读取。菜单里的说明是「附加本机文件，AI 直接读取，无需上传」。

1. 点 **＋**，选 **文件和文件夹**。系统的选择窗口里，文件和文件夹都能选。
2. 选好后确认。每个文件或文件夹在输入框里变成一张卡片，**＋** 菜单的这一行会显示已附加的数量。
3. 写下你要它做什么，发送。

- 附上一个文件夹，适合「把这个文件夹里的周报汇总一下」这类任务。
- 一条消息最多带 50 张卡片，附加的文件和引用的内容合在一起算。
- 从工作区资源的 **文件** 栏把文件拖进输入框，插入的是这个文件的路径文字，而不是卡片，作用和 [@ 引用](#mention-files) 一样。

网页和安卓端没有这种方式，文件要先上传，见 [在网页和安卓端上传](#remote-upload)。

## 发送图片 {#images}

截图、照片、图表和设计稿都可以直接发给 AI。模型能看图时，它看到的就是图片本身，适合让它解读图表、看报错截图或照着设计稿写页面。

1. 用上面任意一种方式添加图片。处理期间输入框上方显示「正在处理图片...」。
2. 图片以缩略图出现在输入框上方。不想发了，点缩略图上的 **移除图片**。
3. 写一句你想让它做什么，比如「帮我把这张表格截图里的数据整理成一份简报」，然后发送。

| 项目 | 限制 |
|---|---|
| 每条消息 | 最多 10 张图片。超出的部分按普通文件附上，不会丢 |
| 单张大小 | 压缩前最大 20 MB |
| 格式 | JPEG、PNG、GIF、WebP。BMP、TIFF 等其他格式按普通文件附上 |
| 发送前处理 | 长边缩到最多 1568 像素再发送 |
| AI 工作期间 | 不能给排队的消息加图片，等这轮回复结束再发 |

发出去的图片可以点开查看：<kbd>←</kbd> <kbd>→</kbd> 切换图片，<kbd>+</kbd> <kbd>-</kbd> <kbd>0</kbd> 或鼠标滚轮缩放（0.5 到 3 倍），<kbd>Esc</kbd> 关闭。

**怎么知道当前模型能不能看图**：在桌面版点发送按钮旁的模型名，弹出的卡片里有一行 **图片输入**，显示 **支持** 或 **不支持**。Halo 不确定时不显示这一行。

## 模型不支持图片时：文字识别 {#text-recognition}

不是每个模型都能看图。给不支持图片的模型发图片时，Halo 不会报错，而是自动改用本机的 **文字识别**：

- 输入框上方提示「当前模型不具备视觉能力——图片将通过本地 OCR 转文字读取（仅文本）」。照常发送就行。
- Halo 把图片另存为工作区里的文件，并为这个会话自动打开 **文字识别**，AI 用它读出图片里的文字。
- AI 只能拿到文字，看不到图片本身。版式、颜色和图表的形状它都不知道。

::: info
从 2.1.15 起，不支持图片的模型不再因为图片报错，也不需要新开对话。
:::

| 项目 | 文字识别的说明 |
|---|---|
| 在哪里运行 | 在你的电脑上运行，图片不会发到任何地方 |
| 费用 | 不消耗 token |
| 语言 | 英文和简体中文。中文基本可用，个别字可能认错 |
| 能做什么 | 只提取文字，不描述图片内容 |
| 格式 | PNG、JPG、JPEG、WebP、BMP、TIF、TIFF、GIF |
| 大小 | 每个图片文件最大 50 MB，每次最多识别 20 张 |

你也可以自己打开它：点 **＋**，在 **能力** 里打开 **文字识别**（「在本机识别图片中的文字，不消耗 token」），从下一条消息起生效。适合让 AI 读取工作区里一批截图或扫描件上的文字，比把每张图都发给模型更省 token。各项能力的说明见 [能力](/features/capabilities)。

- Halo 根据模型判断它能不能看图。判断错了，可以在 [模型与账号](/features/models) 里这个模型的 **模型配置** 中勾选或取消 **视觉**。
- 知识库学习图片时用的也是这套本机文字识别，见 [知识库](/features/knowledge-base)。

## 在网页和安卓端上传 {#remote-upload}

通过 [远程访问](/features/remote-access) 在浏览器或 [安卓 App](/features/mobile) 里使用 Halo 时，设备上的文件不在 Halo 所在的电脑上，所以要先上传：

1. 点 **＋**，选 **文件**（「从本设备上传到工作区；图片会直接发送给 AI」）。也可以拖入（「拖放文件以添加附件」）或粘贴。
2. 输入框显示「正在上传 N 个文件…」，上传完成前不能发送。
3. 上传好的文件保存在当前工作区的文件夹里，以卡片形式附上。

| 项目 | 说明 |
|---|---|
| 单个文件 | 最大 100 MB |
| 文件夹 | 不能上传，只能选文件 |
| 图片 | 不上传，直接作为图片发给 AI，限制和桌面版相同 |
| 重名 | 工作区里已有同名文件时，自动换一个不冲突的名字 |
| 前提 | 先打开一个工作区；Halo 所在的电脑开着远程访问 |

## 用 @ 引用工作区里的文件 {#mention-files}

文件已经在工作区里时，不用再附加，用 **@** 指给 AI 看就行：

1. 在输入框开头或空格后输入 **@**，弹出的菜单分 **数字人**、**对话**、**文件** 三组。
2. 接着输入文件名的一部分来筛选。文件组最多显示 50 个匹配，每行标着 **文件** 或 **文件夹**。索引还没建好时显示「正在索引文件…」，稍等即可。
3. 用 <kbd>↑</kbd> <kbd>↓</kbd> 选择，按 <kbd>Enter</kbd> 或 <kbd>Tab</kbd> 确认，<kbd>Esc</kbd> 关闭。输入框里插入这个文件的路径，比如 `` `docs/合同.docx` ``。

例如：「@报价单.xlsx 里第三季度的合计对不上，帮我查一下」。**@** 菜单里的数字人和对话怎么用，见 [会话](/features/conversations)。

## AI 做好的文件在哪里 {#ai-created-files}

Halo 生成或修改的文件保存在当前工作区里，会出现在工作区资源的 **文件** 栏（点右上角 **展开工作区资源** 打开）。单击可以在画布里预览，双击用电脑上的软件打开。详见 [文件与画布](/features/files-and-canvas)。

::: done
附上的文件变成输入框里的卡片，图片显示为缩略图；发送后 AI 的回复提到了文件或图片里的内容，就说明它读到了。
:::

## 遇到问题 {#troubleshooting}

### 提示「图片过大 (…),最大 20MB」

单张图片超过 20 MB，没有附上。先压缩图片，或者只截取需要的那一部分再发。

### 提示「当前模型不具备视觉能力——图片将通过本地 OCR 转文字读取（仅文本）」

这不是错误，图片仍然会发出去，AI 通过 [文字识别](#text-recognition) 读到其中的文字。如果你需要 AI 看懂图片本身，比如图表走势或界面布局，点发送按钮旁的模型名，换一个 **图片输入** 显示 **支持** 的模型。

### 提示「无法附加：不是这台电脑上的文件或文件夹」

拖进来的内容在电脑上没有对应的文件，比如从网页里直接拖出的内容。先把它保存到电脑上，再附加保存好的文件。

### 网页或安卓端提示「文件夹无法附加：此设备仅支持上传文件」

网页和安卓端只能上传文件。把文件夹压缩成一个文件再上传，或者回到桌面版附加整个文件夹。

### 网页或安卓端提示文件太大、未上传

单个文件超过 100 MB。拆小后再上传，或者在 Halo 所在的电脑上用桌面版直接附加。

### AI 工作时加不了图片

AI 正在回复时，可以继续发文字补充，但这条排队的消息不能带图片。等这轮回复结束，或按 <kbd>Esc</kbd> 停下后再发图片。

### @ 菜单里找不到我的文件

@ 只列出当前工作区里的文件。文件在别的位置时，用 **＋ › 文件和文件夹** 附加。看到「正在索引文件…」时，等索引完成再找。

### 识别出来的字不对

文字识别只认英文和简体中文，图片模糊或字很小时容易出错。换一张更清楚的图，或者换一个支持图片输入的模型。
