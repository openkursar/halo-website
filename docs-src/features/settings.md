# 设置参考

在左侧导航栏点 **设置** 打开设置页。左边是 9 个分区，顺序和本页一致：**AI 模型**、**消息通道**、**应用商店**、**外观**、**系统**、**高级**、**远程访问**、**推荐 Halo**、**关于**。本页按这个顺序列出每个设置项的作用、默认值和限制，适用于 Halo 3.0.4。具体怎么操作，看各行链接的功能页面。没有 **保存** 按钮的项目改完立即生效。

Halo 不能替你修改这些通用设置（主题、语言、权限、系统行为、远程访问都要你自己改）。它能替你做的只有切换模型来源和模型，而且要先打开 **操作 Halo**，见 [哪些事仍需你自己动手](/features/operate-halo#what-stays-manual)。

::: info 说明
公司提供的 Halo 可能显示不同的选项：登录方式、消息通道的帮助链接、商店来源、浏览器允许的站点、互联网访问和内置网关都可能由版本决定。以你屏幕上看到的为准。
:::

## 仅桌面版的设置 {#desktop-only}

在浏览器（通过远程访问）或安卓 App 里打开设置时，下面这些项目不显示。它们只能在运行 Halo 的那台电脑上改。

| 项目 | 远程网页端和安卓 App |
|---|---|
| **系统**、**高级**、**远程访问** 三个分区 | 整个分区隐藏 |
| **外观 › 显示大小** | 隐藏，改用浏览器自己的缩放 |
| **AI 模型** 里的 Claude Code CLI 来源 | 隐藏 |
| 其他分区（AI 模型、消息通道、应用商店、外观、推荐 Halo、关于） | 可用，改动保存到同一台 Halo |

## AI 模型 {#ai-model}

**设置 › AI 模型** 管理你接入的所有 AI 来源（账号或 API Key），并选出新对话默认用哪一个。每个对话用的模型在输入框旁的模型卡片里单独选。登录、填 Key、多账户和每个模型的参数都在 [模型与账号](/features/models) 里讲。

| 项目 | 作用 | 默认 | 备注 |
|---|---|---|---|
| 来源列表（单选按钮） | 选中的来源成为全局当前来源 | — | 刚保存的来源自动成为当前来源；删掉当前来源后，列表里第一个来源接替 |
| 展开后的 **提供商**、**认证类型**、**API URL** | 显示这个来源的类型和地址 | — | **API URL** 只在 API Key 来源上显示 |
| **编辑** / **删除** | API Key 来源：修改，或删除（要点 **确认删除**） | — | — |
| **编辑** / **退出登录** | 登录类来源：改账户名和模型设置，或退出 | — | **退出登录** 没有确认步骤 |
| **移除** | Claude Code CLI 来源：从 Halo 移除 | — | CLI 自己的登录不受影响；仅 macOS，远程端隐藏 |
| **添加AI提供商** | 新增一个 API Key 来源 | — | — |
| **OAuth登录** 组 | 用账号登录，例如 Claude、ChatGPT、GitHub Copilot | — | 列出哪些登录方式由版本决定 |
| **预设API** 组 | 版本预置的固定网关，只需填 API Key | 不显示 | 只在预置了网关的版本中出现 |

## 消息通道 {#message-channels}

**设置 › 消息通道** 配置数字人和人之间收发消息的通道。前 3 张卡片是双向机器人，后 5 张是单向通知。每种机器人都可以添加多个实例。文本框停止输入 500 毫秒后自动保存。这个分区在远程网页端和安卓 App 里同样可用。

| 卡片 | 方向 | 作用 | 详细说明 |
|---|---|---|---|
| **微信机器人** | **双向** | 个人微信扫码登录，只支持私聊 | 没有主人/访客权限控制，每个发消息的人都按主人对待 |
| **飞书机器人** | **双向** | 飞书或 Lark 机器人，可以 **扫描添加** 或 **手动设置** | [消息通道](/digital-humans/channels) |
| **企业微信智能机器人** | **双向** | 企业微信机器人，可以 **扫描添加** 或 **手动设置** | [消息通道](/digital-humans/channels) |
| **电子邮件** | **单向** | SMTP 发信；同一套配置也给数字人的邮件能力用 | [邮件](/features/email) |
| WeCom、DingTalk、Feishu | **单向** | 企业微信、钉钉、飞书的自建应用通知 | 中文界面里这 3 张卡片的标题显示为英文。见 [消息通道](/digital-humans/channels) |
| **Webhook** | **单向** | 把通知以 JSON 发到你的地址 | [消息通道](/digital-humans/channels) |

从设置页 **扫描添加** 机器人，总会新建一位数字人并绑定上去。想给已有的数字人接机器人，从数字人那边操作，见 [消息通道](/digital-humans/channels)。

## 应用商店 {#app-store}

**设置 › 应用商店** 只管理商店从哪些来源（注册表）读取内容，不是商店本身。浏览和安装在左侧导航栏的 **商店** 里，见 [商店](/digital-humans/store)。添加私有来源的步骤见 [私有商店](/advanced/private-store)。

| 项目 | 作用 | 默认 | 备注 |
|---|---|---|---|
| 来源列表 | 每行显示名称、类型、地址和开关 | 5 个内置来源全部开启 | 关闭后商店里不再显示它的内容；已安装的内容照常可用 |
| **添加注册表** | 填 **名称** 和 URL，点 **添加** | — | 只接受 http/https；不能指向 localhost、内网 IP 或链路本地地址 |
| **移除注册表**（垃圾桶图标） | 删除你自己加的来源 | — | 内置来源不能删除，只能关闭 |
| **Smithery API密钥（可选）** | Smithery 来源的可选密钥 | 空 | 只在 Smithery 那一行显示 |

改动后商店列表立即刷新。

## 外观 {#appearance}

| 项目 | 作用 | 默认 | 备注 |
|---|---|---|---|
| **主题** | **浅色**、**深色** 或 **跟随系统** | **跟随系统** | 保存在 Halo 里：在远程端改，电脑上也跟着变 |
| **显示大小** | 整个界面的缩放，50%–150%，每档 10% | 100% | 仅桌面版。也可以用 <Shortcut mac="⌘ +" other="Ctrl +" /> 放大、<Shortcut mac="⌘ −" other="Ctrl −" /> 缩小、<Shortcut mac="⌘ 0" other="Ctrl 0" /> 复原；**重置** 回到 100% |
| **语言** | 界面语言：Deutsch、English、Español、Français、日本語、简体中文、繁體中文 | 第一次启动时跟随系统语言，匹配不上用 English | 每台设备单独保存：手机和电脑可以用不同语言 |
| **发送键** | **Enter** 发送（Shift+Enter 换行），或 **Ctrl+Enter** 发送（Enter 换行） | **Enter** | macOS 上标签也写 Ctrl |

托盘菜单、应用菜单和部分系统对话框只有英文，不跟随 **语言**。

## 系统 <Badge type="info" text="仅桌面版" /> {#system}

**设置 › 系统** 最上面是 **权限** 卡片，下面是系统设置。

| 项目 | 作用 | 默认 | 备注 |
|---|---|---|---|
| **权限**（标记 **完全权限模式**） | 说明 AI 执行操作前不会逐项询问你 | **信任模式** 开启 | 开关锁定为开，不能关。见 [工具权限](/advanced/security#tool-permissions) |
| **浏览器允许的站点** | 给 AI 浏览器的允许名单加你自己的站点 | 不显示 | 只在部分版本中出现。见 [AI 浏览器](/features/ai-browser) |
| **浏览器数据 › 清除浏览器数据** | 清除共享浏览器的 Cookie、网站存储和缓存 | — | 3.0.4 新增。所有网站都会退出登录，包括数字人用的网站；Halo 数据保留；不能撤销 |
| **开机自动启动** | 登录系统时自动运行 Halo | 关 | macOS、Windows 有效；Linux 上打开也没有效果 |
| **任务通知**（「后台任务完成时通知我」） | Halo 窗口不在前台时，对话完成一轮后发系统通知 | 关 | 点通知会切回 Halo。数字人的通知不受它控制，在数字人的 **能力与设置 › 消息与通知 › 系统通知** 里设 |
| **代理** | Halo 自身流量（模型请求、商店、Halo 启动的 AI 引擎和 MCP 进程）走的代理。检查和下载更新不走这里，始终用系统代理 | 空，即使用系统代理 | 只接受 `http://` 和 `https://`，点 **保存** 或按 <kbd>Enter</kbd>。系统里设的 SOCKS 代理要在留空时才生效 |
| **以下地址不使用代理** | 不走代理的地址，逗号分隔 | 空 | 3.0 新增。`.example.com` 只匹配子域名，主域名要另加 `example.com`；支持 `10.0.0.0/8` 这类 IP 段。本机地址始终不走代理。改动对之后开始的对话生效 |
| **同时应用于AI浏览器** | 让 AI 浏览器也用上面的代理 | 关 | 只在填了代理地址后出现；关闭时 AI 浏览器用系统代理 |
| **浏览器 User-Agent** | 替换 AI 浏览器发送的 User-Agent | 空，即内置默认值 | 最多 1024 个字符，保存后立即应用到已打开的页面 |
| **日志文件 › 打开文件夹** | 在文件管理器里打开日志文件夹 | — | `main.log` 满 10 MB 轮转，保留 5 份。位置见 [数据与配置位置](/advanced/config-paths) |
| **崩溃报告 › 打开文件夹** | 打开崩溃转储文件夹 | — | 3.0 新增。报告只存在本机，不会上传 |
| **重启 Halo › 重启** | 重启应用 | — | 会中断所有进行中的对话和后台任务，先确认 |
| **系统诊断 › 运行诊断** | 体检，显示「系统健康」或「检测到问题」 | — | 展开看系统信息、健康指标、进程和服务状态、最近 5 条错误 |
| **恢复操作**：**重置 AI 引擎**、**重启应用** | 结束全部 AI 会话后重启引擎；或重启整个应用 | — | 先试 **重置 AI 引擎**，它能解决大多数问题 |
| **复制报告** / **导出报告** | 复制诊断文本，或把 `halo-diagnostics-<时间>.json` 存到「下载」文件夹 | — | 报告已脱敏：API Key 和令牌被遮盖，路径里的用户名被隐去 |

排查步骤见 [日志与诊断](/troubleshooting/diagnostics)，代理怎么配见 [模型网关与代理](/advanced/gateway-and-proxy)。

## 高级 <Badge type="info" text="仅桌面版" /> {#advanced}

分区顶部提示：「此处的更改将影响所有 AI 助手的行为。新设置将在下次对话时生效。」

### AI Agent 引擎 {#agent-engine}

| 选项 | 说明 | 默认 | 备注 |
|---|---|---|---|
| Claude Code SDK | Anthropic 官方 Claude Code 引擎 | 是 | — |
| Halo SDK | Halo 自己的引擎，资源占用小、启动快 | — | <Badge type="warning" text="实验性" /> |
| Codex SDK | OpenAI Codex 引擎，更适合 GPT 系列模型 | — | <Badge type="warning" text="实验性" /> |
| DeepSeek dsh | DeepSeek dsh 运行时，更适合 DeepSeek 模型 | — | <Badge type="warning" text="实验性" />，3.0 新增 |

切换后要重启才生效：出现「需要重启才能使引擎更改生效。」时点 **立即重启**。新引擎只用于之后的新对话和新任务，已有对话不能换引擎。当前版本没带的引擎显示 **此构建版本未包含**，不能选。各引擎的差别见 [Agent 引擎](/features/agent-engines)。

### 内置MCP扩展 {#built-in-mcp-extensions}

点 **内置MCP扩展** 展开。中文界面里除「数字人」外，这些行都显示英文，下表照原样引用。

| 项目 | 作用 | 默认 |
|---|---|---|
| Plan Mode | 分步规划，审批后再执行 | 关 |
| Git Worktree | 在独立的 git worktree 里并行处理分支 | 关 |
| Scheduled Tasks | AI 引擎自带的定时任务工具（Halo 有自己的计划任务） | 关 |
| Notebook Editing | 编辑 Jupyter 笔记本（.ipynb）单元格 | 关 |
| **数字人** | 在对话里创建、管理数字人并安排它们工作 | 开 |
| Cross-Conversation Interop | 让对话列出、读取同一工作区里的其他对话并给它们发消息 | 开 |
| Cross-Conversation Sending | 允许向其他对话投递消息，而不只是读取；只在上一项开启时有效 | 开 |

多开的工具每条消息都会多消耗 token。改动后新开一个会话或重启 Halo 才生效。这些工具能做什么，见 [内置工具](/features/capabilities#built-in-tools)。

### 轮次、团队和会话上限 {#limits}

| 项目 | 作用 | 默认 | 范围 |
|---|---|---|---|
| **每条消息最大轮次** | AI 处理一条消息最多调用多少轮工具 | 999 | 10–9999。旧配置里的 50 在升级到 3.0 时自动改成 999 |
| **数字团队轮次超时** | 团队成员单轮最长可用的时间 | 60 分钟 | 5–1440 分钟；3.0 新增 |
| **数字团队熔断限制 › 每次运行最大消息数** | 一次团队运行超过这个数就自动停止 | 2000 | 10–5000；3.0 新增 |
| **数字团队熔断限制 › 最大连续回复数** | 数字人之间不停来回回复的上限，有人插话时清零 | 8 | 1–100；3.0 新增 |
| **数字团队并发限制** | 这台电脑上同时运行的团队成员轮次 | 10 | 1–100；3.0 新增 |
| **活跃会话数量上限** | 同时保持就绪的对话数，每个对话在内存里占一个 AI 进程 | 20 | 2–50；3.0 新增。超出后最久没用的对话暂停，下次发消息时恢复；内存不足时自动减半 |

### 开发者模式 {#developer-mode}

**开发者模式**（标记 **开发**）默认关闭。打开后立即记录详细日志：`main.log` 改为调试级别，并新写一份 `http-raw.log`。它不会解锁任何其他功能。提示：「生成大量日志文件，可能影响性能。故障排查后请禁用。」

::: danger 警告
开发者模式打开期间，`http-raw.log` 会原样记录完整的请求头和请求体，里面有你的 API Key 和对话内容。把日志发给别人之前先关掉开发者模式。需要分享时优先用 **系统诊断** 里脱敏过的 **导出报告**。
:::

### Claude CLI 集成 {#claude-cli-integration}

分区最下面有 3 个可展开的面板。它们决定 Claude Code 引擎从哪里读取技能、设置和 MCP 配置。

| 项目 | 作用 | 默认 | 备注 |
|---|---|---|---|
| **配置目录 › Halo 默认** | Halo 自己的独立配置目录 | 是（**推荐**） | 不影响你单独安装的 Claude CLI |
| **配置目录 › Claude CLI 默认** | 和独立的 Claude CLI 共用 `~/.claude` | — | 标记 **高风险**、**不推荐**，要先确认。CLI 里设的 API Key 或地址会盖过 Halo 选的模型 |
| **配置目录 › 自定义路径** | 使用你指定的目录 | — | 点 **应用** 后，重启进行中的对话才生效 |
| **从 Claude CLI 迁移技能** | **扫描** `~/.claude/skills/`，逐个选 **跳过**、**覆盖** 或 **重命名 (+cc)**，再点 **迁移** | — | **重命名 (+cc)** 只在 Halo 里已有同名技能时出现 |
| **从 Claude CLI 迁移 MCP 服务器** | **扫描** `~/.claude.json`，逐个选 **跳过** 或 **覆盖**，再点 **迁移** | — | — |

## 远程访问 <Badge type="info" text="仅桌面版" /> {#remote-access}

**设置 › 远程访问** 让手机、平板或别的电脑通过浏览器使用这台电脑上的 Halo。完整步骤见 [远程访问](/features/remote-access)。

| 项目 | 作用 | 默认 | 备注 |
|---|---|---|---|
| **启用远程访问** | 在这台电脑上开启网页服务 | 关 | 显示 **本地地址**、**局域网地址**、**访问密码** 和 **已连接设备** |
| **访问密码** | 登录远程端用的密码 | 自动生成 12 位 | 自定义密码 8–64 位，要有大小写字母和数字 |
| **互联网访问 › 启动隧道** | 为这台设备申请一个固定的公网地址 | 关 | 需要联网，不用登录账号。**更换地址** 会让旧地址立即失效。部分版本没有这一项 |
| **扫码访问** | 二维码，手机扫码打开公网地址 | — | 只在隧道运行时显示；二维码里不含密码 |
| **联邦网关** | 中继服务器地址，让不在同一局域网的成员加入团队 | 空（仅限局域网） | 关闭远程访问时也显示；改动后重启 Halo 才作用于已有的团队连接。见 [联邦网关](/advanced/federation-gateway) |

::: danger 警告
任何拿到访问密码的人都能完全控制这台电脑上的 Halo，包括读写文件和执行命令。公网访问经过隧道服务和 Halo 的地址服务转发，不是点对点直连。
:::

## 关于 {#about}

**设置 › 关于** 在远程网页端和安卓 App 里也显示。更新的完整说明见 [更新](/advanced/updates)。

| 项目 | 作用 | 备注 |
|---|---|---|
| **版本** | 显示版本号和构建时间，例如 `3.0.4 (<构建日期>-<时间>)` | 预览版旁边有 **预览频道** 标记；界面里没有切换频道的开关 |
| **检查更新** | 立即检查一次 | 按钮依次显示 **检查中...**、下载进度、**发现新版本** 或 **已是最新版本**；失败时显示 **检查失败 — 点击重试**。手动检查会清除「稍后提醒」 |
| **构建** | 显示「Powered by Claude Code」 | 不翻译 |
| **帮助**：**文档**、**反馈** | 打开文档站，或到 GitHub 提交问题 | — |

你不点 **检查更新** 时，Halo 也会自己检查：启动后 5 秒一次，之后每 60 分钟一次，电脑从睡眠唤醒后也会查。新版本在后台下载，下载期间不弹提示。准备好后弹出一条提示：

| 情况 | 提示里的按钮 |
|---|---|
