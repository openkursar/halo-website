# 远程访问

Halo 内置远程访问功能，让你在任何设备、任何地点都能通过浏览器掌控你的 Halo，无需安装任何客户端。

## 开启远程访问

进入 **设置 → 远程访问**，按需开启以下模式。

<!-- 截图占位：screenshot-remote-settings.png（远程访问设置页） -->

---

## 局域网访问

同一 WiFi 网络下，用手机或平板扫描二维码，即可在浏览器中访问 Halo。

**访问地址格式**：`http://192.168.x.x:<端口>`

支持设置访问密码（4–32 字符），默认随机生成 6 位数字密码。

---

## 互联网访问（公网隧道）

开启后约 10 秒，Halo 会生成一个公网地址。在任何地方，用任何浏览器输入该地址和密码，即可远程访问。

支持设备类型：
- PC 浏览器（全功能）
- iPad（自适应布局）
- 手机 H5（移动端适配）

::: danger 安全提示
**拥有地址和密码的人可以完全控制你的电脑上的 Halo，进而执行任意命令。**

请将访问地址和密码妥善保管，仅发送给信任的设备或个人（如发到自己的微信或私人备忘录）。公网模式不使用时建议关闭。
:::

---

## 架构说明

Halo 的远程访问是去中心化的，每台机器的地址都是独立的 Agent 终端：

- **无中心服务器**：Halo 不经过自己的服务器中转，数据直接点对点传输
- **无法一个地址控制多台电脑**：每台设备有独立地址

管理多台电脑的推荐方式：将每台设备的地址和密码分别记录，按需访问。

---

## 典型使用场景

**提前下班场景**
开启公网隧道，把 URL 和密码发到自己的手机，回到家打开浏览器，继续指挥 Halo 干活。

**开会场景**
在无聊的会议中，用手机或平板打开 Halo，实时查看 AI 进展、发送新指令，不影响任何人。

**远程部署（macOS）**
提前在终端保持好登录会话（pin + token），回到家后让 Halo 调用 Apple Script 操作终端，完成服务器打包和部署。

---

## 与 IM 机器人对接

Halo 暴露了标准 HTTP Agent 接口，任何支持 HTTP 请求的机器人都可以接入，包括企业微信、飞书、钉钉的自定义机器人。

::: info 推荐通过 Web 体验
相较于 IM 机器人对接，直接通过浏览器访问体验更完整，配置也更简单。IM 对接适合有自动化集成需求的高级用户。
:::
