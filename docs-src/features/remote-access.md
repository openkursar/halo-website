# 远程访问

远程访问的设置不对 AI 开放，Halo 没法替你打开或改动，下面的步骤需要你在电脑上自己操作。

## 开始之前 {#before-you-start}

- **只有桌面版能开** <Badge type="info" text="仅桌面版" />：远程访问在 macOS、Windows 和 Linux 的 Halo 桌面版里设置。通过浏览器或安卓 App 打开的 Halo 里没有这个设置。
- **电脑要开着，Halo 要在运行**：别的设备连的是这台电脑上的 Halo。电脑关机、休眠，或者退出了 Halo，远程访问就断开。在 macOS 和 Windows 上关掉窗口 Halo 仍在后台运行；在 Linux 上关掉窗口就是退出。怎样让它一直在线，见 [让数字人一直在线](/digital-humans/keep-running)。
- **不需要登录账号**：局域网访问和互联网访问都不需要登录 Halo 账号。

先按你所在的位置选方式：

| 我想… | 用这个 |
|---|---|
| 手机和电脑连着同一个 Wi-Fi，开会时用手机看看进度 | [局域网访问](#lan) |
| 下班回家或出差时，继续用办公室电脑上的 Halo | [互联网访问](#internet-access) |
| 在安卓手机上长期用，后台也能收到完成通知 | [安卓 App](#android) |

## 打开远程访问 {#turn-on}

1. 点导航栏底部的 **设置**，再点左侧的 **远程访问**。
2. 读一下顶部的 **安全警告**：「启用远程访问后,任何拥有密码的人都可以完全控制您的计算机(读写文件、执行命令)。」
3. 打开 **启用远程访问**（「允许从其他设备访问 Halo」）。下方出现 **本地地址**、**局域网地址** 和 **访问密码**。

![设置里的远程访问页：启用远程访问开关已打开，下方显示本地地址、局域网地址、访问密码和互联网访问](/images/features/remote-access/remote-settings.zh.webp)

::: done
看到 **本地地址** 和 **访问密码**，就说明远程访问已经开好了。
:::

这个开关会被记住。Halo 重启后，远程访问会自动重新打开，上次开着的互联网访问也会恢复。

有设备连上时，页面会显示 **已连接设备** 和台数。这个数字统计的是所有打开的连接，包括团队里其他电脑的连接和还没输密码的登录页，所以它不是手机列表。界面上没有单独踢掉某台设备的按钮；想让所有设备都重新登录，就 [修改访问密码](#password)。

一些功能也要求远程访问开着：数字人的 HTTP 触发器（见 [运行计划与触发方式](/digital-humans/triggers)），以及邀请别的电脑加入团队（见 [跨电脑团队](/digital-humans/cross-computer-teams)）。没开时会看到「请在设置中开启远程访问，以便他人加入该团队。」

## 局域网访问 {#lan}

手机、平板或别的电脑和这台电脑在同一个网络里时，用局域网地址就能打开 Halo。

1. 在电脑上的 **设置 › 远程访问** 找到 **局域网地址**，例如 `http://192.168.1.100:3456`，点旁边的 **复制**。
2. 在另一台设备的浏览器里打开这个地址。页面显示英文登录页「Halo Remote Access」。
3. 在输入框（提示文字「Access Code」）里输入 [访问密码](#password)，点 **Connect**。看到「Connected! Loading...」后，Halo 的界面就打开了，里面是同一套会话和工作区。

关于地址：

| 项目 | 说明 |
|---|---|
| 本地地址 | `http://localhost:<端口>`，只在这台电脑本身能打开 |
| 局域网地址 | `http://<局域网 IP>:<端口>`，只显示一个；找不到局域网 IP 时不显示 |
| 端口 | 默认 `3456`，保存在 Halo 的配置里。被占用时 Halo 会自动换下一个空闲端口并记住它。界面上没有端口设置 |
| 二维码 | 局域网地址没有二维码，请手动输入或复制地址 |
| 加密 | 局域网地址是 `http://`，传输不加密，请只在信任的网络里使用 |

手机用的是移动数据而不是同一个 Wi-Fi 时，局域网地址打不开，请改用 [互联网访问](#internet-access)。

## 互联网访问 {#internet-access}

不在电脑旁边时，互联网访问会给这台电脑一个公网 HTTPS 地址，任何网络下都能打开。

1. 在 **设置 › 远程访问 › 互联网访问** 点 **启动隧道**。按钮先显示 **连接中...**，页面提示「地址已就绪——正在建立连接,通常只需几秒。」
2. 连好后显示 **永久地址** 和「此地址永久绑定这台设备,重启后自动恢复。」点 **复制** 把地址发到自己的手机上。
3. 页面下方出现 **扫码访问** 二维码（「用手机扫码即可打开你的地址——任意网络均可访问」）。用手机扫码，或在浏览器里打开永久地址。
4. 在英文登录页输入 [访问密码](#password)，点 **Connect**。

::: done
在不同的网络里（比如手机用移动数据）打开永久地址并登录后，能看到电脑上的会话，就说明互联网访问可用。
:::

### 永久地址和临时地址 {#permanent-address}

- **永久地址** 绑定这台设备，重启 Halo、关掉再打开隧道，地址都不变。可以收藏起来长期使用。
- 第一次启动隧道时，Halo 会向它的地址服务申请永久地址，这一步需要联网。
- 申请不到时，Halo 会先给一个临时的 **公开地址**，并用黄色提示说明原因：

| 提示 | 意思 |
|---|---|
| 「临时地址——签发服务暂时无法连接,此链接每次重启都会变化。下次将自动切回你的永久地址。」 | 地址服务暂时连不上 |
| 「临时地址——你所在的网络今日申请永久地址的次数已达上限。这是产品限制,不是故障。限额重置后(24 小时内)你的永久地址会自动恢复。」 | 你的网络当天申请次数用完了 |
| 「临时地址——设备身份被地址服务拒绝。」 | 地址服务不接受这台设备 |

临时地址每次启动都会变，发给手机前请确认用的是当前显示的地址。

### 更换地址 {#change-address}

地址泄露了，或者想作废旧地址时：

1. 在 **互联网访问** 下点 **更换地址**。
2. 读提示「当前地址将立即失效且无法找回」，点 **确认更换**。

旧地址马上失效，新的永久地址会显示出来；隧道没开着时，新地址在下次 **启动隧道** 时生成。每个网络每天能更换的次数有上限，用完会提示「你所在的网络今日更换地址的次数已达上限,请在限额重置后(24 小时内)再试。」记得更新收藏和用到旧地址的集成。

### 互联网访问的流量怎么走 {#how-it-works}

互联网访问不是点对点直连。流量经过 Cloudflare 隧道服务转发到你的电脑，永久地址由 Halo 的地址服务分配。公网地址使用 HTTPS。二维码里只有地址，不含密码，扫码后仍要输入访问密码。

::: info
公司提供的 Halo 可能没有 **互联网访问** 这一块：有的公司版本关掉了这个功能，此时也不会出现 **扫码访问**。局域网访问不受影响。
:::

## 访问密码 {#password}

访问密码是所有远程设备共用的一把钥匙：浏览器登录、安卓 App 和 HTTP 接口用的都是它。

- **自动生成**：第一次打开远程访问时，Halo 生成一个 12 位密码，包含大写字母、小写字母、数字和符号。
- **一直有效**：密码没有过期时间。重启 Halo、关掉再打开远程访问，密码都不变，已经登录的设备不用重新输入。
- **查看和复制**：在 **访问密码** 旁边点 **显示** / **隐藏**、**复制**。建议复制后粘贴到手机上，避免输错大小写。

### 改成自己的密码 {#custom-password}

1. 在 **访问密码** 旁边点 **编辑**。
2. 输入新密码（提示文字「8-64个字符，包含大小写字母和数字」），点 **保存**。

| 规则 | 要求 |
|---|---|
| 长度 | 8–64 个字符 |
| 必须包含 | 至少一个大写字母、一个小写字母、一个数字 |
| 符号 | 可以有，不强制 |

少于 8 个字符时 **保存** 按钮不可点；缺少某类字符时会提示缺什么，例如「密码必须包含：数字」。保存后，所有已登录的设备都会退出登录，需要用新密码重新登录。界面上没有「重新生成」按钮，想换密码就用 **编辑**。

### 输错太多次会被锁定 {#lockout}

为防止有人猜密码，Halo 会在登录失败过多时暂停登录：

| 范围 | 触发条件 | 锁定时长 |
|---|---|---|
| 同一个 IP | 5 分钟内失败 5 次 | 这个 IP 锁 15 分钟 |
| 所有设备合计 | 1 小时内失败 10 次 | 所有设备锁 30 分钟，包括你自己 |

锁定时电脑上会弹出英文系统通知「Remote access locked」或「Remote access: suspicious activity」。登录页在锁定期间也只显示「Invalid code」。成功登录只清空这个 IP 的计数；Halo 重启后计数清零。

## 远程设备上能做什么 {#remote-clients}

在浏览器或安卓 App 里打开的是同一个 Halo：同一套会话、工作区、数字人和知识库，AI 也在这台电脑上干活。你在手机上发的消息，电脑上同时能看到；多台设备可以同时登录，大家看到的是同一份内容。

有些操作只能在电脑上的桌面版里做：

| 在远程设备上 | 情况 |
|---|---|
| 设置 | 没有 **系统**、**高级** 和 **远程访问**（**联邦网关** 也在其中） |
| 新建工作区 | 不能选本机文件夹，显示「请在桌面应用中选择文件夹」 |
| 添加附件 | 输入框里是 **文件**：从当前设备上传到工作区，每个文件最大 100 MB，不能上传文件夹，也不能填电脑上的本地路径 |
| 打开工作区文件 | 点击文件会下载到当前设备，不会用系统应用打开 |
| AI 浏览器 | 没有 **打开浏览器**，看不到浏览器画面；AI 仍可以在电脑上用 [AI 浏览器](/features/ai-browser) 操作网页 |
| 知识库 | 不能添加文件或监视的文件夹 |
| 团队 | 不能加入别人的团队 |

网络断开时页面顶部显示「正在重新连接...」，恢复后会自动补上错过的内容。手机上的详细用法见 [在手机上用 Halo](/features/mobile)。

开发者可以用同一个地址和访问密码调用 Halo 的 HTTP 接口，见 [HTTP API 概览](/developers/api/)。

## 安卓 App {#android}

除了手机浏览器，还可以装 Halo 安卓 App。第一次打开时选 **连接到您的桌面**，填入 **服务器地址**（局域网地址或永久地址）或点 **扫描二维码**，再在 **访问码**（提示文字「PIN 或密码」）里输入电脑上的访问密码，点 **继续**。App 能保存多台电脑，在后台保持连接，任务完成时发通知。目前没有 iOS App。安装和使用见 [在手机上用 Halo](/features/mobile)。

## 联邦网关 {#federation-gateway}

**设置 › 远程访问** 页里还有 **联邦网关** 一栏，填的是一台中继服务器的地址，让不在同一网络的同事电脑也能加入你的数字人团队。只在局域网里组队时留空即可。何时需要、怎么部署，见 [部署联邦网关](/advanced/federation-gateway)。

## 关闭远程访问 {#stop}

- **只关互联网访问**：在 **互联网访问** 点 **停止隧道**。公网地址马上打不开，局域网访问照常可用。永久地址会保留，下次 **启动隧道** 还是同一个地址。
- **全部关闭**：关掉 **启用远程访问**。Halo 停止对外服务，隧道一起停止，所有远程设备断开，重启后也不会自动打开。访问密码会保留，再次打开时沿用原来的密码。
- **退出 Halo**：远程访问随之停止。如果开关是开着的，下次启动 Halo 后会自动恢复。

## 安全须知 {#safety}

::: danger
任何人只要拿到地址和访问密码，就能完全控制这台电脑上的 Halo：查看和修改你的会话与文件，让 AI 在这台电脑上执行命令。请把密码只发给自己的设备。
:::

- **用强密码**：保留自动生成的 12 位密码，或者设置足够长、不在别处用过的密码。
- **不用时关掉互联网访问**：点 **停止隧道**，需要时再打开，永久地址不变。
- **怀疑泄露时**：先 [修改访问密码](#custom-password)，让所有设备退出；必要时再 [更换地址](#change-address)。
- **局域网不加密**：局域网地址走 `http://`，在公共 Wi-Fi 上请改用互联网访问的 HTTPS 地址。
- **密码保存在这台电脑上**：开源版把访问密码以明文保存在 Halo 的配置文件里，能登录这台电脑的人就能看到。详情见 [安全、隐私与数据流](/advanced/security)。

## 遇到问题 {#troubleshooting}

### 手机打不开局域网地址

1. 确认电脑开着、没有休眠，Halo 正在运行，**启用远程访问** 是打开的。
2. 确认手机连的是和电脑同一个 Wi-Fi，而不是移动数据。
3. 重新复制 **局域网地址**：端口被占用时 Halo 会换端口，旧地址就打不开了。
4. 仍然不行时，检查电脑的防火墙是否拦截了 Halo，或者改用 [互联网访问](#internet-access)。

### 登录页一直提示「Invalid code」

- 密码区分大小写。在电脑上点 **复制**，再粘贴到登录页。
- 失败次数过多会被 [锁定](#lockout)，锁定期间也显示「Invalid code」。等 15 分钟（全部设备被锁时等 30 分钟）再试，或者在电脑上重启 Halo。
- 少于 8 个字符时登录页会提示「Please enter access code」。

### 已登录的设备突然回到登录页

访问密码被修改过。浏览器会回到登录页，安卓 App 会回到设备列表，用新密码重新登录即可。

### 显示「临时地址」而不是永久地址

看黄色提示里的原因，对照 [永久地址和临时地址](#permanent-address)。地址服务恢复或限额重置后，下次启动会自动切回永久地址。

### 出现「隧道连接失败」

1. 确认电脑能正常上网。
2. 点 **停止隧道**，等几秒再点 **启动隧道**。
3. 反复失败时，可能是公司网络拦截了隧道连接，请联系公司 IT。局域网访问不受影响。

### 设置里没有「互联网访问」

你用的 Halo 由公司提供，关掉了互联网访问。可以用局域网访问，或询问公司 IT。

### 提示「存储的访问凭证无法解码，已将其清除」

Halo 已关闭远程访问并清除了旧密码。重新打开 **启用远程访问**，Halo 会生成新密码，再用新密码重新登录各台设备。
