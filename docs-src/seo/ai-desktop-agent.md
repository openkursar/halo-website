# AI 桌面助手：用自然语言操控你的电脑

你有没有想过，直接对电脑说"帮我把这个文件夹里的图片按日期整理好"，然后它就自己做了？

这就是 AI 桌面助手在做的事。

---

## 什么是 AI 桌面助手

AI 桌面助手是一类运行在你电脑上的 AI 应用。与 ChatGPT 这类网页聊天工具不同，AI 桌面助手可以**直接操作你的电脑**——读写文件、运行脚本、打开网页、管理项目。

Halo 就是这样一款 AI 桌面助手。它的底层是 Anthropic 的 Claude Code Agent，但封装了完整的图形界面，不需要打开终端或输入命令行。

### 与普通 AI 聊天工具的区别

| | 网页 AI 聊天（ChatGPT 等） | AI 桌面助手（Halo） |
|---|---|---|
| 能操作你的文件吗 | 不能 | 能，直接读写本地文件 |
| 能运行代码吗 | 受限的沙盒环境 | 完整的本地运行环境 |
| 能操控浏览器吗 | 不能 | 内置 AI 浏览器，自动操控 |
| 能 7×24 自动跑任务吗 | 不能 | 数字人功能，定时自动执行 |
| 需要联网吗 | 必须 | AI 模型需要，但文件操作不需要 |

## Halo 能帮你做什么

**日常办公**
- "帮我把桌面上所有 PDF 按文件名分类到不同文件夹"
- "把这个 Excel 里的数据做一张图表"
- "帮我写一封回复这个邮件的英文邮件"

**编程开发**
- "帮我把这个 Python 脚本改成支持批量处理"
- "这个项目的 bug 在哪，帮我修一下"
- "帮我部署这个网站到服务器上"

**数据分析**
- "分析这个 CSV 文件，告诉我销售趋势"
- "帮我从这 20 个网页上抓取产品价格数据"

**自动化**
- "每天早上 8 点帮我抓取竞品价格，有变动就通知我"
- "监控这个 GitHub 仓库的新 PR，自动做 Code Review"

## 为什么选 Halo 作为 AI 桌面助手

1. **开源免费** — 代码完全开源，不收订阅费
2. **Claude Code 完整能力** — 不是阉割版，是 100% 的 Claude Code Agent
3. **不用终端** — 有图形界面，普通用户也能用
4. **远程访问** — 出门在外用手机也能操控家里/公司电脑上的 AI
5. **数字人** — 创建 7×24 自动执行任务的 AI 智能体
6. **支持全平台** — macOS、Windows、Linux、Android
