# AI 桌面助手

AI 桌面助手是运行在你电脑上的 AI 应用：它不只回答问题，还能读写本机文件、打开网页、运行命令，把一件事从头做到尾。Halo 是一款开源的 AI 桌面助手（官方叫法是 AI 桌面工作站），支持 macOS、Windows 和 Linux，本身免费，模型费用由你的账号或 API 提供商收取。

## 它在你电脑上能做什么 {#what-it-does}

| 能力 | 能做什么 | 怎么用 |
|---|---|---|
| 本机文件 | 读写你的文件和文件夹，不用先上传 | 输入框 **＋ › 文件和文件夹**，或直接拖进来 |
| 网页 | 打开网页、点击、填表、下载，沿用你的登录状态 | **网页控制**，默认开启 |
| 终端 | 和你共用一个真实终端，可以接手 SSH 和长任务（macOS、Windows） | 输入框 **＋** 里打开 **AI 终端** |
| 办公文档 | 生成和修改 Word、Excel、PowerPoint、PDF，不用另装软件 | 直接说要什么文档，见 [Office 文档](/features/office-documents) |
| 你的资料 | 从你放进知识库的文档里找答案，并标出出处 | 输入框的 **知识** 按钮 |
| 图片里的文字 | 在本机识别图片中的文字，不消耗 token | 输入框 **＋** 里打开 **文字识别** |
| 重复的工作 | 按计划自动运行，结果发到企业微信、飞书或邮件 | 让 Halo 帮你建一个数字人 |

## 用一句话交代 {#just-ask}

不需要学命令，直接说你要的结果，例如：

> 把「下载」文件夹里的 PDF 按月份整理到不同文件夹，再列一张清单给我。

Halo 会自己规划步骤并完成，每一步做了什么都显示在对话里。它工作的时候你可以随时补充信息，它做完手头这一步就会看到；想停下来就点 **停止**。

## 你需要知道的 {#good-to-know}

- **数据在哪里**：对话、文件和设置都保存在你的电脑上。发给模型的内容会经过你选择的模型提供商。
- **AI 用你的权限做事**：Halo 不会每一步都弹窗确认，需要你拍板的时候会停下来问你。在重要的文件夹里工作之前，先说清楚哪些东西不能动。详情见 [安全与权限](/advanced/security)。
- **需要联网**：调用模型需要联网；知识库学习文档和文字识别在本机完成。

## 常见问题 {#faq}

### AI 桌面助手和网页版 AI 聊天有什么不同？

网页聊天主要在网页里对话；AI 桌面助手装在你的电脑上，可以直接处理本机文件、操作浏览器和终端，还能按计划自动工作。

### Halo 收费吗？

Halo 是开源软件（MIT 协议），本身不收费。AI 模型的费用取决于你用的账号或 API 提供商。

### 不会写代码能用吗？

能。用平常说话的方式描述你要的结果就行。需要写代码的事情，Halo 会自己写、自己运行。
