# Claude Code 桌面版：不用终端，也能用 Claude Code

Claude Code 是 Anthropic 出品的强大 AI 编程工具，但它是命令行工具——你需要安装 Node.js、打开终端、输入命令。

**对很多人来说，这就是最大的门槛。**

Halo 解决了这个问题：它将 Claude Code Agent 的完整能力封装进一个桌面应用，提供图形界面。

---

## Claude Code CLI vs Halo（Claude Code 桌面版）

| | Claude Code CLI | Halo（桌面版） |
|---|---|---|
| 界面 | 终端命令行 | 图形界面（GUI） |
| 安装 | 需要 Node.js + npm | 下载双击即用 |
| Agent 能力 | 完整 | 完整（100% 继承） |
| 文件预览 | 无 | 图片、PDF、代码高亮预览 |
| 多对话 | 需要手动管理 | 可视化多窗口管理 |
| 远程访问 | 需要自己配置 SSH | 内置远程，手机浏览器即可用 |
| AI 浏览器 | 无 | 内置，AI 可直接操控网页 |
| 数字人 | 无 | 创建 7×24 自动执行的 AI 智能体 |
| 适合谁 | 开发者 | 开发者 + 非技术用户 |
| 价格 | 需要 Anthropic API Key | 需要 Anthropic API Key（相同） |

核心结论：**Halo 的 AI 能力与 Claude Code 完全相同**（因为底层就是同一个引擎），但额外提供了 GUI、远程访问、AI 浏览器和数字人。

## 谁需要 Claude Code 桌面版

### 已经在用 Claude Code 的开发者
- 想要文件预览和可视化输出
- 想在手机/平板上远程操控
- 想让 AI 自动跑定时任务

- 产品经理、运营、设计师
- 不想碰命令行的非技术用户
- 想让 AI 帮忙处理日常工作的普通用户

### 团队协作场景
- 工位电脑跑 Halo，出差时手机远程操控
- 创建数字人监控生产环境
- 让 AI 自动处理 Code Review

---

## 从 Claude Code CLI 迁移到 Halo

如果你已经在用 Claude Code CLI，迁移非常简单：

1. **API Key 直接复用** — 同一个 Anthropic API Key
2. **相同的能力** — 所有 CLI 能做的事，Halo 都能做
3. **额外获得** — GUI + 远程 + AI 浏览器 + 数字人
4. **不冲突** — Halo 和 CLI 可以同时存在
